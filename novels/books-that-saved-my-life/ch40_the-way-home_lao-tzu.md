# Ch40 · The Way Home · Lao Tzu

**讨论的书**：*Tao Te Ching*（约公元前六世纪）· Lao Tzu
**核心叙事**：McGirr 说"**有些书你掉进它就像掉进救生艇一样**"（There are books that you fall into in the same way as you fall into a lifeboat.）。在一个冬天，儿子 Jacob 说他的设备屏幕坏了——McGirr 带全家去购物中心维修——**排队、等待、被三个维修摊分别报价 349 美元、300 美元、245 美元**——**"越远离母公司，越便宜"**——Jacob 说"我们该去第三个"——McGirr 心里想"我们根本不需要去任何一个"——Jacob 已经是天才了。McGirr 在食物广场等待时，**"把脑袋探进附近的一家连锁书店"**——哲学书架上只有一本书：**Lao Tzu 的《道德经》**——**"正是我在找的"**——**"我完全不了解这本书。但它比食物广场任何一台加热盘上的任何一盘菜都便宜"**——**"我发现在书超市里潜伏着的这卷纤细的小书吞噬了我。就像在购物中心五颜六色的巨浪中找到一艘救生艇"**。

## 核心论证

1. **"fall into a lifeboat"（"掉进救生艇"**）**：**"有些书你掉进它就像掉进救生艇一样"**——**"在购物中心……找到一艘救生艇"**——**"这里是有 81 段短文冥想，写于另一个时空"**——**"Lao Tzu（不管他是谁或她是谁），比孔子年长，是苏格拉底的同代人"**——**"它是对围绕我的消费主义的完美反击。它是对理智、简单和丰富讽刺感的呼唤，面对人类试图太严肃"**。
2. **"Truthful words are not beautiful"**：**《道德经》最后一段说——**"真实的字不美；美的字不真。好的字不说服；说服的字不好。有知者不博学；博学者不知。"**——**"圣人不清积。把所有给予别人后，他还有更多；把所有给予别人后，他更富有"**。
3. **"For ten bucks, I had got myself out of a hole and back on the earth"**：**"十美元，我把自己从坑里拉出来回到了大地上"**——**"我要回家开始另一场冒险"**——Jacob 回来拿着新屏幕给了他一个拥抱——**"你是救命恩人，他说"**——**"我想告诉他我读到的拯救我生命的东西"**。
4. **"the further we walked from the mother store, the cheaper it got"**：**维修摊从 349 → 300 → 245 美元递减**——**"越远离母公司，越便宜"**——**Jacob 立刻选了最便宜的——McGirr 暗想"我们已经是不需要任何维修了的天才"**。
5. **购物中心 vs 《道德经》**：购物中心——**"六十万人，每人拿着信用卡，每人寻找东西"**——**"你可以吃世界任何大陆的任何国家的食物，但每一餐都可以配可乐"**——**"《道德经》是对消费主义的反击 = 理智 + 简单 + 讽刺 = 太严肃的反面"**。
6. **McGirr 与 Marcel 的相遇**：McGirr 在书店遇到哲学课学生 Marcel——**"让我找到哲学区"——Marcel 不知道在哪里**——**"我们找到了。只有一本书。Lao Tzu 的《道德经》"**——**"正是我在找的，我说"——Marcel 笑得非常宽**——**"也许他很高兴服务了一位顾客。也有可能如果 McGirr 找到了想要的，他的老师就会很快离开书店"**。

## 选择性精读

**①** "There are books that you fall into in the same way as you fall into a lifeboat."
- 中文理解：McGirr 说——**"有些书你掉进它就像掉进救生艇一样。"**
- 写作技巧：**"fall into" + "lifeboat"**——McGirr 用"**掉进书**"和"**掉进救生艇**"这两个"掉进"的并置来描述"书的力量"**——**"掉进书" = 偶然进入 = 被动**；**"掉进救生艇" = 紧急救援 = 生存**——**"掉进书 = 掉进救生艇" = "书 = 救生艇 = 生存"**——**"《道德经》就像在购物中心五颜六色的巨浪中找到一艘救生艇"用**"在购物中心巨浪中找到救生艇"把"《道德经》"从"书"变成"救生艇"**——**"消费主义的巨浪 = 购物中心 = 需要救生艇"**——**"《道德经》 = 救生艇 = 在消费主义巨浪中的救援"**。
- 关键表达：**fall into a lifeboat**（"掉进救生艇"——**"书的力量"**）——**本章对 *Tao Te Ching* 的核心定义**：**"《道德经》 = 救生艇 = 在消费主义巨浪中的救援"**。
- 可迁移：**用"像 X 一样掉进 Y"描述"一种生存的力量"**——"像掉进救生艇一样掉进书 = 《道德经》的力量"。

**②** "Truthful words are not beautiful; beautiful words are not truthful."
- 中文理解：《道德经》最后一段——**"真实的字不美；美的字不真。"**
- 写作技巧：**"truthful words" vs "beautiful words"**——Lao Tzu 用**"真实的字"和"美的字"**的对比来描述"语言的悖论"**——**"真实的字" = 真 = 不美**；**"美的字" = 美 = 不真**——**"真 = 不美；美 = 不真" = "真和美的对立"**——**"好的字不说服；说服的字不好"用**"好的字"和"说服的字"把"语言的悖论"从"真和美"扩展到"好和说服"**——**"好 = 不说服；说服 = 不好" = "好和说服的对立"**——**"有知者不博学；博学者不知"用**"有知者"和"博学者"把"语言的悖论"从"字"扩展到"人"**——**"有知 = 不博学；博学 = 不知" = "有知和博学的对立"**——**"三组对立 = 《道德经》的悖论 = 真美 / 好说服 / 有知博学"**。
- 关键表达：**Truthful words are not beautiful**（"真实的字不美"——**第一组对立**）；**beautiful words are not truthful**（"美的字不真"——**第二组**）；**Good words are not persuasive**（"好的字不说服"——**第三组**）——**本章对 *Tao Te Ching* 的核心定义**：**"真 = 不美；美 = 不真；好 = 不说服；说服 = 不好；有知 = 不博学；博学 = 不知"**。
- 可迁移：**用"X 不 Y，Y 不 X"描述"一种悖论"**——"真实的字不美，美的字不真"。

**③** "The sage does not hoard. Having bestowed all he has on others, he has yet more: having given all he has to others, he is richer still."
- 中文理解：《道德经》说——**"圣人不清积。把所有给予别人后，他还有更多；把所有给予别人后，他更富有。"**
- 写作技巧：**"does not hoard" + "bestowed all he has on others" + "yet more" + "richer still"**——Lao Tzu 用**"不清积"和"把所有给予别人"和"还有更多"和"更富有"**这四个短语来描述"圣人的悖论"**——**"不清积" = 不积聚 = 圣人的态度**；**"把所有给予别人" = 彻底的给予 = 圣人的行动**——**"还有更多" = "给予后 = 更多"**；**"更富有" = "给予后 = 更富"**——**"给予 = 更多 = 更富 = 圣人的悖论"**——**"越给予 = 越富有" = "越失去 = 越拥有" = "圣人的逻辑"**——**"这与购物中心形成完美对比"**——**"购物中心 = 每个人拿着信用卡寻找东西 = 越买 = 越空"**；**"《道德经》 = 圣人 = 越给予 = 越富有"**——**"消费主义 = 买 = 空 = 圣人的反面"**。
- 关键表达：**does not hoard**（"不清积"——**圣人的态度**）；**bestowed all he has on others**（"把所有给予别人"——**圣人的行动**）——**本章对"圣人"的核心定义**：**"不清积 + 全部给予 = 还有更多 = 更富有 = 圣人的悖论"**。
- 可迁移：**用"越 X 越 Y"描述"一种悖论"**——"越给予 = 越富有"。

**④** "It was a call to sanity, simplicity and a rich sense of irony in the face of human attempts to be too serious."
- 中文理解：McGirr 说《道德经》——**"它是对理智、简单和丰富讽刺感的呼唤，面对人类试图太严肃。"**
- 写作技巧：**"sanity, simplicity and a rich sense of irony"**——McGirr 用**三个"s"的短语**（sanity / simplicity / sense of irony）来描述《道德经》的"呼唤"**——**"理智" = 清醒；"简单" = 简朴；"丰富的讽刺感" = 幽默**——**"理智 + 简单 + 讽刺 = 《道德经》的核心"**——**"面对人类试图太严肃"用**"面对"把"《道德经》"从"书"变成"反击"**——**"人类试图太严肃" = 消费主义 = 购物中心 = 信用卡 = 寻找东西 = "太严肃"**——**"《道德经》 = 理智 + 简单 + 讽刺 = 反击人类太严肃 = 对购物中心的反击"**。
- 关键表达：**sanity, simplicity and a rich sense of irony**（"理智、简单和丰富讽刺感"——**《道德经》的呼唤**）；**human attempts to be too serious**（"人类试图太严肃"——**被反击的对象**）——**本章对 *Tao Te Ching* 的核心定义**：**"理智 + 简单 + 讽刺 = 对'太严肃'的反击"**。
- 可迁移：**用"对 X 的呼唤面对 Y"描述"一本书的功能"**——"对理智简单讽刺的呼唤面对人类太严肃"。

**⑤** "For ten bucks, I had got myself out of a hole and back on the earth."
- 中文理解：McGirr 说——**"十美元，我把自己从坑里拉出来回到了大地上。"**
- 写作技巧：**"ten bucks" + "got myself out of a hole" + "back on the earth"**——McGirr 用**"十美元"和"从坑里拉出来"和"回到大地上"**这三个短语来描述《道德经》的"救赎"**——**"十美元" = 极少的钱 = 一本书的价格 = "救赎的成本"**；**"从坑里拉出来" = "购物中心 = 坑 = 消费主义的坑"**；**"回到大地上" = "大地 = 真实 = 现实"**——**"从坑里拉出来 + 回到大地上 = 《道德经》 = 救赎 = 从消费主义到真实"**——**"我要回家开始另一场冒险"用**"另一场冒险"把"《道德经》"从"救赎"变成"新旅程"**——**"回家 + 另一场冒险 = 《道德经》 = 从购物中心的坑回到大地 = 新旅程的起点"**。
- 关键表达：**ten bucks**（"十美元"——**"救赎的成本"**）；**got myself out of a hole**（"从坑里拉出来"——**"购物中心 = 坑"**）；**back on the earth**（"回到大地上"——**"真实 = 现实"**）——**本章对 *Tao Te Ching* 的核心定义**：**"十美元 = 从坑里拉出来 = 回到大地上 = 《道德经》 = 救赎 + 新旅程"**。
- 可迁移：**用"用 X 从 Y 出来回到 Z"描述"一种救赎"**——"用十美元从购物中心出来回到大地"。

**⑥** "Jacob returned with a fresh screen and gave me a hug. 'You're a lifesaver,' he said. I wanted to tell him about the things I read that had saved my life."
- 中文理解：McGirr 说——**"Jacob 拿着新屏幕回来给了我一个拥抱。'你是救命恩人'，他说。我想告诉他我读到的拯救我生命的东西。"**
- 写作技巧：**"a fresh screen" + "a lifesaver" + "the things I read that had saved my life"**——McGirr 用**"新屏幕"和"救命恩人"和"拯救我生命的东西"**这三个短语来描述"McGirr 与 Jacob 的对话"**——**"新屏幕" = Jacob 想要的 = 物质**；**"救命恩人" = Jacob 对 McGirr 说的 = 感谢**；**"拯救我生命的东西" = McGirr 想告诉 Jacob 的 = 书 = 《道德经》**——**"Jacob 说 McGirr 是救命恩人" = "McGirr 帮助了 Jacob"**——**"McGirr 想告诉 Jacob 拯救我生命的东西" = "McGirr 想反向帮助 Jacob = 用《道德经》"**——**"Jacob = 物质的救命恩人 = 屏幕"**；**"McGirr = 精神的救命恩人 = 《道德经》"**——**"物质的救命 vs 精神的救命 = Jacob vs McGirr = 屏幕 vs 书"**。
- 关键表达：**a fresh screen**（"新屏幕"——**Jacob 想要的**）；**a lifesaver**（"救命恩人"——**Jacob 对 McGirr 说的**）——**本章对"McGirr 与 Jacob"的核心定义**：**"Jacob = 物质的救命恩人 = 屏幕；McGirr = 精神的救命恩人 = 《道德经》"**。
- 可迁移：**用"X 是 Y 的 Z"描述"一种双向的关系"**——"Jacob 是 McGirr 的救命恩人（屏幕）；McGirr 是 Jacob 的救命恩人（书）"。

## 一句话总结

**"有些书你掉进它就像掉进救生艇一样"**——McGirr 在购物中心 81 段《道德经》中找到**"一艘救生艇"**；《道德经》说"**真实的字不美；美的字不真；圣人不清积——把所有给予后，他更富有**"——**"十美元，我把自己从坑里拉出来回到了大地上"**——Jacob 说 McGirr 是"救命恩人"，McGirr 想告诉他"**拯救我生命的东西**"。

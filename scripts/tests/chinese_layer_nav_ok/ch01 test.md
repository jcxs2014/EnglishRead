# Chapter 1

## 本章导航

- **一句话概括**：Alba 在一家布满血迹的店里苏醒，发现耳朵上多了九个耳环，末尾听见有人在哼歌。
- **情感弧线位置**：全书第一章——先立住身体恐怖的基调，并埋下女儿缺席的母题。
- **人物弧线**：Alba 从昏迷到坐起，从困惑到认出眼前的女孩。
- **叙事手法**：第三人称限制视角，五段递进，以一句话收尾留悬念。

## 精读

> **原句 1:** "She came to in the dark, sprawled across the floor."

**中文理解**：她在黑暗中苏醒，四肢摊开趴在地板上。

**句子结构**：主句 + 过去分词短语作伴随状语。

**关键词**：came to / sprawled

**为什么这样写**：用最短的句子交代苏醒，把读者直接按进现场。

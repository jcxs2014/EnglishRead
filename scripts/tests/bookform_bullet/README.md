# bookform 的列表型子项夹具

**为什么要有这一份**：真书的子项普遍写成列表项——

```
- **中文理解**：…
```

而 `bookform.py` 第一版的 `SUB_RE` 只认行首的 `**中文理解**：`。
后果不是报错，是**整本书的子项一个都没解析出来**，于是「子项缺 / 中文过薄 / 空引号」
三项全部在空集上判 0 —— **量具没量，却报了绿**。
2026-10-20 在 `fabulous-bodies` 上实测：`bookform` 报「子项集 0 项」，而每块实际有 4 个子项。

## 预期（阴性对照，必须 rc=1）

```
子项集（众数，3 项）：中文理解 / 关键词 / 为什么这样写
❌ 子项缺：原句2 → ['为什么这样写', '读者视角提示']
结论：❌ 有阻断
```

判据：**原句 2 故意缺「为什么这样写」**。若该行不出现，说明列表型子项又没被解析。

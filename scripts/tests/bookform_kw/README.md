# bookform 关键词判据的崩栈夹具

**为什么要有这一份**：`bookform.py` 的 `kw_problems()` 里用了 `STOPWORDS`，
而 `lib.text` 的导入名单没有它 ⇒ 只要某一章有一个关键词**既不在该块引语、也不在本章全文**，
`chapter.sh` 不是报「关键词不成立」，而是 `NameError` 崩栈、退出码 1。
2026-10-20 由子代理在 ch13 上踩到（诱因：关键词中文注解里用了顿号，被 `[/、,，;；]` 切开）。

## 预期（阴性对照，必须 rc=1）

```
空引号 0｜子项缺 0｜关键词不成立 1｜中文过薄 0
  ❌ 关键词：原句1 → ['zzzqqqxx（缺 zzzqqqxx）']
结论：❌ 有阻断
```

判据：出现「关键词不成立 1」并给出缺词，而不是 `NameError` 栈。若崩栈，说明 `STOPWORDS` 又漏导入了。

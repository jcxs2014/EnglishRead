# 夹具：模板套话（bookform_template）

**期望**：`bash scripts/chapter.sh "scripts/tests/bookform_template/ch01 test.md"` → **rc=1**，输出含
`模板套话` 与 `❌ 模板套话：…「本句描写了场景与人物的反应」`。

**防的是什么**：2026-10-21 `ebenezer-scrooge-by-j-s-barnes` 实证——免费模型 33 分钟写 40 章，
中文理解抄英文原文、为什么这样写套「把 X 重新定义 as Y, not Z」696 次。这类产物**子项齐全、中文够长**，
旧判据全绿，只有模板特征能识别。

**反向对照**：正常章节（如 `fitcher-s-bird` 的 ch01）必须 `模板套话 0`。

## 小说精读目录结构与命名规则（2026-08-22 定稿）

### 目录结构（每本一个 slug 目录）
```
novels/<slug>/
├── prologue.md               ← 序言（如有）
├── ch01_keyplot.md           ← 逐章精读
├── ch02_keyplot.md
├── ...
├── epilogue.md               ← 尾声（如有）
├── 人物.md                   ← 人物档案（追加模式）
├── library/                  ← epub 原文（不入 git）
├── text/                     ← 章文本（不入 git）
└── _chapters.json            ← 章元数据（不入 git）
```
- **无 `精读/` 子目录**，**无 `分章/` 子目录**，ch*.md 直接放小说根目录
- **无总索引 `.md`**，**无词典/主题/总结.md**（词汇在各分章末尾，主题无独立文档必要）
- **FORMAT.md / INDEX.md 不追踪**——规则只记 memory

### 文件命名
- **小说**（如 a-most-angelic-death）：`ch<NN>_<keyplot>.md`
  - `<NN>` 两位数字（ch01–ch18），`<keyplot>` 本章核心情节 slug
  - 序言/尾声：`prologue.md` / `epilogue.md`
- **随笔集**（如 books-that-saved-my-life）：`ch<NN>_<chapter_title_slug>_<author_slug>.md`
  - 例：`ch01_to-kill-a-mockingbird_harper-lee.md`

### 精读格式（不适用根 AGENTS.md 逐句精读）
- 每章 3–8 段**选择性**精读；分析颗粒=叙事功能/人物关系/主题脉络
- 每章末尾附词汇三档（⭐⭐⭐/⭐⭐/⭐）+ 一句话总结

## Quartz 章节排序根因分析

### 双套独立排序机制
- **Explorer（侧边栏）**：`sortFn` 内置 P 函数 → 文件夹优先 + displayName localeCompare numeric:true
- **PageList（文件夹页）**：`byDateAndAlphabeticalFolderFirst()` → modified date desc → alphabetical fallback

### 乱序根因
批量同步文件 mtime 毫秒差 → date-desc 让 ch01（最早 mtime）落底 → ch02-07 在前

### 修复方案
统一 `modified:"YYYY-MM-DD"` frontmatter（首 commit 日期）→ 同日期 → alphabetical 接管

**逐条核**（每条都要回原文，不许只看格式）：

```bash
B=notes/books/mystery-thriller/a-fatal-legacy-by-charlotte-vassell
# 以 ch31 为例：例句列 = 第 3 个 | 与 | 之间的内容
grep -F 'This one looks like an accident.' "$B"/text/ch31_*.txt
```

判据，按顺序：

1. **整句必须在本章 `text/` 里逐字命中**（`grep -F`，不是只看开头）。命中 1 次或多次都算通过；0 次就是阻断。
2. **`grep -F` 前先剥掉例句外层的引号**（`‘ ’` `'` `"`），否则带引号会假阴。
3. **引号三态**（这是本轮改动的判据，写反会大面积假红）：
   - 原文该处句末收尾 → 例句应成对（`‘…’`）或干脆不带引号；
   - 摘录从对白中途起头 → 只留**收**引号，或全去掉；
   - **缺陷判据是「开引号数 > 收引号数」**，不是「两者不等」。
     后面那种写法会把「只有一个收引号」的正常中途摘录判成错（上一轮就这样误报过几百行）。
4. 直引号 / 弯引号不一致 → **提示型**，不是阻断。

**必须避开的两类假红**（改前先读行）：

- 例句是**两个片段**拼的（原著此处跨了叙述标签）——先看 `text/` 里两半是否各自逐字，再定性。
- 例句含 `…`（原文自带省略）——`grep -F` 整串必然查无，要分段查。

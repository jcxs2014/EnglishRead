# 4-correspondence.md · ch25 逐块对应（人判）

> 只回答一个问题：**这段中文是不是在讲这句引语？**
> 判据（`docs/rules/审查表.md` R4）：讲引语之外的上下文 → 引语选短；讲全书主旨/作者生平 → 不对应；只复述字面没有「为什么这样写」 → 密度不足。
> 另附固定三问：① 每个动词的主语是谁 ② 宾语/受事是谁 ③ 「谁的/谁欠谁/谁问的」回原文按 `by`/`to`/`from`/`of` 核方向。
> 只看引语，不看子项标题。

### 逐块固定三问的集中结论

- **说话人**：8 块全部核对通过（专家 / 凯厄斯×3 / 艾米×3 / 凯厄斯），无一处错配。
- **施事与受事方向**：8 块全部一致（艾米认包、凯厄斯看录像、艾米报店名、艾米指 T 恤、艾米想面包卷、凯厄斯提问），无「谁的／谁欠谁」方向反转。
- **密度**：8 块全部含「为什么这样写」的写法层说明，**无「只复述字面」的密度不足块**。
- **不对应块数**：0；**引语选短/溢出块数**：1（块 8）；**密度不足块数**：0。

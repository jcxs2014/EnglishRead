## 3. 防幻觉与取证纪律

1. **报警前先读行**：任何"这里不对"都必须 `sed -n 'N,Mp' 文件` 贴原文；不许凭"文件名变了""看起来像"下结论。
2. **对比同条件**：同书、同参数、同 cwd。旧脚本**从仓库根用绝对路径跑**。
3. **命令失败 ≠ 缺陷**：`ModuleNotFoundError` / `No such file` 先查自己的 cwd、参数、依赖是否复制全。
4. **报"0 问题"必须说明扫了什么**（命令、范围、样本量）。
5. **区分三种"不一样"**：路径显示不同／措辞不同／**判定不同**。只有第三种算缺陷。
6. **不确定标 ❓**，不要猜。

## 每批收口流程

1. 子代理交回执（6 项，见 `子代理派工.md` §2）
2. 主会话验收：`bash scripts/chapter.sh "<章 md>"` **rc=0**（rc=2 = 无法判定，**不是通过**）
3. 件数对账：`ls text/chNN_*.txt` 件数 == `ls chNN *.md` 件数（8.1 第 7d 条：**先数文件，再看报告**）
4. 块序抽查：`python3 scripts/structure.py order`（**不进正门，必须手跑**）
5. `bash scripts/gate.sh "<书目录>"` 退出码 0
6. `git add` **仅本批路径** → `git commit -- <明确路径>`（pathspec 模式，禁 `git add -A`）
7. 回填本表 commit hash

## 红线备忘（每次 commit 前对照）

- `git add` 只加本任务明确路径清单，**禁 `git add -A` / `git add .`**
- `git commit -- <路径>`（pathspec），**禁 `--amend`**
- **不 push**（须用户明确指令）
- 引语 1–3 句 / 30–70 词；>100 词必拆
- `…` 只能跳过**同一自然段**内内容；跨段一律拆独立引语块
- 每章必含 `## 本章词汇`（三档表，例句逐字取自本章 text/）
- 不写模板套话 / 不写不可核的计数与排版断言 / 不写「上一章」「第 N 章」跨章指认

# 派工通用条款 · love-you-to-death-by-jenna-levine

> 配套：章节专案在派工 brief 里逐条给；给料索引在 `派工指令书.md`。

## 0. 必读（按顺序，读完就写，别长篇规划）

1. `docs/rules/创建卡.md` **全文**（约 2 KB，写作规则 + 一章骨架）
2. `python3 scripts/bookform.py "notes/books/novels/love-you-to-death-by-jenna-levine" --contract`（本书契约：判红 8 项 + 一章骨架 + 导航项名 + 子项名）
3. 你负责的章的 `text/chNN_*.txt` **全文**（不许只读开头）
4. 形态参照成品（**读全文**，产出必须与它们同形）：
   `notes/books/novels/love-you-to-death-by-jenna-levine/ch01 the white room.md`、
   `ch13 monday.md`（Lucy 视角）、`ch14 the deal.md`（Daniel 视角）

**不要读、也不要去找**：`docs/rules/审查表.md`、`docs/实测档案/`、`scripts/` 下的门禁脚本源码。

## 1. 你必须自己交「素读清单」（动笔前的硬前置）

动笔**之前**先写事实清单文件：
`.memory/raw-gates/love-you-to-death-by-jenna-levine/production/chNN-facts.txt`
格式：**每行一条**，`原文锚点 || 事实`（锚点必须是原文逐字片段，事实用中文）。**5–8 条**。
然后跑：
`python3 scripts/suread.py "notes/books/novels/love-you-to-death-by-jenna-levine" chNN ".memory/raw-gates/love-you-to-death-by-jenna-levine/production/chNN-facts.txt"`
**必须全部命中（输出逐条 ✅、退出码 0）才允许动笔**；有查无就换锚点重跑。
短章凑不满 5–8 条 ⇒ **宁可少写两条、只写原文确有的事实，也不要编**。

## 2. 本书契约（`--contract` 会重复给出，以它为准）

- 体裁 `novels`
- **导航 5 项**：一句话概括 / 情感弧线位置 / **Tropes 兑现/反转** / 人物弧线 / 叙事手法
- **精读块 4 子项**：中文理解 / 关键词 / 为什么这样写 / **读者视角提示**
- 块数 profile 3–10（**硬限 2–15**）。**块数按本书自校准**：全书已成章块数区间 4–12；
  块数落在区间内即合规；偏离全书中位 ±50% 只报提示，不判红。
- H1 形态：`# <NN>. <原文标题>`（**文件号 = 原文章号 + 1**，序章占 ch01）
- 成品骨架（照此顺序）：
  frontmatter（`状态: 未读` + `modified: "2026-10-24"`）→ `# <NN>. <原文标题>` → `## 本章导航`
  （5 条 `- **xxx**：`）→ `## 精读`（每块 `> **原句 N:** "…"` + 4 个子项）→ `## 本章词汇`
  （三档表）→ `## 一句话总结`

## 3. 硬约束（违反即判红）

1. **引语逐字**：每个引语块 **1–3 句、30–70 词**（>100 词被门禁打提示）。
   **强烈建议写脚本按锚点从本章 `text/` 切片生成引语**（先把连续空白压成单空格再匹配，
   先 `find()` 定位再切片）——手打零风险。绝不可句中删词；
   **不可给原文没有引号的叙述加 `“”`**（斜体/内心叙述照抄时不要自己加引号）。
2. **`…` 的两侧各自必须是原文连续的一段**（逐字）。
   **块内各段的先后顺序必须与原文一致**——顺序倒置＝拼接红线，门禁直接判红。
3. 块数：见 brief 指定；**超过 15 或少于 2 直接判红**。
4. 每块必须含 **4 个子项**：中文理解 / 关键词 / 为什么这样写 / 读者视角提示。
5. 必须有 **导航 5 项**、**`## 本章词汇`**（三档：⭐⭐⭐ 高级 / ⭐⭐ 进阶 / ⭐ 基础；
   例句**逐字取自本章 text/** 且**例句本身必须含该词头**；释义用中文写）
   + `## 一句话总结`（正文 ≥10 字）。
6. **关键词短语控制在 3–6 词**（>8 词会被判为「关键词整句」）；
   格式：`英文短语 / 英文短语 / 英文短语（中文1、中文2、中文3）`；
   **每个关键词必须能在本块引语里找到**（门禁 lane ⑱ 会逐块核）。
7. **不要写**：模板套话、不可核的断言（「全章唯一」「第一次」「先于」「N 个词」「倒数第二段」）、
   跨章指认（「上一章」「第 N 章」「前文」——**禁止用原文章号指代别章**）、
   写作期自述（「我核对了原文」「我逐字检查」等）。
8. **不许 git add / commit / push**——只负责把文件写到磁盘。

## 4. 落盘前自检（自己跑，不许跳）

- 每段引语在本章 `text/` 里**逐字命中**；**块内分段顺序递增**；每块引语词数在 30–70。
- 词表每条例句在原文命中**且含词头**；没有给原文无引号的叙述加引号。
- 跑 `bash scripts/chapter.sh "notes/books/novels/love-you-to-death-by-jenna-levine/<你的文件名>"`，
  **退出码 0 才算过**；非 0 就修到 0（提示项也尽量清掉）。
- 建议再跑一次 `python3 scripts/structure.py order "notes/books/novels/love-you-to-death-by-jenna-levine"`
  看本章块序（该命令查全书，看自己那章有没有倒置即可）。

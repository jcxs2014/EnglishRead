## 二、退化是什么样（ch25 原文节选）

```
中文理解：本句描写了场景与人物的反应，推进了情节的发展。On the train，Captain Ambrose leaned forward and
looked Mrs Fell directly in the eyes。The telling of the story seemed to have given him a degree of
additional confidence in this regard。…（把整段英文抄一遍，再抄一遍去标点的版本）

为什么这样写：…"On the train, Captain Ambrose leaned forward…" 把 Ambrose 重新定义 as leaning forward,
not back—Ambrose leans forward；"The telling…" 把 Ambrose 重新定义 as confident, not timid—Ambrose confident；
…（同一句式把每句引语复述一遍）此句通过修辞与节奏把人物的内心状态外化为可感知的文本细节，使读者在不被
直接告知的情况下理解其动机与处境…（这句话在同一字段里重复 3 次）
```

三类特征同时出现，是**模板循环**而不是写作：
1. 中文理解 = 英文原句逐句照抄 + 去标点再抄一遍；
2. 关键词 = 整句英文（`His English was very good, tinged with a slight accent（同一句）`）；
3. 为什么这样写 = 「把 X 重新定义 as Y, not Z」机械重复 + 一句通用套话反复出现。

## 三、根因

该会话模型为 `dsh-opencode-go / beam-free`（后切 `commandcode / reflection/beam:free`），`reasoningEffort: low`。
**免费模型的自由额度在长任务后段塌成模板循环**：ch01/ch02 还能写，第 3 章开始套话出现，第 8 章引语失控，第 19 章之后基本只剩英文复读。
与「规则太多」无关——同样的指令在 ch01/ch02 产出了合格内容。

## 四、处置

1. **停掉 `session-895bdfe5`**，不要再让它写 ch44 之后（73 章只写了 43 章，且 41 章是废的）。
2. **作废 ch03–ch43**：
   ```bash
   cd notes/books/novels/ebenezer-scrooge-by-j-s-barnes
   git rm "ch03 III.md" … "ch43 XI.md"      # 41 个，逐条列全路径，禁止 git rm -r 整个目录
   ```
   commit 信息写「作废 ch03–ch43：退化产物（模板循环 / 引语超长 / 分析英文），保留 ch01–ch02」。
   **不要 `git reset`**：本机多实例共用一个 HEAD，reset 会把别人的提交一起带走。
3. **ch01–ch02 保留**，作为形态样板（92% 中文、引语 67–71 词、关键词 3–5 个词）。
4. **用非免费模型重写**：每条指令只写一章，写完立刻 `bash scripts/chapter.sh "<章 md>"`；每章提交间隔不得低于 5 分钟（低于这个数说明是套话生成的）。

## 五、验收（每章都要过，不是最后抽查）

- `chapter.sh` rc=0，且输出里 `引语偏长` 必须为 0；
- 引语每块 **1–3 句、30–70 词**，最长 ≤100；
- `**关键词**` 每项 ≤5 个词，不得整句照抄；
- 分析字段**不得出现**：`重新定义 as`、`本句描写了场景与人物的反应`、`此句通过修辞与节奏把人物的内心状态外化`；
- `check_chinese_layer` 单章密度 ≥60%、夹杂 0；
- 全书 `gate.sh` EXIT=0。

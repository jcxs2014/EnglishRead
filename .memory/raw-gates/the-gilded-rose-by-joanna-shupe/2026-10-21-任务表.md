## 全局约束（每一章都适用）

- 书目录：`notes/books/novels/the-gilded-rose-by-joanna-shupe/`
- 语料：`text/chNN_<slug>.txt`，**27 件**（ch01=Prologue … ch27=Chapter Twenty-Six）
- ⚠️ **文件号 ≠ 书内章号**：ch02=Chapter One、ch03=Chapter Two … ch27=Chapter Twenty-Six（序章占 ch01）
  ⇒ 任何跨章指认按**书内章标题**写（"Chapter Ten"），不按文件号
- 体裁：novels（言情长篇）｜双 POV：**Caroline（女主）/ Zane Bishop（男主）**
  - ⚠️ **POV 分布（2026-10-21 实测纠正）**：**大多数章是双视角**，POV 段之间有**独立成行的姓名小标题**
  （`Zane` / `Caroline` 单独一行）。**读每章时先 grep 出全部段标记**，别只看首个标题行。
  - 纯单视角：ch01/ch02/ch10/ch14/ch15/ch21/ch23 = Caroline 或 Zane（见下表）
  - 双视角：ch03–07, ch08–09, ch11–13, ch16–20, ch22, ch24–27
  - ch20 是三段：Caroline → Zane → Caroline
  - 导航「人物弧线」「情感弧线位置」要覆盖**本章出现的两个视角**（谁在本章动了、动了多少）
- 形态样板：`ch01 the courtship and the wedding night.md`
  - H1 `# NN. <书内章标题>`（**文件号**前缀 + 书内标题，如 `# 02. Chapter One`）
  - 导航 5 项：一句话概括 / 情感弧线位置 / Tropes 兑现/反转 / 人物弧线 / 叙事手法
  - 子项 4 项：中文理解 / 关键词 / 为什么这样写 / 读者视角提示
  - 词表三档：`### ⭐⭐⭐ 高级` / `### ⭐⭐ 进阶` / `### ⭐ 基础`
- **引语是句级**：每块 1–3 句、**30–70 词**、≤4 行；>100 词 chapter.sh 打 ⚠️ ⇒ 按原文句界拆
- **块数**：按本章词数定档（见下表），硬限 2–15；profile 区间 3–10，本书 4500 词以上的章走 11–12 块
  （`blocks_target` 允许；创建卡 §3「4,500 词以上最多 15 块」；profile 漂移只出提示行，不判红）
- **关键词分隔符用 ` / `**（`·` 不被 `split_keywords` 切分 ⇒ 整行只当 1 个词校验，其余词从未被验）
- **不许写模板句**（bookform TEMPLATE_PATTERNS 5 类 + 同句同字段重复 ≥3 次 = 阻断）
- 例句必须逐字取自本章 text/；词条头用本章原词形；专名保持英文不音译
- 每章：`bash scripts/chapter.sh "<章 md>"` 退出码 0
- 每批：`bash scripts/gate.sh "<书目录>"` 退出码 0
- commit：`git add <本章路径>` + `git commit -m "..." -- <本章路径>`（**禁 push**）

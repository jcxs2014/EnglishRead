# T3 深审作业单（Life Out of Order，同会话深审）

一句话：**每章四件套，先素读后开 md，铁律不许破。**

## 路径约定

- 书目录：`notes/books/novels/life-out-of-order-by-audrey-niffenegger/`
- 原文：`<书目录>/text/chNN_*.txt`（NN 两位，如 ch07）
- 精读：`<书目录>/chNN <标题>.md`（用 章号 找，**不要按文件名比**）
- 落盘：`.memory/raw-gates/life-out-of-order-by-audrey-niffenegger/review/chNN/`
  - `1-suread.json`
  - `2-machine.json`
  - `3-diff.md`
  - `4-verdict.md`

## R1 素读（只读 `text/`，此时不许打开 md）

- 5–8 条「谁做了什么」，粒度到**动作**不到气氛；人物关系、日期、数字逐字抄（`Alba is 27` 这种抬头也抄）。
- 每条带**原文字符区间**（起止 char offset 或行号 + 该句前 8 个词作锚）。
- JSON 形如：`[{"fact":"...","quote":"...","line":123}, ...]`
- **额外一句**：写完素读后，自己写一句「本章的转折点进没进这 5–8 条？没进就补一条」。

## R2 机器层（第二实现）

```bash
bash scripts/chapter.sh "<书目录>/chNN 标题.md" --json > <review>/chNN/2-machine.json
echo "rc=$?"
```

rc=0 无阻断 / 1 有阻断 / **2＝无法判定（不是通过）**。记下 rc 与关键计数（块数、引语块、查无、空引号、子项缺、关键词、密度）。

## R3 对账（此时才开 md）

三张单子，逐条写 `3-diff.md`，每条**两侧原文都贴**：

| 单 | 判据 | 档 |
|---|---|---|
| 漏 | 素读有、md 无（关键事件/转折未进任何一块或导航） | 阻断，除非 md 写明取舍理由 |
| 编 | md 有、原文无（情节/关系/数字凭空出现） | 阻断 |
| 错 | 两边都有但不一致（主语、因果、数字、时序、归属方向） | 阻断 |

## R4 逐块对应（人判，唯一不可机械化）

对每一块只问：**这段中文是不是在讲这句引语？** 再固定追三问：

1. 这块中文里**每个动词的主语是谁**？
2. **受事/宾语是谁**？
3. 「谁的 / 谁欠谁 / 谁问的」这类归属——回原文看 `by` / `to` / `from` / `of` 定方向。

⇒ 讲的是引语之外的上下文＝引语选短了；讲全书主旨/作者生平＝不对应；只复述字面＝密度不足。

## R5 判定表 `4-verdict.md`

- 表格列：`断言 | 证据（text/文件:行 + 原文逐字） | 结论 | 档位`
- 档位四选：**阻断 / 提示 / 假红 / 跳过**。报数只报四组：**逐字 / 对应 / 形态 / 断言**。
- **无原文逐字不得判阻断**。给不出逐字的写「未核」，不许写阻断。
- 「零命中 / 全书查无 / 唯一」这类断言必须附**取证命令+输出+退出码**：用 `/usr/bin/grep -nE` 或 Python 读文件；**禁用 `git grep`/rg 默认 ignore**（`text/` 被 .gitignore 排除，会假零命中）。
- 末尾固定一节「**已核实为正确**」：列出看着像错、回原文核对后成立的写法，每条给 `text/文件:行` + 原文。作用是防下一轮误修。

## 三条纪律

1. **先落盘再判**：文件写完才算判完。
2. **不许改书**：审查方只写 `review/` 下的四件套，不动 `notes/books/` 下的 md，不跑 git。
3. **不读 `scripts/` 源码**：只用脚本，不反推判据。

## 与门禁的分工（本轮实证）
- 上述两处**门禁都判绿**：`verify_quotes` 只管引语行，`check_vocab` 只查「词条用没用过」，都不校验**例句整句是否逐字**、也不查**枚举项缺一**。
- ⇒ 机器层负责「有不有、在不在」，人判负责「全不全、对应不对应」。这正是对照表第一节的分工。

# 派工模板 · the-sixth-faction-by-veronica-roth

> 每章派一个子代理起草；**只给创建卡 + 本章 text + 上游一句话概括**，不给审查表。
> 并发上限 3；批间留 30–90 秒；子代理一律不许 git 操作。

## prompt 骨架

```
你是 EnglishRead 精读库的起草者：为一章英文小说写一篇中文精读 md。**第一步必须用 read 工具读 docs/rules/创建卡.md 全文**，严格按它写（工作目录 = /Users/jcxs2014/Documents/Works/EnglishRead）。

本章原文（只读这一个文件，可 grep 它）：notes/books/novels/the-sixth-faction-by-veronica-roth/text/chNN_chapNN.txt
```

## 已踩过的坑（写进每个 prompt）

1. **词汇词头形态**：check_vocab 把整格当词头；写成 `escalate（escalating）` 会判 A 类虚构（epub 查无）。只用原文形态。
2. **短自然段**：整段 <30 词无法成块；不跨段缝合，宁可换段。
3. **关键词越界**：关键词若落在被 `…` 跳过的内容里，gate 判「关键词不成立」。
4. **块数**：本书中位 8–9、范围 6–12；chapter.sh 的建议区间是提示型，不判红。
5. **收稿后我自己要做的**：`gate.sh` **先跑再 commit**（曾在 gate 判红时先提交，靠后续 commit 修）。
6. **自己加引号**（2026-10-31，ch42 块 7）：从一段连续对白中间截断时，子代理为了让引语「看起来完整」在截断处补了一个原文没有的 `”`（原文该段还在继续 "And she'd play music…"）。chapter.sh 剥引号比对，查不出来。**正确做法**：对白中部起引就不写开引号，且只有在原文该段真有收尾引号处才能收尾；否则要么退到段末真实收尾、要么改用段末 3 句切片。收稿后跑 `/tmp/sf_quotecheck.py "<书目录>" chNN`（逐块查「原句 N」是否 text 的逐字子串，允许 `…` 分段）——它查不出「截断处补引号」，但能查出引语里夹了原文没有的字。

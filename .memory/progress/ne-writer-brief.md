## 2. 引语生产（最高优先，违者整章作废）

1. 每条引语**必须从本章 `text/` 复制**（Read 后逐字粘贴），**全章禁止出现 `…`/省略号引语**——只取原文连续段落内的完整句或完整段。
2. **写前断言**：落盘前用 Python 对每条引语执行
   `assert q in src`（`src`=本章 text 全文）；不成立就改切片，**不许改原文字形/撇号/标点来迁就**。
3. 引语**首尾落在句读边界**：`assert q[-1] in '.?!"’”'`（防「截短」——本项目第 9 类缺陷）。
4. 多段引语：只允许**原文相邻的连续多段**，同块内用 `>` 空行分隔，每段逐字。跨不相邻段落＝缺陷。
5. 引语块数：**长章（>10K 字符）8 块，中章 5–8 块，短章（<5K）3–6 块**；块须覆盖本章前/中/末段，不许全挤在前半。
6. **关键词只能从本块引语里挑**（词形原样）。

## 3. 分析层英文（第 14/19/24 类缺陷防线）

- 中文理解/为什么这样写/读者视角提示里出现的任何**作证据的英文**（≥2 词的片段）必须是**本章 `text/` 的精确子串**（`frag in src`，不是 flat 近似），并同样过写前断言。单词级引用（术语、专名）须在本章原文存在。
- 语法术语与句式记法（如 `neither…, nor…` 的并列框架说明）可豁免逐字，但**不得伪装成原文引语**。
- 释义列**纯中文**，不得含英文短语。

## 4. 词汇生产

- 跑 `python3 scripts/vocab_candidates.py "<$BOOK 绝对路径>" --ch <N> --tiers`，从输出里**粘贴选中的行、只填释义**（只做减法）。
- 三档是分类不是配额：某档不足就少列甚至留空该档 2–3 行，**禁止从记忆里补词**。
- 词头/例句必须逐字在本章（脚本产出天然满足，**不许手打誊抄**）。
- 全书通行专名（VisorForge 等）不必收词表。

## 5. 内容纪律

- 「上一章/下一章/后文如何」类指涉：**当场 grep 被指章的 `text/` 并在报告中记行号**，核不上就不写。中文式相对章号是本项目最高频缺陷。
- 计数断言（N 个词/N 次/N 段）与最高级/唯一断言：**能当场数出来才写**，写不出可复现排序就改可证措辞（禁令 2/7c）。
- 段落次序/位置断言用字符偏移取证：`src.find(A) < src.find(B)`。
- 书内没写的（人物生死、结局因果、关系名分）**不许替你的人物下结论**；导航与总结同样受此约束。
- 本章若含粗口/暴力：照原文逐字保留，不软化不改写。

## 6. 文件与交付

- 文件名：`ch<NN> <keyphrase>.md`，keyphrase 全小写、单词间单空格、无任何标点/下划线，且**全书不重名**。
- 只写你被分配的章的文件；**临时脚本一律 `/tmp/ne_<组前缀>_*` 前缀**；**禁止一切 git 写操作**（add/commit/stash 都不许）。
- 每章写完跑自检：`python3 scripts/attic/ne_strict.py "<md 文件绝对路径>"`，**阻断项必须修到 0**。
- 交付报告写 `.memory/progress/ne-<组前缀>.md`：逐章列「块数／自检阻断数／你核过行号的跨章指涉／你**不敢下判断**的清单（总览层要用）」。
- 「（另有 N 条短引语未校验）」类括号是覆盖缺口不是缺陷：**引语尽量避免 <20 字符的裸短句**；确有则回源 grep 并在报告记行号。

## 7. 你的章怎么读

用 Read 完整读你负责章的 `text/` 文件（最长 15.8K 字符，一次读完），**动笔前读该章结尾 20 行**（8.1 第 4 步）。不要读其他组的 md（在制品）；需要跨章核证时只 grep 他章 `text/`。

# Ch33 · The Ingenious Gentleman · Miguel de Cervantes

**讨论的书**：*Don Quixote*（1605）· Miguel de Cervantes
**核心叙事**：McGirr 说他**"只有一个笑话，并学会了把它用到极致"**——**"它帮我度过了无数的学校露营和远足"**——Don Quixote 是"**一本近一千页的书，围绕一个单一的笑话构建**"（a book of almost a thousand pages built around a single joke）——**这个笑话是"一个中产阶级骑士对骑士小说上瘾到脑子干了，他开始以为自己生活在一个故事里"**——风车变成巨人，农民变成王子，理发师的盆变成头盔——**"这一个笑话从不褪色"**（The one gag never stales）。

## 核心论证

1. **Don Quixote = 一个笑话的近千页**：**"Don Quixote 是一本近一千页的书，围绕一个单一的笑话构建"**——**"Don Quixote 自己就是这两样东西：一个疯狂的读者"**（Don Quixote himself was both these things: a mad reader.）——西班牙国王 Philip III 说：**"如果我看到一个人独自发笑，他要么是疯子，要么是在读《堂吉诃德》"**——**Don Quixote 的"笑话"不褪色 = "一个笑话贯穿一千页"**。
2. **Cervantes vs Shakespeare**：**"Cervantes 和 Shakespeare 1616 年在同一周去世"**——McGirr 想象 Cervantes 会笑话 Shakespeare"**写过那么多战争，而他自己真的打过仗**"**——Cervantes 在 Lepanto 战役中失去左臂的使用功能——**"如果是右臂，他可能永远写不出这部巨大的杰作，我们都会变得更穷"**。Shakespeare 写过各种监狱；Cervantes 在阿尔及利亚坐牢 5 年，被卖为奴隶。Shakespeare 可能会嘲笑 Cervantes"**破坏了他的商业模式：舞台和公共表演**"**——**"《堂吉诃德》的巨大流行在创造我们文化的一个基石方面发挥了作用——独自坐着为自己阅读消遣的人"**。
3. **Rocinante 的传统**：Don Quixote 的马叫 Rocinante——**Steinbeck 在《随查理旅行》中把他的房车叫 Rocinante**——**Graham Greene 的《蒙西诺·吉诃德》中司机的车叫 Rocinante**——**McGirr 的哥哥 Joe 把他的第一辆大众车叫 Rocinante**——**"很多人都在某个阶段车库里有一辆 Rocinante"**（A lot of people have had a Rocinante in the garage at some stage.）。
4. **Peter Steele（1939–2012）**：McGirr 与 Peter Steele 的友谊——**"Peter 是澳大利亚 20 世纪最重要的宗教诗人之一"**——**"他对 Seamus Heaney 和 Peter Porter 是重要的灵感来源"**——**他的诗"**土气的、难以捉摸的、冷僻的、幽默的、博学的、有时难以理解的、常常温柔的**"**（earthy, elusive, recherché, comic, erudite, sometimes difficult and often tender）——**Peter 把自己描述为"a broken hydrant"（"一个坏掉的水龙头"**）——**"许多夜晚你会看到 Peter 带着一篮子书退到他的房间，他的衣服在一个破旧的旧公文包里"**。
5. **"quixotification of Sancho and sanchification of Quixote"**：Peter 在 *Expatriates*（1985）中说——**"我相信 Sancho 的吉诃德化和 Quixote 的 Sancho 化"**——**"这意味着仆人需要梦想，冒险者需要服务"**——**"这意味着我们中的一些人需要下马，另一些人需要上马"**。
6. **Peter 的诗**：Peter 在弟弟去世时写了一首诗——**"没有一天不让我萦绕你的影子……我看着自己录制，嘴巴倾倒着词叠词……我感到羞愧活过了你……那里，正如你沉思的目光总是暗示的，无话可说。"**
7. **Sancho 的谜语**：一个旅行者说他要过桥去绞刑架上死——法官陷入困境——**"Sancho 纠正他们，说他自己是个笨蛋，然后说显而易见的做法是让这个人自由"**——理由是"**做好事总是比做坏事好，在怀疑的情况下，宽恕和怜悯是可取的"**——**"他用一个使人解除武装的回答击败了谜语，通过提醒他的听众生活不是一种智力练习；正义不是一种抽象的概念"**——**"如果你能在谜语中找到里面的人，那就再也不是游戏了"**。

## 选择性精读

**①** "Don Quixote is a book of almost a thousand pages built around a single joke. The one gag never stales."
- 中文理解：McGirr 说 *Don Quixote*——**"是一本近一千页的书，围绕一个单一的笑话构建。这一个笑话从不褪色。"**
- 写作技巧：**"built around a single joke" + "The one gag never stales"**——McGirr 用"**围绕一个单一的笑话构建**"和"**这一个笑话从不褪色**"这两个短语来描述 *Don Quixote* 的结构——**"近千页" = 最长的书**；**"一个单一的笑话" = 最简单的笑话**——**"最长的书 + 最简单的笑话 = 极致的对比"**——**"built around"用"围绕……构建"把"笑话"从"内容"提升到"结构"**——**"笑话不是内容，是结构 = 笑话是书的骨架"**——**"The one gag never stales"用**"从不褪色"把"笑话"从"一次"变成"永恒"**——**"一个笑话 + 永恒 = Don Quixote 的核心定义"**——**"Don Quixote = 一个笑话 + 近千页 = 一个笑话 + 永恒"**。
- 关键表达：**a book of almost a thousand pages**（"近千页的书"——**"最长"**）；**built around a single joke**（"围绕一个单一的笑话构建"——**"最简单的结构"**）；**The one gag never stales**（"这一个笑话从不褪色"——**"永恒的笑话"**）——**本章对 *Don Quixote* 的核心定义**：**"一个笑话 + 近千页 + 永恒 = Don Quixote"**。
- 可迁移：**用"围绕 X 构建"描述"一个结构"**——"围绕一个单一的笑话构建 = Don Quixote 的骨架"。

**②** "If he saw a person laughing alone, they were either mad or reading Don Quixote."
- 中文理解：西班牙国王 Philip III 说——**"如果我看到一个人独自发笑，他要么是疯子，要么是在读《堂吉诃德》。"**
- 写作技巧：**"laughing alone" + "either mad or reading Don Quixote"**——Philip III 用"**独自发笑**"和"**要么是疯子，要么是在读《堂吉诃德》**"这两个短语来描述"《堂吉诃德》的读者"**——**"独自发笑" = 单独发笑 = 没有观众**；**"疯子" = 不正常**；**"读《堂吉诃德》" = 阅读"**——**"独自发笑 = 疯子 = 读《堂吉诃德》"用"**要么是……要么是**"把"独自发笑"从"不正常"变成"阅读"**——**"读《堂吉诃德》 = 独自发笑 = 阅读从"集体"变成"个人"**——**"《堂吉诃德》的巨大流行在创造我们文化的一个基石方面发挥了作用——独自坐着为自己阅读消遣的人"用**"独自坐着为自己阅读消遣"把"《堂吉诃德》"从"一本书"提升到"一种文化"**——**"《堂吉诃德》 = 独自阅读 = 我们文化的基石"**——**"Philip III 说'要么疯，要么读《堂吉诃德》' = 读《堂吉诃德》 = 疯 = 独自发笑 = 我们文化的基石"**。
- 关键表达：**laughing alone**（"独自发笑"——**"独自阅读"的标志**）；**either mad or reading Don Quixote**（"要么是疯子，要么是在读《堂吉诃德》"——**Philip III 的核心定义**）——**本章对 *Don Quixote* 的核心定义**：**"《堂吉诃德》 = 独自发笑 = 独自阅读 = 我们文化的基石"**。
- 可迁移：**用"要么 X 要么 Y"描述"一个人的行为"**——"要么疯，要么读《堂吉诃德》"。

**③** "If it had been his right arm, he might never have composed his enormous masterpiece and we would all be much poorer."
- 中文理解：McGirr 说 Cervantes——**"如果是他的右臂，他可能永远写不出这部巨大的杰作，我们都会变得更穷。"**
- 写作技巧：**"If it had been his right arm" + "we would all be much poorer"**——McGirr 用"**如果是他的右臂**"和"**我们都会变得更穷**"这两个假设句来描述 Cervantes 的"幸存"**——**"如果是右臂" = 右臂受伤 = 无法写作**；**"如果是右臂" = 无法写作 = 没有《堂吉诃德》 = "我们都会变得更穷"**——**"我们都会变得更穷"用**"我们都会"把"《堂吉诃德》"从"Cervantes 的"变成"我们的"**——**"《堂吉诃德》 = 我们的 = 全世界的文学遗产"**——**"Cervantes 的右臂 = 我们的文学 = 《堂吉诃德》 = 全世界的财富"**——**"Cervantes 的左臂幸存 = 我们的右臂幸存 = 《堂吉诃德》 = 全世界的财富"**。
- 关键表达：**If it had been his right arm**（"如果是他的右臂"——**"假设"**）；**enormous masterpiece**（"巨大的杰作"——**《堂吉诃德》**）——**本章对 Cervantes 的核心定义**：**"Cervantes 的左臂幸存 = 我们的右臂幸存 = 《堂吉诃德》 = 全世界的财富"**。
- 可迁移：**用"如果是 X，我们都会 Y"描述"幸存的意义"**——"如果是他的右臂，我们都会变得更穷"。

**④** "Peter described himself as a celebrant of life, which meant that he understood humans are essentially laughable."
- 中文理解：Peter Steele 把自己描述为——**"生命的庆祝者，这意味着他理解人类本质上是可笑的。"**
- 写作技巧：**"a celebrant of life" + "humans are essentially laughable"**——Peter 用"**生命的庆祝者**"和"**人类本质上是可笑的**"这两个短语来描述 Peter 的核心信念——**"生命的庆祝者" = 赞美生命 = 生命的赞美者**；**"人类本质上是可笑的" = 人类 = 可笑**——**"庆祝生命 = 理解人类是可笑的"**——**"庆祝" = 理解"可笑"**——**"庆祝" = 承认 = 承认人类可笑 = 庆祝生命"**——**"Peter 的'庆祝生命' = Peter 的'理解人类可笑' = Peter 的'幽默哲学'"**——**"你听到 Chesterton 的欢乐悖论在 Peter 的散文中的回声"用**"欢乐悖论"把 Peter 从"个人"连接到"Chesterton"**——**"Peter = Chesterton 的继承者 = 欢乐悖论 = 庆祝生命 = 理解人类可笑"**。
- 关键表达：**a celebrant of life**（"生命的庆祝者"——**Peter 的自我描述**）；**humans are essentially laughable**（"人类本质上是可笑的"——**Peter 的核心信念**）——**本章对 Peter Steele 的核心定义**：**"生命的庆祝者 = 理解人类本质上是可笑的 = 欢乐悖论"**。
- 可迁移：**用"X 的庆祝者"描述"一个哲学立场"**——"生命的庆祝者 = 理解人类可笑"。

**⑤** "In Expatriates, Peter said that he believed in 'the quixotification of Sancho and the sanchification of Quixote'. This means, I think, that the servant needs to dream and the adventurer needs to serve."
- 中文理解：Peter 在 *Expatriates* 中说——**"我相信 Sancho 的吉诃德化和 Quixote 的 Sancho 化。这意味着仆人需要梦想，冒险者需要服务。"**
- 写作技巧：**"the quixotification of Sancho" + "the sanchification of Quixote"**——Peter 用**"Sancho 的吉诃德化"和"Quixote 的 Sancho 化"**这两个"化"的短语来描述 Peter 的核心哲学——**"Sancho = 仆人 = 需要梦想 = 吉诃德化 = 冒险"**；**"Quixote = 冒险者 = 需要服务 = Sancho 化 = 谦逊"**——**"仆人 + 冒险 = 吉诃德化；冒险者 + 服务 = Sancho 化"**——**"吉诃德化 + Sancho 化 = 互补 = 互补的哲学"**——**"这意味着我们中的一些人需要下马，另一些人需要上马"用**"下马"和"上马"把"吉诃德化 + Sancho 化"从"抽象"变成"具体"**——**"下马" = 谦逊 = 服务；"上马" = 冒险 = 梦想**——**"需要下马的人" = 骄傲的冒险者；"需要上马的人" = 卑微的仆人**——**"Peter 的核心哲学 = 每个人都需要'互补'的另一半 = 吉诃德 + Sancho = 一个完整的人"**。
- 关键表达：**the quixotification of Sancho**（"Sancho 的吉诃德化"——**"仆人需要梦想"**）；**the sanchification of Quixote**（"Quixote 的 Sancho 化"——**"冒险者需要服务"**）——**本章对 Peter 哲学的核心定义**：**"仆人需要梦想 + 冒险者需要服务 = 吉诃德化 + Sancho 化 = 互补的哲学"**。
- 可迁移：**用"X 的 Y 化"描述"一种互补的哲学"**——"Sancho 的吉诃德化 = 仆人需要梦想"。

**⑥** "He defeats the riddle by reminding his listeners that life is not an intellectual exercise; justice is not an abstract notion. If you can find the person inside the riddle, it isn't a game anymore."
- 中文理解：McGirr 描述 Sancho 的谜语——**"他用一个使人解除武装的回答击败了谜语，通过提醒他的听众生活不是一种智力练习；正义不是一种抽象的概念。如果你能在谜语中找到里面的人，那就再也不是游戏了。"**
- 写作技巧：**"life is not an intellectual exercise" + "justice is not an abstract notion" + "If you can find the person inside the riddle, it isn't a game anymore"**——McGirr 用**三个"不是"的短语**来描述 Sancho 的"谜语哲学"**——**"生活不是一种智力练习" = "谜语" = "生活"的反面**；**"正义不是一种抽象的概念" = "抽象" = "具体"的反面**；**"如果你能在谜语中找到里面的人，那就再也不是游戏了" = "游戏" = "现实"的反面**——**"三个反面 = Sancho 的哲学 = 现实 > 抽象 = 人 > 谜语 = 游戏 = 现实"**——**"Sancho 纠正他们，说他自己是个笨蛋，然后说显而易见的做法是让这个人自由"用**"显而易见的做法"把"Sancho 的智慧"从"聪明"变成"显而易见"**——**"显而易见的智慧" = "最深刻的智慧" = "Sancho 的智慧"**——**"做好事总是比做坏事好，在怀疑的情况下，宽恕和怜悯是可取的"用**"做好事 > 做坏事"和"宽恕和怜悯"把"Sancho 的智慧"从"逻辑"变成"伦理"**——**"伦理 > 逻辑 = Sancho 的智慧"**。
- 关键表达：**life is not an intellectual exercise**（"生活不是一种智力练习"——**"谜语"的反面**）；**justice is not an abstract notion**（"正义不是一种抽象的概念"——**"抽象"的反面**）——**本章对 Sancho 哲学的核心定义**：**"生活不是智力练习 + 正义不是抽象概念 = 如果你在谜语中找到人，那就再也不是游戏了"**。
- 可迁移：**用"X 不是 Y"描述"一个哲学立场"**——"生活不是智力练习 = 伦理 > 逻辑"。

## 一句话总结

**"Don Quixote 是一个单一的笑话构建的近千页"**——Cervantes 的左臂幸存 = "**我们都会变得更穷**"；Peter Steele 说"**生命的庆祝者 = 理解人类本质上是可笑的**"；"**仆人需要梦想，冒险者需要服务**"——**"如果你在谜语中找到人，那就再也不是游戏了"**。

# Ch38 · Souvlaki · Homer

**讨论的书**：*The Iliad*, Book 24（第八世纪 bce）· Homer
**核心叙事**：McGirr 说 humbles souvlaki（希腊烤肉串）——**"卑微的 souvlaki 在历史中有一个可敬的地位。它是所有文学中最伟大时刻之一的支点"**（the pivot on which turns one of the great moments in all literature）。*Iliad* 最后一章，**"整个世界都筋疲力尽"**（the whole world is exhausted）——**"在西方叙事史上这么早达到这个最低点是令人不舒服的"**。Achilles 杀死 Hector 后进行了 12 天侮辱尸体——**然后 Troy 国王 Priam 独自去 Achilles 的帐篷请求带回儿子的遗体**——**"在最关键时刻，Achilles 给了 Priam 一个 souvlaki——羊肉，在烤架上旋转烤制，切成小块，放在面包里。两个男人第一次重新品尝食物。他们开始从悲伤中回家的漫长旅程。他们成了朋友。卑微的 souvlaki 取得了和任何帝国盛宴一样多的成就。"**

## 核心论证

1. **"Rage"（"愤怒"**）**：*Iliad* 的第一个词是"愤怒"——**"Robert Fagles 当代翻译的第一词是'Rage'；18 世纪 Pope 翻译的第一词是'Wrath'"**——**"不容易错过这个信息"**——**"*Iliad* 谈论每一次战斗过的战争和每一次家庭暴力场景"**——**"它处理愤怒和暴力，特别是男性的愤怒和男性的暴力——它们把人类历史推入无数悲剧"**。
2. **Achilles 的愤怒 = "构造力"**：Achilles 是神的母亲 Thetis 和凡人父亲 Peleus 的儿子——**"Achilles 的愤怒是这首诗的发动机"**——Patroclus 死在 Hector 手里，**"Achilles 与 Hector 战斗并杀死了他。仅仅杀死还不够"**——**"十二天，Achilles 对 Hector 的尸体进行侮辱——他把 Hector 的尸体拖在战车后面一圈又一圈——毫无疑问希望他复活这样他可以再杀他一次"**。
3. **"Achilles = 被困在可耻的小男子气概形象中"**：**"Achilles 被可耻的小男子气概形象困住了"**（Achilles has been trapped in a pathetically small image of masculinity）——Priam 的赤手空拳打破了 Achilles 的防御——**"Achilles 被解脱了"**——**"Priam 让他想起了自己的父亲——他 10 年没见到的父亲"**。
4. **"The whole world is now tired of conflict"**：**"整个世界现在厌倦了冲突和侵略"**——**"它对男人 macho 姿态和肌肉展示感到心满意足地厌恶"**——**"它需要一些不同的东西，谦卑打破了僵局"**。
5. **Homer 的"口述传统"**：**"在口述传统中……讲故事者有一种神圣的信任。他们不觉得可以自由摆弄自己的材料"**——但 **The Iliad"距离它的源头还很远"**——**"《伊利亚特》之所以能生存这么久，不是因为它是某种轻娱乐或甚至是历史传奇——而是因为它找到了故事的力量对社区自身的生存是必要的"**。
6. **"Homer Simpson = 反英雄"**：McGirr 说 **Homer Simpson 是一切"原来的 Homer 不是"的东西**——**"Homer Simpson 是没有宏大叙事的核心英雄。他是核电站的安保主管——他可能把世界的未来掌握在他笨拙且容易出事故的手中。但 Homer Simpson 没有能力停下来想知道那可能意味着什么——这就是为什么他如此令人痛苦地好笑"**。
7. **Adam Nicolson 的"Homer 记忆"**：**"Homer 充满了那个北方过去的半掩埋的记忆——一个远离水、远离城市、封闭在陆地、被巨大的天空主导、马富、专注于畜群和羊群以及它们提供的肉的世界——暴力、流动和英雄的"**。

## 选择性精读

**①** "The humble souvlaki has a venerable place in history. It is the pivot on which turns one of the great moments in all literature."
- 中文理解：McGirr 说——**"卑微的 souvlaki 在历史中有一个可敬的地位。它是所有文学中最伟大时刻之一的支点。"**
- 写作技巧：**"the humble souvlaki" + "the pivot"**——McGirr 用"**卑微的 souvlaki**"和"**支点**"这两个短语的对比来描述 souvlaki 的地位——**"卑微" = 不值钱 = 街头小吃**；**"支点" = 关键 = 伟大**——**"卑微 + 支点 = 伟大的卑微 = McGirr 的核心定义"**——**"在历史中有一个可敬的地位"用**"可敬"把"souvlaki"从"小吃"提升到"历史地位"**——**"所有文学中最伟大时刻之一的支点"用**"支点"把"souvlaki"从"食物"提升到"文学的关键时刻"**——**"卑微的 souvlaki = 支点 = 所有文学中最伟大时刻"**——**"两个男人第一次重新品尝食物"用**"重新品尝食物"把"souvlaki"从"食物"变成"和解的象征"**——**"souvlaki = 食物的重新品尝 = 和解 = 朋友的开始 = 所有文学中最伟大时刻"**。
- 关键表达：**the humble souvlaki**（"卑微的 souvlaki"——**"卑微"的食物**）；**the pivot on which turns**（"支点"——**"伟大"的关键**）——**本章对 souvlaki 的核心定义**：**"卑微的 souvlaki = 支点 = 所有文学中最伟大时刻 = 食物的重新品尝 = 和解"**。
- 可迁移：**用"X 的 Y"描述"一种矛盾的伟大"**——"卑微的 souvlaki = 支点 = 伟大"。

**②** "The opening word of Robert Fagles' contemporary translation is 'Rage'. The first word of the eighteenth-century translation by Alexander Pope is 'Wrath'."
- 中文理解：McGirr 说——**"Robert Fagles 当代翻译的第一个词是'Rage'。18 世纪 Alexander Pope 翻译的第一个词是'Wrath'。"**
- 写作技巧：**"Rage" + "Wrath"**——McGirr 用**"Rage"和"Wrath"**这两个几乎同义词的并列来描述 *Iliad* 的第一词——**"Rage" = 愤怒 = 现代**；**"Wrath" = 愤怒 = 古典**——**"Rage 和 Wrath" = 同一个意思 + 两个时代 = 《Iliad》的"永恒主题"**——**"不容易错过这个信息"用**"不容易错过"把"第一个词"从"细节"提升到"核心主题"**——**"《Iliad》谈论每一次战斗过的战争和每一次家庭暴力场景"用**"每一次"把"愤怒"从"战争"扩展到"家庭暴力"**——**"它处理愤怒和暴力，特别是男性的愤怒和男性的暴力"用**"特别是"把"愤怒"从"一般"集中到"男性"**——**"男性的愤怒和男性的暴力" = 《Iliad》的核心 = "男性愤怒 = 历史悲剧"**。
- 关键表达：**Rage**（"愤怒"——**Fagles 翻译**）；**Wrath**（"愤怒"——**Pope 翻译**）——**本章对 *Iliad* 的核心定义**：**"Rage = Wrath = 男性愤怒 = 历史悲剧 = 《Iliad》"**。
- 可迁移：**用"X 和 Y"的并列描述"一个永恒的主题"**——"Rage 和 Wrath = 男性的愤怒 = 《Iliad》"。

**③** "For twelve days, Achilles performs desecrations on the body of Hector. He drags the corpse of Hector around and around behind his chariot, no doubt hoping he could come back to life so he could kill him again."
- 中文理解：McGirr 说——**"十二天，Achilles 对 Hector 的尸体进行侮辱。他把 Hector 的尸体拖在战车后面一圈又一圈，毫无疑问希望他复活这样他可以再杀他一次。"**
- 写作技巧：**"performs desecrations" + "drags the corpse around and around" + "hoping he could come back to life"**——McGirr 用**"进行侮辱"和"拖在战车后面一圈又一圈"和"希望他复活"**这三个短语来描述 Achilles 的"愤怒"**——**"进行侮辱" = 对尸体的亵渎 = Achilles 的"愤怒"**；**"拖在战车后面一圈又一圈" = 身体的暴力 = Achilles 的"无尽的复仇"**；**"希望他复活这样他可以再杀他一次" = 复仇的极致 = Achilles 的"永不满足"**——**"亵渎 + 拖拽 + 无尽的复仇 = Achilles 的愤怒"**——**"Hector 的尸体被奇迹般地保护"用**"奇迹般地保护"把"Hector"从"死者"变成"神圣"**——**"Hector 的尊严 = 尸体的奇迹保护 = 神的力量"**——**"Achilles 的愤怒越强 = Achilles 越无能为力"用**"越强 = 越无能为力"把"Achilles"从"强大"变成"无能为力"**——**"Achilles 无法睡觉。他失去了食欲。他的食物没有味道"用**"无法睡觉"、"失去食欲"、"食物没有味道"**把"Achilles"从"战士"变成"病人"**。
- 关键表达：**performs desecrations**（"进行侮辱"——**Achilles 的"愤怒"**）；**drags the corpse around and around**（"拖在战车后面一圈又一圈"——**Achilles 的"复仇"**）；**the corpse is miraculously protected**（"尸体被奇迹般地保护"——**Hector 的"尊严"**）——**本章对 Achilles 的核心定义**：**"亵渎 + 拖拽 + 无尽的复仇 = Achilles 的愤怒 = 越强 = 越无能为力"**。
- 可迁移：**用"X 越强 = Y 越 Z"描述"一种矛盾"**——"Achilles 的愤怒越强 = Achilles 越无能为力"。

**④** "Achilles has been trapped in a pathetically small image of masculinity."
- 中文理解：McGirr 说 Achilles——**"Achilles 被可耻的小男子气概形象困住了。"**
- 写作技巧：**"pathetically small image of masculinity"**——McGirr 用"**可耻的小男子气概形象**"这个"矛盾组合"来描述 Achilles 的"困境"**——**"pathetically" = 可耻的 = 可怜**；**"small" = 小的 = 狭隘**；**"image of masculinity" = 男子气概的形象 = Achilles 的自我**——**"可耻的 + 小的 + 男子气概的形象" = Achilles 的"自我" = "可耻的狭隘的男子气概"**——**"Priam 让他想起了自己的父亲"用**"Priam 让他想起自己的父亲"把"Achilles"从"战士"变成"儿子"**——**"Priam 的赤手空拳打破了 Achilles 的防御"用**"赤手空拳"把"胜利"从"暴力"变成"谦卑"**——**"Achilles 被解脱了"用**"被解脱"把"Achilles"从"困住"变成"自由"**——**"Achilles = 被可耻的小男子气概困住 = Priam 的赤手空拳 = Achilles 的自由"**。
- 关键表达：**pathetically small image of masculinity**（"可耻的小男子气概形象"——**Achilles 的"困境"**）；**Achilles is relieved**（"Achilles 被解脱了"——**Achilles 的"自由"**）——**本章对 Achilles 的核心定义**：**"可耻的小男子气概 = Priam 的赤手空拳 = Achilles 的自由"**。
- 可迁移：**用"被 X 困住"描述"一种困境"**——"Achilles 被可耻的小男子气概困住"。

**⑤** "It needs something different and humility breaks the deadlock."
- 中文理解：McGirr 说——**"它需要一些不同的东西，谦卑打破了僵局。"**
- 写作技巧：**"something different" + "humility breaks the deadlock"**——McGirr 用**"一些不同的东西"和"谦卑打破了僵局"**这两个短语来描述 Priam 的"解决方案"**——**"一些不同的东西" = 谦卑 = 反 macho = 反暴力 = 反肌肉展示**——**"humility" = 谦卑 = Priam 的"武器"**；**"breaks the deadlock" = 打破僵局 = Priam 的"胜利"**——**"谦卑 = 打破僵局 = Priam 的"胜利"**——**"整个世界现在厌倦了冲突和侵略"用**"厌倦了"把"整个世界"从"战场"变成"疲劳的观众"**——**"它对男人 macho 姿态和肌肉展示感到心满意足地厌恶"用**"心满意足地厌恶"把"整个世界"从"疲劳"变成"主动拒绝"**——**"整个世界 = 厌倦 = 主动拒绝 macho = 谦卑打破僵局"**。
- 关键表达：**something different**（"一些不同的东西"——**"反 macho"**）；**humility breaks the deadlock**（"谦卑打破了僵局"——**Priam 的"胜利"**）——**本章对"整个世界的状态"的核心定义**：**"整个世界 = 厌倦冲突 = 主动拒绝 macho = 谦卑打破僵局"**。
- 可迁移：**用"X 打破了 Y"描述"一种解决方案"**——"谦卑打破了僵局 = Priam 的胜利"。

**⑥** "The humble souvlaki achieved as much as did any imperial banquet in history."
- 中文理解：McGirr 总结——**"卑微的 souvlaki 取得了和任何帝国盛宴一样多的成就。"**
- 写作技巧：**"the humble souvlaki" + "as much as any imperial banquet"**——McGirr 用"**卑微的 souvlaki**"和"**任何帝国盛宴**"这两个短语的对比来描述 souvlaki 的"成就"**——**"卑微的 souvlaki" = 街头小吃 = 不值钱**；**"任何帝国盛宴" = 帝国 = 最贵**——**"卑微的 souvlaki = 帝国盛宴" = 卑微 = 伟大 = McGirr 的核心结论"**——**"as much as"用**"一样多"把"souvlaki"从"小吃"提升到"帝国盛宴"**——**"卑微的 souvlaki = 帝国盛宴 = 一样多的成就"**——**"两个男人第一次重新品尝食物"用**"重新品尝食物"把"souvlaki"从"食物"变成"和解"**——**"他们开始从悲伤中回家的漫长旅程。他们成了朋友"用**"回家的漫长旅程"和"成了朋友"把"souvlaki"从"食物"变成"和解"和"友谊"**——**"卑微的 souvlaki = 和解 + 友谊 = 帝国盛宴 = 一样多的成就"**。
- 关键表达：**the humble souvlaki**（"卑微的 souvlaki"——**"卑微"的食物**）；**as much as any imperial banquet**（"和任何帝国盛宴一样多"——**"伟大"的成就**）——**本章对 souvlaki 的核心定义**：**"卑微的 souvlaki = 帝国盛宴 = 和解 + 友谊 = 一样多的成就"**。
- 可迁移：**用"X 和 Y 一样多的 Z"描述"一种对比的成就"**——"卑微的 souvlaki 和帝国盛宴一样多的成就"。

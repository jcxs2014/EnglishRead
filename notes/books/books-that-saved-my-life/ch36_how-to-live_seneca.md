# Ch36 · How to Live · Seneca

**讨论的书**：*On the Shortness of Life*（c. 55 ce）· Seneca
**核心叙事**：McGirr 说拉丁语——**"琐碎的思想在拉丁语中听起来更好。这是让这种语言在最后一个角斗士咽气数百年后仍然活着的原因之一"**（It's one thing that keeps the language alive so many centuries after the last gladiator bit the dust.）。McGirr 最喜爱的拉丁谚语是一位老修女给他的——**"omni quique proprius stercus bene olet"——"对每个人来说，他们自己的屎闻起来最好"**——**"我一直以来都努力实现这一点"**（I have always tried to live up to that）。McGirr 16 岁时在 Tyrell's Bookshop 花了 1 美元买了一本 *Latin Elegy, Lyric and Epigram*，在其中发现了 Seneca 的句子——**"Omnia mors poscit. Lex est, non poena, perire."**——**"死亡拥有一切。毁灭是法律，不是惩罚。"**——**"Seneca 是'一个让我灵魂味蕾振奋的人，就像第一次尝到发霉的奶酪'"**——McGirr 爱上了"对苍凉做作的喜爱"。

## 核心论证

1. **"琐碎的思想在拉丁语中听起来更好"**：**"拉丁语对讨论电脑问题、火箭科学或干洗并不擅长"**——但**"当涉及到'尽力而为'或'寻求真理'这样崇高的情感时，没有什么比拉丁语更好"**——**"说'克服困难'是一回事，而说 *per ardua ad astra*（穿过逆境到达星辰）是另一回事"**——**"拉丁语的陈词滥调从不听起来像陈词滥调——它们听起来像纹章的一部分"**。
2. **"stercus"谚语**：老修女给 McGirr 的谚语——**"omni quique proprius stercus bene olet"（"对每个人来说，他们自己的屎闻起来最好"）**——**"我一直以来都努力实现这一点"**——**"这是对'自我'的自嘲式描述"——"每个人都觉得自己最好"——"修女用拉丁语说脏话 = 智慧"**。
3. **"Latin Elegy"中的 Seneca 句子**：McGirr 在 1 美元的旧书中发现——**"Omnia mors poscit. Lex est, non poena, perire."（"死亡拥有一切。毁灭是法律，不是惩罚。"）**——**"这些字让 McGirr 的灵魂味蕾振奋——就像第一次尝到发霉的奶酪"**——**"他爱上了'对苍凉做作的喜爱'"**（the affectation of bleakness）——**"McGirr 是错误的——关于他自己和关于 Seneca"**。
4. **Seneca 的死**：Seneca（4 bce–65 ce）——哲学家和剧作家——**"他的前学生、皇帝尼禄命令他自杀"**——Seneca "**几乎不可能杀死**"**——他**"幸存了多次尝试，包括割腕、割腿和毒药，最后被蒸汽闷死"**——**"他会让拉辛（Rasputin）也竞争一下"**——**"尽管他一生身体脆弱，但 Seneca 却几乎不可能被杀死"**。
5. **"On the Shortness of Life"**：Seneca 最被记住的作品是 *On the Shortness of Life*——**"恰如其标题，它很简短。它是在同一十年、同一地点（罗马）写的，与另一篇简短的作品——《马可福音》"**——**两者都部分处理了"一个破坏性政治领袖的影响——尼禄"**——**"Mark 让人们坚持和忍耐；Seneca 让人们放手——因为一切很快就会结束。你会期待相反。"**
6. **Stoicism（斯多葛主义）**：**"我们今天所说的'stoic'是指他们断了手臂还在踢足球。更好的词是'stupid'"**——**"Stoicism 不是关于否认真实的痛苦、真实的焦虑、真实的悲伤或任何真实的东西"**——**"它是关于用心智不去改变现实而是通过把它放在更广阔的语境中来应对现实"**——**"当然，这有改变现实的效果，因为我们就是现实的一部分，如果我们改变自己，我们就改变了世界，至少在小范围上"**。
7. **Seneca 的《On the Shortness of Life》**：Seneca 一生与不合作的肺战斗——**他患有严重的哮喘和支气管炎**——**"咳嗽和喘息成了他的名片"**——**"他成年生活的很大一部分都在几下心跳内"**——**"Seneca 本可以写一本叫《On the Shortness of Breath》（论呼吸的短暂）的书"**。

## 选择性精读

**①** "Trivial ideas sound better in Latin."
- 中文理解：McGirr 说——**"琐碎的思想在拉丁语中听起来更好。"**
- 写作技巧：**"trivial ideas" + "sound better in Latin"**——McGirr 用"**琐碎的思想**"和"**在拉丁语中听起来更好**"这两个短语来描述拉丁语的功能——**"trivial" = 琐碎的 = 不值钱**；**"sound better" = 听起来更好 = 被美化**——**"琐碎的思想 + 拉丁语 = 听起来更好 = 拉丁语的美化功能"**——**"拉丁语对讨论电脑问题、火箭科学或干洗并不擅长"用**"对……并不擅长"把"拉丁语"从"万能"变成"有限的"**——**"拉丁语 ≠ 实用语言 = 情感语言"**——**"当涉及到'尽力而为'或'寻求真理'这样崇高的情感时，没有什么比拉丁语更好"用**"没有什么比拉丁语更好"把"拉丁语"从"有限的"变成"崇高的"**——**"拉丁语 = 不擅长实用 + 擅长崇高 = 拉丁语的定位"**。
- 关键表达：**trivial ideas**（"琐碎的思想"——**被美化的对象**）；**sound better in Latin**（"在拉丁语中听起来更好"——**本章的标题**）——**本章对拉丁语的核心定义**：**"琐碎的思想 + 拉丁语 = 听起来更好 = 拉丁语的美化功能"**。
- 可迁移：**用"X 在 Y 中听起来更好"描述"语言的美化功能"**——"琐碎的思想在拉丁语中听起来更好"。

**②** "Omni quique proprius stercus bene olet."
- 中文理解：老修女给 McGirr 的谚语——**"对每个人来说，他们自己的屎闻起来最好。"**
- 写作技巧：**"proprius stercus bene olet"**——谚语用**"自己的屎闻起来最好"**这个"粗俗的身体比喻"来描述"自我中心"**——**"proprius" = 自己的 = 个人的**；**"stercus" = 屎 = 最脏的**；**"bene olet" = 闻起来好 = 香**——**"自己的屎闻起来最好" = "自己最香 = 自我中心 = 每个人都觉得自己最好"**——**"修女用拉丁语说脏话"用**"修女用拉丁语"把"脏话"从"低俗"提升到"智慧"**——**"修女 = 圣洁 = 拉丁语 = 最脏的词 = 智慧"**——**"圣洁的修女 + 最脏的拉丁词 = 智慧 = McGirr 的老师"**——**"McGirr 说'我一直以来都努力实现这一点'"用**"努力实现"把"谚语"从"描述"变成"承诺"**——**"McGirr = 努力实现"自己的屎闻起来最好" = McGirr 的自我中心"**。
- 关键表达：**proprius stercus**（"自己的屎"——**本章最脏的词**）；**bene olet**（"闻起来最好"——**"屎"的赞美**）——**本章对"谚语"的核心定义**：**"自己的屎闻起来最好 = 每个人都觉得自己最好 = 自我中心 = 智慧"**。
- 可迁移：**用"X 的 Y 闻起来 Z"描述"自我中心"**——"自己的屎闻起来最好 = 每个人都觉得自己最好"。

**③** "Omnia mors poscit. Lex est, non poena, perire."
- 中文理解：Seneca 在 *Latin Elegy* 中的句子——**"死亡拥有一切。毁灭是法律，不是惩罚。"**
- 写作技巧：**"Omnia mors poscit" + "Lex est, non poena, perire"**——Seneca 用**"死亡拥有一切"和"毁灭是法律，不是惩罚"**这两个短语来描述"死亡的本质"**——**"Omnia mors poscit" = "死亡" = "拥有" = "一切"**；**"Lex est" = "法律" = 自然法则**；**"non poena" = "不是惩罚" = 道德判断的反面**——**"毁灭是法律，不是惩罚" = "死亡 = 自然法则 = 不是道德审判"**——**"McGirr 的灵魂味蕾振奋"用**"味蕾振奋"把"Seneca 的句子"从"文字"变成"食物"**——**"就像第一次尝到发霉的奶酪"用**"发霉的奶酪"把"Seneca 的句子"从"文字"变成"味觉"**——**"味蕾振奋 = 发霉的奶酪 = Seneca 的句子 = 16 岁的 McGirr 的'启蒙'"**——**"McGirr 爱上了'对苍凉做作的喜爱'"用**"对苍凉做作的喜爱"把"16 岁的 McGirr"从"学生"变成"模仿者"**——**"16 岁的 McGirr = 苍凉做作的模仿者 = Seneca 的模仿者"**——**"但 McGirr 是错误的——关于他自己和关于 Seneca"**——**"16 岁的 McGirr = 苍凉做作的模仿者 = 错误"**。
- 关键表达：**Omnia mors poscit**（"死亡拥有一切"——**Seneca 的第一句**）；**Lex est, non poena, perire**（"毁灭是法律，不是惩罚"——**Seneca 的第二句**）——**本章对 Seneca 的核心定义**：**"死亡拥有一切 = 毁灭是法律，不是惩罚 = McGirr 的灵魂味蕾振奋"**。
- 可迁移：**用"X 是 Y，不是 Z"描述"一种本质"**——"毁灭是法律，不是惩罚"。

**④** "He survived several attempts, including wrist-slashing, leg-slashing and poison, before he was suffocated in steam."
- 中文理解：McGirr 说 Seneca——**"他幸存了多次尝试，包括割腕、割腿和毒药，最后被蒸汽闷死。"**
- 写作技巧：**"survived several attempts" + "wrist-slashing, leg-slashing and poison" + "suffocated in steam"**——McGirr 用**"幸存多次尝试"和"割腕、割腿、毒药"和"蒸汽闷死"**这三个短语来描述 Seneca 的"几乎不可能杀死"**——**"割腕、割腿、毒药" = "三种自杀方式 = Seneca 的三次幸存"**——**"幸存" = 没死 = Seneca 的"生命力"**——**"最后被蒸汽闷死"用**"蒸汽闷死"把"Seneca"从"幸存者"变成"最终的死者"**——**"蒸汽闷死" = 最奇怪的死法 = Seneca 的"戏剧性死亡"**——**"他会让拉辛（Rasputin）也竞争一下"用**"拉辛"把"Seneca"从"哲学家"变成"不朽的幸存者"**——**"Seneca = 拉辛 = 不死之身 = 最后被蒸汽闷死"**——**"尽管他一生身体脆弱"用**"一生身体脆弱"把"Seneca"从"强壮"变成"脆弱"**——**"Seneca = 一生身体脆弱 + 几乎不可能杀死 = Seneca 的悖论"**。
- 关键表达：**survived several attempts**（"幸存多次尝试"——**Seneca 的"生命力"**）；**wrist-slashing, leg-slashing and poison**（"割腕、割腿、毒药"——**三种自杀方式**）；**suffocated in steam**（"蒸汽闷死"——**最终的死法**）——**本章对 Seneca 的核心定义**：**"一生身体脆弱 + 幸存多次 + 最后被蒸汽闷死 = Seneca 的悖论"**。
- 可迁移：**用"X 让 Y 也竞争一下"描述"一种极端的比较"**——"Seneca 让拉辛也竞争一下 = 不死之身"。

**⑤** "Mark asks people to hold on and endure. Seneca asks them to let go because it will all soon be over. You'd expect it to be the other way around."
- 中文理解：McGirr 对比 Seneca 和 Mark——**"Mark 让人们坚持和忍耐。Seneca 让人们放手，因为一切很快就会结束。你会期待相反。"**
- 写作技巧：**"Mark asks...to hold on and endure" + "Seneca asks...to let go" + "You'd expect it to be the other way around"**——McGirr 用**"Mark 让人们坚持"和"Seneca 让人们放手"和"你会期待相反"**这三个短语来描述 Seneca 和 Mark 的"对比"**——**"Mark" = 基督教 = "坚持和忍耐" = 未来的希望**；**"Seneca" = 斯多葛 = "放手" = 当下的接受**——**"坚持和忍耐" = 未来的希望 = 基督教的核心**；**"放手" = 当下的接受 = 斯多葛的核心**——**"你会期待相反"用**"你会期待相反"把"Seneca"从"基督教"变成"斯多葛"**——**"Seneca 是基督教的反面 = 斯多葛 = 放手"**——**"Mark = 坚持；Seneca = 放手 = 你期待相反 = 事实相反 = 基督教和斯多葛的对比"**。
- 关键表达：**hold on and endure**（"坚持和忍耐"——**Mark 的核心**）；**let go**（"放手"——**Seneca 的核心**）——**本章对 Seneca vs Mark 的核心定义**：**"Mark = 坚持；Seneca = 放手 = 你会期待相反 = 事实相反"**。
- 可迁移：**用"X 让人们 Y；Z 让人们 W = 你期待相反"描述"一种对比"**——"Mark 让人们坚持；Seneca 让人们放手 = 你期待相反"。

**⑥** "Stoicism is not about the denial of real pain, real anxiety, real grief or, indeed, anything real. It is about using the mind not to change reality but to deal with it by placing it in a broader context."
- 中文理解：McGirr 定义 Stoicism——**"斯多葛主义不是关于否认真实的痛苦、真实的焦虑、真实的悲伤或任何真实的东西。它是关于用心智不去改变现实，而是通过把它放在更广阔的语境中来应对现实。"**
- 写作技巧：**"not about the denial of" + "using the mind not to change reality but to deal with it"**——McGirr 用**"不是关于否认"和"用心智不去改变现实而是应对现实"**这两个短语来定义 Stoicism——**"不是关于否认" = Stoicism 的反面 = 流行的误解**；**"用心智不去改变现实而是应对现实" = Stoicism 的真正定义**——**"把现实放在更广阔的语境中"用**"更广阔的语境"把"Stoicism"从"个人"变成"宇宙"**——**"Stoicism = 宇宙语境 = 更广阔的视角"**——**"当然，这有改变现实的效果"用**"有改变现实的效果"把"Stoicism"从"不改变"变成"间接改变"**——**"因为我们就是现实的一部分，如果我们改变自己，我们就改变了世界"用**"我们自己 = 现实的一部分"把"Stoicism"从"心智"变成"世界"**——**"改变心智 = 改变世界 = Stoicism 的间接改变"**。
- 关键表达：**not about the denial**（"不是关于否认"——**流行的误解**）；**placing it in a broader context**（"放在更广阔的语境中"——**Stoicism 的定义**）；**if we change ourselves, we change the world**（"如果我们改变自己，我们就改变了世界"——**Stoicism 的间接改变**）——**本章对 Stoicism 的核心定义**：**"Stoicism ≠ 否认 = 放在更广阔的语境中 = 间接改变 = 改变心智 = 改变世界"**。
- 可迁移：**用"X 不是 Y 而是 Z"描述"一种真正的定义"**——"Stoicism 不是否认而是放在更广阔的语境中"。

## 一句话总结

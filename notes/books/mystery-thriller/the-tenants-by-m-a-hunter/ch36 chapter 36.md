# 36. Chapter 36

## 本章导航

- **一句话概括**：Eve 发现她的广告方案文件被删除了——她确信是那个黑衣人进入了她的电脑并删除了文件；她还在门口发现了一张被篡改过的学校照片。
- **情感弧线位置**：偏执升级（escalating paranoia）——Eve 现在确信有人系统性地在破坏她的生活，而不仅仅是进入她的公寓。
- **Tropes 兑现/反转**：数字入侵（文件被删除）；心理战（篡改的照片送到门口）。
- **人物弧线**：Eve 开始将当前的骚扰与她过去的创伤联系起来——她意识到这个入侵者知道她过去发生了什么，而不仅仅是想要骚扰她。
- **叙事手法**：单一 POV（Eve）+ 发现场景和内心分析交叉。

## 精读

> **原句 1:** "'Where's the file?'"

**中文理解**："文件去哪了？"

**关键词**：where's the file / missing presentation / deleted file / the file isn't there

**为什么这样写**：这是 Eve 发现文件消失时的第一反应——她花了数小时制作的广告方案不见了。这个简短的问句在上下文中非常重要：Eve 昨天花了整天工作，她"记得"在屏幕上看到所有视觉材料，但文件现在不见了。"Where's the file?"这个简单的问题暗示了更大问题：Eve 开始怀疑自己的记忆。她之前的创伤（被侵犯、父亲的罪行）正在与当前的现实交织，让她质疑什么是真的，什么是她的想象。

**读者视角提示**：文件消失可能意味着入侵者能够远程访问她的电脑。

---

> **原句 2:** "'Someone else must have deleted it and then removed it from the Recycle Bin so I couldn't restore it.'"

**中文理解**："一定有别人删除了它，然后从回收站里清空了我无法恢复。"

**关键词**：someone else / deleted it / removed from the Recycle Bin / couldn't restore it

**为什么这样写**：这是 Eve 得出结论的时刻——有人故意删除了她的文件，并且知道如何彻底删除它。这个引用在悬疑中很重要：如果入侵者能删除文件，那意味着他们有她的电脑密码，能访问她的账户，并且知道她的文件系统。这个场景还展示了 Eve 的偏执正在变成实际的恐惧——她不再只是觉得有人在监视她，她现在有证据表明有人在积极破坏她的生活。

**读者视角提示**：入侵者能删除文件说明他们有更高水平的知识和访问权限。

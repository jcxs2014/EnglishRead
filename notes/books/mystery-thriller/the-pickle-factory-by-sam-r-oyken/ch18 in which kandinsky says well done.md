# 15. In Which KANDINSKY Says “Well Done”

## 本章导航
- **一句话概括**：Veronica 一边擦银器一边数落 Nick 太天真，劝他别当追猎恶物的阿哈伯；两人聊完中情局的毛病，以“全熟，间谍操蛋鬼”的床笫玩笑收场。
- **情感弧线位置**：全章从厨房里的争吵式关心滑向床边的嬉闹，紧张与温情交替，结尾用双关彻底泄压。
- **线索结构**：GOOWIKI 是否骗局这条线继续悬置；新增“新通信系统推广到整个中国线人网”的隐患，暗示局里内部还有更大的雷。
- **人物弧线**：Nick 坚持“中情局该变优秀”的理想主义，Veronica 以“逃逸速度”的现实主义拉他，两人最终用私人玩笑搁置分歧。
- **叙事手法**：大段对话加一段回忆插叙（总部会议），再切回厨房；标题双关在结尾才揭晓。

## 精读

> **原句 1:** "“Honey, I’ve said it before, and I’ll say it again. You’ve got to stop being so fucking naive,” said Veronica, drying the last of the silverware Nick had hand-washed in the kitchen sink in her apartment."

**中文理解**：Veronica 一边擦干 Nick 手洗的银器，一边重申他太天真，骂得粗鲁却透着熟稔。
**关键词**：Honey / said / Veronica / naive / drying / silverware / Nick / hand-washed / kitchen sink / apartment
**为什么这样写**：把尖锐指责放进擦餐具的家务动作里，亲昵与警告同框，开篇就定下两人关系的底色。
**读者视角提示**：注意她骂的是“naive”而不是“蠢”，语气像姐姐教训弟弟，为后面“我这是为你好”做铺垫。

> **原句 2:** "“What you’re talking about is playing Ahab, hunting something evil that doesn’t want to be found. That’s a counterintelligence job. Are you saying you want to be a counterintelligence officer?"

**中文理解**：她说他想干的是扮演阿哈伯去追猎不想被发现的恶物，那是反间谍的差事，问他是不是想当反间谍官。
**关键词**：talking / playing / Ahab / hunting / evil / found / counterintelligence / job / officer
**为什么这样写**：借《白鲸》里追鲸至死的船长来命名他的执念，一句话把天真拔高成危险的悲剧原型。
**读者视角提示**：Ahab 是西方经典典故，不认识也不影响理解，但认识就能预感到 Veronica 在替他的未来担心。

> **原句 3:** "Neither one of those excellent organizations tolerated deadwood, and neither one was CIA, which comes nowhere, and I mean nowhere, close. But CIA should be the most excellent of all. That’s what Americans deserve."

**中文理解**：他说两家优秀组织都不容忍冗员，而中情局离这个标准差得远；但 CIA 本该最优秀，这是美国人应得的。
**关键词**：excellent / organizations / tolerated / deadwood / CIA / nowhere / close / Americans / deserve
**为什么这样写**：用“优秀组织不容冗员”的职场经验当尺子量 CIA，再把落差归到“美国人应得”，理想主义里带着爱国修辞。
**读者视角提示**：注意他说“我强调一遍，差得远”，这种强调暴露他其实很在意，嘴上说失望，心里仍盼着它变好。

> **原句 4:** "We could be made excellent again, the raw ingredients have already been gathered together. It’s like BUTTONFLY said, we just need to pare way down, take off the lead weights, and set the Agency free to go and do her job once more."

**中文理解**：他相信中情局还能变回优秀，原料已经备齐；照 BUTTONFLY 的说法，只需精简、卸下铅块，让局里放手再干一次。
**关键词**：excellent / raw ingredients / gathered / together / BUTTONFLY / pare / lead weights / Agency / free / job
**为什么这样写**：把改革纲领安在 BUTTONFLY 名下，既让他的信念有出处，也暗示书里早有角色在鼓吹同一套“精简论”。
**读者视角提示**：“卸下铅块”是比喻官僚负担，“让局里放手干”把机构当人写，能看出 Nick 对 CIA 仍有感情寄托。

> **原句 5:** "But far, far from here. If we stick around and try to fix all these huge problems you’re talking about, which I am the first to admit exist, we’ll get sucked in and never reach escape velocity. ‘Get deployed, stay deployed,’ remember?"

**中文理解**：她说要离得远远的，留在总部修问题会被卷进去，永远达不到逃逸速度；还提醒他记得“外派，就待在外派”。
**关键词**：far / here / stick / problems / admit / sucked / escape velocity / deployed / remember
**为什么这样写**：把“别蹚浑水”的劝告包装成航天物理的逃逸速度，再用内部黑话“外派就待外派”给出逃路线，务实得近乎冷血。
**读者视角提示**：她先承认问题存在再劝他走，这种让步式说服比硬顶更有效，也说明她不是不认同，只是更怕被吞没。

> **原句 6:** "“It’s the latest and greatest, thanks to the Internet,” the briefer went on. “We’re going to roll it out across the entire Chinese agent base — all of them. Any questions?”"

**中文理解**：简报人继续吹捧这套系统最新最好，全靠互联网，并说要推广到整个中国线人网，全部都用，然后问有没有问题。
**关键词**：latest / greatest / Internet / briefer / roll out / Chinese / agent base / questions
**为什么这样写**：让简报人用促销广告式的口吻宣布高危决定，“全部”一词重读，为随后质疑搭好靶子。
**读者视角提示**：“整个中国线人网全用同一套”在情报上等于把鸡蛋放一个篮子，读者听到“Any questions?”就该知道要出事。

> **原句 7:** "“Are we sure we should provide the same system to multiple agents in the same country?” she said. “Shouldn’t we change it up for compartmentation reasons?”"

**中文理解**：她忍不住发问：真该让同一国家的多个线人共用同一套系统吗？出于隔离考虑，难道不该换着来？
**关键词**：sure / provide / same / system / multiple / agents / country / said / compartmentation / reasons
**为什么这样写**：两句都是反问，把常识包装成疑问抛向全场，沉默回应反而衬托出她的清醒与众人的麻木。
**读者视角提示**：这里没有写任何人的反应，直接跳到下文，留白让读者自己先替她捏一把汗。

> **原句 8:** "There were no other questions, just a cloying afternoon of donuts and flim-flam. And, so far as Veronica knew, the commo system rollout had gone forward like a doomed ocean liner speeding toward an iceberg."

**中文理解**：会上再无其他提问，只剩甜得发腻的下午、甜甜圈和空话；据 Veronica 所知，通信系统照旧推进，像注定撞冰山的邮轮。
**关键词**：questions / cloying / afternoon / donuts / flim-flam / Veronica / commo system / rollout / doomed / ocean liner / speeding / iceberg
**为什么这样写**：把“没人再问”与“轮船撞冰山”并置，用平静的灾难意象宣告一场注定的事故正在匀速发生。
**读者视角提示**：“so far as Veronica knew”这句限制视角很关键，读者知道她掌握的信息有限，反而更担心系统已经上线。

> **原句 9:** "“Well done, spyfucker,” she hollered. “Pottymouth,” he hollered back."

**中文理解**：她大喊“全熟，间谍操蛋鬼”，他回喊“脏话鬼”，两人用荤笑话给整晚的争论收尾。
**关键词**：Well done / spyfucker / hollered / Pottymouth
**为什么这样写**：让章题“Well Done”的双关在床笫玩笑里落地，政治争吵瞬间泄压，讽刺喜剧以荤段子作结。
**读者视角提示**：标题里的“Well Done”直到这里才被点破是“几分熟”的梗，回头再看章题会多一层幽默。

# 25. Radio Transcript

## 本章导航

- **一句话概括**：Grand Junction 电台主持人 Molly Moss 的广播稿——5 岁 Shiloh Morris 在 Edelweiss 公园的"木制城堡"游乐设施中消失；公园有围栏、只有一个出入口；"一分钟她还在，下一分钟她就不见了"。
- **情感弧线位置**：全书"社会背景"系列第三篇（ch15：9 岁 Rachel；ch24：15 岁 Steven；ch25：5 岁 Shiloh）。Shiloh 是最小的——5 岁。"有围栏的公园"中消失，比"树林"更不可能。
- **Tropes**：公园消失 / "木制城堡" / "一分钟在，下一分钟不在"。
- **人物弧线**：Shiloh Morris（5 岁）——在公园"木制城堡"中消失；Molly Moss——电台主持人，用"恐怖故事"语调播报。
- **叙事手法**：电台广播体裁 + 主持人"故事化"播报（"想象一下"）+ "一分钟在，下一分钟不在"。

## 精读

> **原句 1:** "one minute she's there, the next she's gone—without a trace."

- **中文理解**："一分钟她还在，下一分钟她就不见了——毫无痕迹。"
- **关键词**：without a trace——毫无痕迹
- **为什么这样写**：全书"社会背景"的核心——"一分钟在，下一分钟不在"。"one minute she's there, the next she's gone"是全书最关键的"不可能"：Shiloh 的消失是"瞬间的"——不是"渐进"的，是"瞬间"的。这个"瞬间"暗示全书所有"消失"都是"瞬间的"——不是"被带走"的，是"瞬间消失"的。这个"瞬间"暗示全书最核心的悬念：失踪的儿童都是"被 Rowan 能力瞬间擦除的"——他们"一瞬间"就"消失"了。
- **读者视角提示**：注意"without a trace"——"毫无痕迹"。这个"毫无痕迹"暗示全书所有"消失"都是"无声的"——没有"痕迹"、没有"挣扎"、没有"声音"。这个"无声"暗示全书所有"消失"都是"不可能的"。

> **原句 2:** "You all know Edelweiss Park is fenced in, with only one way in and out. You'd think it would be impossible for a child to just disappear in broad daylight, but somehow, that's precisely what took place."

- **中文理解**："你们都知道 Edelweiss 公园是有围栏的，只有一个出入口。你会认为在光天化日之下，一个孩子不可能就这样消失，但不知怎的，恰恰就是这样发生的。"
- **关键词**：fenced in——有围栏的
- **为什么这样写**：全书"社会背景"的核心——"有围栏的公园"中消失。"fenced in, with only one way in and out"是全书最关键的"不可能"：公园是"封闭"的——有"围栏"、"一个出入口"。Shiloh 在"封闭"空间中"消失"。这个"封闭"暗示全书所有"消失"都是"不可能的"——不是"跑出去"的，是"在封闭空间中消失"的。这个"封闭"暗示全书最核心的悬念：失踪的儿童都是"在封闭空间中消失的"——不是"被带走"的，是"被擦除"的。
- **读者视角提示**：注意"You'd think it would be impossible"——"你会认为这是不可能的"。这个"不可能"暗示 Shiloh 的消失是"不可能的"——在"有围栏的公园"中"消失"是"不可能的"。这个"不可能"暗示全书所有"消失"都是"不可能的"。

> **原句 3:** "Sergeant Emily Parker from the Grand Junction Police Department summed it up: 'This kind of thing doesn't happen here. We're doing everything we can to find Shiloh, but we need the public's help.'"

- **中文理解**："Grand Junction 警察局的 Emily Parker 中尉总结道：'这种事不应该在这里发生。我们正在尽一切努力寻找 Shiloh，但我们需要公众的帮助。'"
- **关键词**：doesn't happen here——不应该在这里发生
- **为什么这样写**：全书"社会背景"的核心——"这种事不应该在这里发生"。"This kind of thing doesn't happen here"是全书最关键的"社区反应"：警方认为"这种事"不应该"在这里"发生。这个"不应该"暗示全书所有"社区反应"都是"否认的"——警方"否认"失踪是"正常的"。这个"否认"暗示全书最核心的悬念：失踪是"系统性的"——社区"否认"但"现实"是"系统性的"。
- **读者视角提示**：注意"We're doing everything we can to find Shiloh"——"我们正在尽一切努力寻找 Shiloh"。这个"尽一切努力"暗示警方是"无能的"——他们"尽力"但"无法"找到。这个"无法"暗示全书所有"警方反应"都是"无能的"。

# 36. JOHN ADAMS' DIARY

**作者**：Bill Nye (Edgar Wilson)

## 一句话总结

Nye 以幽默的笔调模拟了 John Adams 的日记，展示了19世纪美国幽默文学对历史人物的戏仿——他假装 John Adams 写日记，记录了各种荒诞的历史事件。

## 逐句精读（10 处）

① **"December 3, 1764.—I am determined to keep a diary, if possible, the rest of my life."**
- 中文理解：Nye 用正式的历史格式" December 3, 1764"来开场——John Adams 决定要记日记，如果可能的话，记一辈子；这个" if possible"暗示了 Adams 对自己能否坚持的怀疑。
- 句子结构：日期（December 3, 1764）作为时间状语 + 主语（I）+ 谓语（am determined）+ 不定式短语（to keep a diary）+ 条件状语（if possible）+ 时间状语（the rest of my life）。
- 关键词：December 3, 1764 / determined to keep a diary / if possible / the rest of my life——"December 3, 1764"是历史日期，这个格式暗示了这是一份"真实的历史日记"。
- 表达方式：Nye 用" if possible"来暗示 Adams 对自己能否坚持记日记的怀疑——这个" if possible"是幽默的来源。
- 为什么这样写：这是 Nye 的"历史格式戏仿"技巧：通过使用正式的历史日期格式，Nye 建立了一个"假装真实"的日记框架。

② **"I fully realize how difficult it will be to do so. Many others have made resolutions of this kind, and have failed."**
- 中文理解：Adams 说他" fully realize"（完全意识到）坚持记日记有多难，因为" many others have...failed"（其他人也都失败了）；这个"其他人也失败了"的提及暗示了 Adams 的幽默自嘲。
- 句子结构：主语（I）+ 谓语（fully realize）+ 宾语从句（how difficult it will be）+ 主语（Many others）+ 谓语（have made resolutions...and have failed）。
- 关键词：fully realize / difficult / made resolutions / failed——"fully realize"暗示了 Adams 的理性；"failed"暗示了前人的失败。
- 表达方式：Nye 用" many others have failed"来暗示 Adams 的自嘲——他知道很多人尝试过但都失败了。
- 为什么这样写：这是 Nye 的"幽默自嘲"技巧：Adams 在开始记日记之前就承认这很难——这个"自我贬低"是幽默的来源。

③ **"December 4, 1764.—This morning I arose at half past seven, and after performing my ablutions, I sat down to a substantial breakfast."**
- 中文理解：Adams 记录了他的第一个日记条目：他早上七点半起床，" performing my ablutions"（完成我的沐浴仪式），然后吃了一顿" substantial breakfast"（丰盛的早餐）；这个" substantial"和" ablutions"的夸张是幽默的来源。
- 句子结构：日期（December 4, 1764）作为时间状语 + 主语（I）+ 谓语（arose）+ 时间状语（at half past seven）+ and + 谓语（sat down）+ 地点状语（to a substantial breakfast）+ 分词短语（after performing my ablutions）。
- 关键词：arose / performing my ablutions / substantial breakfast——"arose"是起床的正式说法；"ablutions"是沐浴的正式说法；"substantial breakfast"是"丰盛早餐"的意思。
- 表达方式：Nye 用" ablutions"这个正式词汇来形容"洗澡"——这个夸张的正式感是幽默的来源。
- 为什么这样写：这是 Nye 的"日常行为正式化"技巧：Adams 把简单的"起床、洗澡、吃早餐"用最正式的语言来描述——这个"过度正式"是幽默的核心。

④ **"I am resolved to be a great man, if I can."**
- 中文理解：Adams 说"我决心要成为一个伟人，如果可以的话"——这个" if I can"是幽默的核心，因为它暗示了 Adams 对自己能否成功的怀疑。
- 句子结构：主语（I）+ 谓语（am resolved）+ 不定式短语（to be a great man）+ 条件状语（if I can）。
- 关键词：resolved to be a great man / if I can——"great man"是 Adams 的志向；"if I can"是幽默的来源。
- 表达方式：Nye 用" if I can"来暗示：Adams 对自己能否成为"伟大人物"持怀疑态度——这个" if I can"是幽默的来源。
- 为什么这样写：这是 Nye 的"野心与怀疑的对比"技巧：Adams 的"伟大"野心和" if I can"的怀疑形成了幽默的对比。

⑤ **"I have made a great discovery. If I can make a small fire in my study, I can write more fluently."**
- 中文理解：Adams 说他有了一个"伟大发现"——如果他能在书房里生一小堆火，他能写得更流畅；这个"伟大发现"的夸张是幽默的来源。
- 句子结构：主语（I）+ 谓语（have made）+ 宾语（a great discovery）+ 条件状语（If I can make a small fire...）+ 结果状语（I can write more fluently）。
- 关键词：great discovery / a small fire / write more fluently——"great discovery"被用来描述一个显而易见的道理——有火可以让人更舒服地写作。
- 表达方式：Nye 用" great discovery"来形容一个"常识"——这个"常识"被称为"伟大发现"是幽默的核心。
- 为什么这样写：这是 Nye 的"常识性发现被过度夸张"技巧：Adams 把一个有火可以让人更舒服地写作这种常识称为"伟大发现"——这个"过度夸张"是幽默的来源。

## 一句话总结

《John Adams' Diary》是 Nye 的经典戏仿：通过假装 John Adams 写日记，Nye 讽刺了历史人物"自我重要感"的膨胀——Adams 把简单的日常活动（起床、洗澡、吃早餐）用最正式的语言来描述，并把常识性的发现称为"伟大发现"。

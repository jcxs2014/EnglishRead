# 22. Six of Us（我们六个）

## 概览

- **出处**：*Notes on Grief* by Chimamanda Ngozi Adichie（爱德华·哈密尔顿，2022）
- **作者**：Chimamanda Ngozi Adichie
- **章节定位**：全书 30 个碎片中的第 22 篇，无所属 Part
- **字符数**：约 1,600
- **一句话主旨**：本篇写**一个完整家庭在丧失后的失序**——他们在实务上与情感上都在「扑腾」，因为**他们太幸福、太完整，从未练习过如何处理这道裂口**；而最后，母亲说了一句让所有孩子都沉默的话：「我什么都做。为了爸爸。」

**论证脉络**：在 Zoom 通话上，我们**在实务上扑腾、毫无准备、毫无信息** → 这也是**一种情感的跌跌撞撞** → 我们**如此有福、如此幸福、如此被一个安全完整的家庭单元所包裹**，所以**我们不知道拿这道裂口怎么办** → **直到现在，哀都属于别人** → 爱是否会带来（哪怕无意识地）**那种"永不被哀触碰"的妄想的傲慢**？→ 我们踉跄；我们**从一个极端的强颜欢笑，摇摆到被动攻击，再摇摆到为客人摆在哪张桌子而争吵** → **因为幸福让你脆弱——它让你在哀面前毫无防御** → 值得敬重的是我父母：**我们六个人，每人都感到自己被个别地、亲密地了解和爱着** → 而因此**我们哀的方式各不相同** → 而「人们哀的方式不同」这句话，** intellect 容易吸收，但对心来说难得多** → 我开始**害怕那些 Zoom 通话，被阴影笼罩** → **家庭的结构永远地改变了，而没有什么比这更令人心碎：在我的手机屏幕上滑动，再也看不到那个写着"Dad（爸爸）"的方块了** → 母亲说，有些寡妇来找她问那规矩是什么 → **首先，寡妇会被剃成光头**——而**在她继续说之前，我的弟弟们立刻说这很荒谬，不会发生** → 我说：**从来没有人因为妻子去世而剃男人的光头；从来没有人让男人连吃几天清淡的食物；从来没有人指望男人的身体带上他们丧失的印记** → 而**母亲说她要把这一切都做**：「**我什么都做，为了爸爸。**」

**核心张力**：本篇最核心的对照是**子女的「这很荒谬」与母亲的「我什么都做，为了爸爸」**——**子女用性别平等拒绝（男性不必受苦），而母亲用"父亲会想要"接受（他生前看重规矩）**。这两句话的分歧，不是关于习俗，而是**关于「谁在为谁承受」**。

## 论证结构

- **核心论点**：这个家庭的六个人之所以在丧失后如此失序，不是因为他们不够团结，而是因为**他们此前太团结、太完整**——**「幸福是一种脆弱」（Happiness becomes a weakness）**，因为它从未让他们需要「如何共同承受坏事」的技能。而母亲的最后一句话表明：**这个家的应对方式，最终是「为了他」——而不是「为了彼此」**。

- **证据链**

| 证据 | 类型（案例/研究/数据/类比） | 支撑什么 |
|---|---|---|
| 在实务与情感上都在「扑腾」（flailing / floundering） | 案例（状态） | **失序是双重的**——不只是不会办事，是不会处理情感 |
| 「如此有福、如此幸福、如此被一个安全完整的家庭单元所包裹」 | 案例（自述） | **他们的幸福是「被包裹」的**——而这正是脆弱的来源 |
| `Until now, grief belonged to other people`（直到现在，哀都属于别人） | 概念（转折） | **哀一直是「别人的事」**——他们从未在「失去」的位置上 |
| 「爱是否会带来那种妄想的傲慢：以为永不被哀触碰」 | 概念（心理学判断） | **爱与免疫的错误绑定**——作者直接质疑「爱 = 豁免」 |
| 从强颜欢笑 → 被动攻击 → 争论客人在哪桌 | 案例（三段摇摆） | **家庭内部在用情绪的摆动来消耗彼此** |
| `Happiness becomes a weakness`（幸福变成了一种脆弱） | 概念（论断） | **本篇的中心命题**——**快乐让人在痛苦面前没有铠甲** |
| 「我们六个人每人都感到个别地、亲密地被了解和爱着」 | 案例（自述） | **这个家的爱是「个别化」的**——这解释了他们为什么「各自哀悼」 |
| `people mourn differently is easy for the intellect... much harder for the heart` | 概念（智识 vs 心） | **「我们都懂，但我们做不到」**——哀的分歧无法靠道理弥合 |
| 开始害怕 Zoom 通话 | 案例（行为） | **丧亲改变的不只是心情，是关系的形态**——通话从联结变成负担 |
| 手机屏幕上不再有写着「Dad」的方块 | 案例（细节） | **丧失的可见形态就是一个消失的图标**——**父亲在技术层面上被注销了** |
| 母亲说寡妇要剃光头；弟弟们立刻说荒谬 | 案例（冲突） | **习俗在子女这里立刻遭到「性别理性」的抵抗** |
| 「从来没人因为妻子去世而剃男人光头……从没让男人吃清淡食物……」 | 案例（作者的反驳） | **作者用「从来没人」的重复，揭穿习俗的性别本质** |
| 「我什么都做，为了爸爸」 | 案例（母亲的话） | **母亲的选择与子女完全相反**——她接受了**作为女性、为丈夫**的全部代价 |

- **论证脉络**：Zoom 上的双重失序 → **他们太幸福太完整**（以至于没有"处理坏事"的技能）→ 哀一直是别人的 → 爱带来的"免疫傲慢" → 情绪的摆动（强颜欢笑/被动攻击/争吵）→ **幸福变成脆弱** → 六个人被个别地爱着 → 因此各自哀悼 → 智识能理解，心不能 → 害怕 Zoom → 手机上不再有「Dad」方块 → **丧亲的可见形态** → 母亲讲习俗（剃光头）→ 子女的理性抵抗 → 作者的"从来没人"重复 → **母亲的选择：我什么都做，为了爸爸**

- **可质疑处**：
  1. **`Happiness becomes a weakness because it leaves you defenceless in the face of grief`（幸福变成一种脆弱，因为它让你在哀面前毫无防御）是一个需要在全书中反复权衡的论断**：它**准确描述了本篇这家人的处境**，但它也可能**滑向一种对"快乐"的贬低**。全书里，作者自己也有许多快乐的时刻（ch04 全篇的笑话、ch08 的自嘲、ch16 的幽默），**这些时刻是否也算"脆弱"？** 文本**没有对冲这个论断**——**而这正是它在 ch04 与 ch18 中被大量展示的东西（laughing is a part of grief）**。也就是说：**本书自身对"幸福是脆弱"这一论断提供了反例，但作者没有让这些反例说话**。
  2. **母亲与子女之间那道裂缝在本篇未被处理**：作者明确说「从来没人因为妻子去世而剃男人的光头」——**这是一个强有力的、几乎无法反驳的性别观察**。而母亲说「我什么都做，为了爸爸」——**这个选择既可以被读作"母亲的牺牲精神"，也可以被读作"母亲内化了一套要求女性自我牺牲的规范"**。**文本没有裁定**——**它让母亲的这句话作为本篇的最后一行悬置**。而这与 ch21（`But I have to care; these things mattered to my father`——作者自己也以"父亲会想要"为理由接受了程序）**形成了值得警惕的呼应**：**当"为了他"成为唯一的决策原则时，谁来为这个原则的代价负责？** 文本不答。
  3. **「手机上不再有那个写着 Dad 的方块」这一细节的重量可能被低估了**：在全书的物质谱系里（ch12 的遗物、ch13 的家族树、ch16 的手表、ch10 的文件夹），这一行是**第一次由"数字化"承载丧失**——**父亲作为聊天软件里的一个联系人（一个方块、一个名字）消失了**。而这一消失**不可逆、不可修复**（不像地图可以分放两家、不像手表可以被带走）——**一个联系人被注销，就是一个关系在技术层面上被注销**。文本没有展开这层，读者需要自己完成。

## 选择性精读

> **原句 1:** On the Zoom calls, we are flailing, unprepared, uninformed on practical things. It is also an emotional floundering.

**中文理解**：在 Zoom 通话上，**我们在实务上扑腾、毫无准备、毫无信息**。**这也是一种情感的跌跌撞撞。**

**句子结构**：`On the Zoom calls, we are flailing, unprepared, uninformed on practical things` 是一个**地点状语 + 主系表**（三个并行的形容词/分词短语作表语：flailing 扑腾着、unprepared 毫无准备的、uninformed 毫无信息的）。第二句 `It is also an emotional floundering` 是一个**主系表**（an emotional floundering 情感的跌跌撞撞）。

**关键词**：flailing, unprepared, uninformed / an emotional floundering / on practical things

**表达方式**：**以三个并排的贬义词（flailing / unprepared / uninformed）**描述 Zoom 上的状态。`flailing`（扑腾）与 `floundering`（跌跌撞撞）**是两个近义的词**——**但作者用它们区分了两个层面**：**前者是实务的（扑腾），后者是情感的（跌撞）**。而 `It is also...`（这也是……）——**这个"也"字承认了两个层面的并行**。

**为什么这样写**：`flailing` 与 `floundering` 这两个词**都带有「在水中挣扎」的意象**（flail = 挥动四肢；flounder = 挣扎、狼狈）——**作者用水的意象来写他们在家庭聚会中的状态**——**这与 ch05（`churning`，翻涌）、ch06（`drowning nihilism`，令人窒息的虚无）形成一条完整的「水」的意象链**：**在本书里，哀总是以水的形态出现——拔根、翻涌、溺水、扑腾**。而**最值得玩味的是"uninformed"（毫无信息）**——**这个词把「死亡」重新定义为「一次信息不足的事件」**——而这**恰恰是父亲本人一生的状态**（ch19：不熟悉 WhatsApp、不懂「nuke」这个美国俚语、记不住安抚奶嘴的名字）。**父亲一辈子都在"信息不足"中（他不懂他那个世界的东西），而现在他彻底不在了，于是"信息不足"成了孩子们面对他的方式**——**而 `on practical things`（在实务的事情上）这个限定暗示：他们的"信息不足"是关于**怎么操办葬礼**（呼应 ch21 的 clearance、日期、周五、清单）。**

> **原句 2:** We have been so fortunate, to be happy, to be enclosed in a safe, intact family unit, and so we do not know what to do with this rupture.

**中文理解**：**我们如此有福、如此幸福、如此被一个安全完整的家庭单元所包裹，所以不知道拿这道裂口怎么办。**

**句子结构**：`We have been so fortunate, to be happy, to be enclosed in a safe, intact family unit` 是一个**现在完成时 + 三个并列的动词不定式**（have been so fortunate / to be happy / to be enclosed）。破折号（此处为 `,`）后 `and so we do not know what to do with this rupture` 是**结果从句**（so + 主语 + 动词），内含一个**疑问词作宾语的从句**（what to do）。

**关键词**：so fortunate / to be enclosed in a safe, intact family unit / this rupture / what to do with

**表达方式**：**以三个平行的"to be"不定式**（fortunate / happy / enclosed）堆叠出一种**完美的、无缝隙的**家庭图景。而 `so we do not know what to do with this rupture`（所以我们不知道拿这道裂口怎么办）——**这个 so 引出一个残酷的因果**——**正因为他们太完美，所以现在不知所措**。而 `rupture`（裂口）——**这个词极富医学与地质学语感**（rupture = 破裂、断裂）。

**为什么这样写**：`enclosed`（被包裹在……里）——**这个词把「家庭」处理成一个封闭的容器**——**一个安全的、完整的（intact）、封闭的单元**。而 `intact`（完整的、未受损的）——**这个词暗示这个家庭此前从未被任何东西「破开」过**。**而正是这个「从未被破开」的状态，在父亲死后让他们完全无能**——**因为他们没有"破过"，所以不知道破了的家庭怎么运作**。而 `rupture`（裂口）——**这个名词的选择极其精准**：**它不是"悲伤"（sadness）、不是"困难"（difficulty），而是"裂口"（a break, a rupture）**——**悲伤可以被承受，困难可以被解决，但裂口只能被"带着"**。**而 "so we do not know what to do with this rupture"（所以我们不知道拿这道裂口怎么办）——这句话的精髓在于 "what to do"（该怎么办）**——**作者用"不知道该怎么办"来描述六个成年人在一道裂口前的状态**——**而"不知道该怎么办"恰恰是哀的定义**。

> **原句 3:** Until now, grief belonged to other people.

**中文理解**：**直到现在，哀都属于别人。**

**句子结构**：`Until now, grief belonged to other people` 是一个**时间状语（Until now 到现在为止）+ 主谓宾**（grief 主语、belonged 谓语、to other people 介词短语）。全句仅六个词。

**关键词**：Until now / grief belonged / to other people

**表达方式**：**以一个六词的极短句作为本篇的转折点**。而 `belonged`（属于）——**这个动词暗示"哀"是一个有主人的东西**——**在此之前，它一直"属于别人"**——**不属于他们**。而 `Until now`（直到现在）——**这个时间状语标记了一个断裂**——**在这个 "now" 之后，哀第一次"属于"了他们**。

**为什么这样写**：这句话的深刻之处在于**它揭示了"哀"的位置**——**在这家人之前的生命里，哀是"别人的事"**：别人的葬礼、别人的失去、别人的新闻——**他们作为"活着的人"，一直站在哀的旁观席上**。而这一句话宣告：**他们从旁观者变成了当事人**——**而从旁观到当事人的转变，是不可逆的**（呼应 ch11 的 `Never`——"再也"已经住进来了）。这个句子还回应了 ch03（`Grief is a cruel kind of education`——哀是一门课）：**而这门课，他们此前从未修过**。**而 "Until now"（直到现在）这个短语，让父亲的死亡成为了一个精确的时间坐标**——**在此之前，一切都是"别人的"；**在此之后，一切都是"我们的"**。

> **原句 4:** Does love bring, even if unconsciously, the delusional arrogance of expecting never to be touched by grief?

**中文理解**：**爱是否会带来（哪怕无意识地）那种妄想的傲慢——以为永不被哀触碰？**

**句子结构**：`Does love bring...` 是一个**疑问句**（Does + 主语 + 动词原形 + 宾语）。`even if unconsciously` 是一个**让步状语**（even if = 即使）。`the delusional arrogance of expecting never to be touched by grief` 是**宾语**（the + 名词 + of + 动名词结构，of 后接动名词 expecting + 宾语从句 never to be touched by grief）。

**关键词**：Does love bring / even if unconsciously / the delusional arrogance / expecting never to be touched

**表达方式**：**以一个直接向读者/自己发问的疑问句开篇**（这在本书中较少见——通常她用陈述句）。而 `delusional`（妄想的、妄想的）——**这个词带医学色彩**（delusion = 妄想，临床上指病理性信念）。而 `the arrogance of expecting`（那种"以为……"的傲慢）——**把"以为"称为 arrogance（傲慢），是一种道德性的指责**（不是无知，是傲慢）。

**为什么这样写**：这个问句**直接挑战了本书的核心前提**（ch08：因爱太深所以恐惧）。**它提出了一个反向的可能**：**也许不是"爱让人恐惧失去"，而是"爱让人傲慢地以为自己不会失去"**。而 `delusional`（妄想的）这个词**带医学语感**——**暗示"以为永不被哀触碰"是一种病态的、错乱的信念**——**而这个信念，在这一刻被现实击碎了**。**而 `even if unconsciously`（哪怕无意识地）**——**这个让步承认：爱与"免疫的傲慢"之间，不是有意识的因果，而是一种无意识的错误定价**。**作者在问：我们爱得越多，就越以为自己不会失去吗？** 而这个问题**紧接着就被回答了——在接下来的段落里，她说 "We stumble; we veer from an extreme forced cheer to passive aggressiveness"（我们踉跄；我们从一个极端的强颜欢笑摇摆到被动攻击）**——**因为傲慢被击碎之后，剩下的是"摇摆"与"踉跄"。**

> **原句 5:** We stumble; we veer from an extreme forced cheer to passive aggressiveness, to arguing about where guests are to be served. Happiness becomes a weakness because it leaves you defenceless in the face of grief.

**中文理解**：**我们踉跄；我们从一个极端的强颜欢笑，摇摆到被动攻击，再摇摆到为客人摆在哪张桌子而争吵。幸福变成了一种脆弱，因为它让你在哀面前毫无防御。**

**句子结构**：`We stumble; we veer from... to... to...` 是**两个并列的分句**（用分号连接）。`veer from A to B to C` 是**三个并列的介词短语**（from an extreme forced cheer / to passive aggressiveness / to arguing about where guests are to be served）。第二句 `Happiness becomes a weakness because it leaves you defenceless in the face of grief` 是一个**主系表 + 原因从句**。

**关键词**：We stumble / veer from an extreme forced cheer / passive aggressiveness / arguing about where guests are to be served / Happiness becomes a weakness / leaves you defenceless

**表达方式**：**以三个并排的"摇摆"目标**（强颜欢笑 / 被动攻击 / 争论餐桌）**来呈现家庭的失序**。而 `Happiness becomes a weakness`（幸福变成一种脆弱）——**这是一个"X 变成 Y"的转换结构**——**而这个 X（幸福）正是全书前二十一篇所反复展示的东西**。

**为什么这样写**：`veer`（急转、偏航）——**这个词来自"车辆"的转向**（veer = 车辆突然转向）——**它暗示这家人像一辆失控的车，在"强颜欢笑"与"被动攻击"之间来回猛打方向**。而三个摇摆的终点**都很具体、都很小**（强颜欢笑、被动攻击、争餐桌）——**而这正是"哀中最常见的家庭争吵"的样子**。而 `Happiness becomes a weakness because it leaves you defenceless in the face of grief`（幸福变成一种脆弱，因为它让你在哀面前毫无防御）——**这句话是本篇的中心命题**——**而它有一个"因为"（because）**——**作者给出了理由**：**不是因为幸福本身不好，而是因为它让你"毫无防御"（defenceless）**。**"毫无防御"是一个军事/身体的词**——**它暗示：正是因为他们此前被幸福保护得太好，所以当哀来临时，他们**没有任何应对它的"抗体"或"铠甲"**。**而这个论断在逻辑上是自洽的，但它也回过头来对本书自己构成一个质问**——**因为这本书里到处都是笑声**（ch04：笑声是哀的一部分；ch18：父亲把幽默穿得很轻；ch20：孩子用"Mouth plug"逗所有人）——**而这些笑声，难道不是"幸福"或"乐观"吗？它们难道不是"在哀面前毫无防御"吗？** **作者在本篇里给了这个论断一个漂亮的表述，但她在全书的其余二十二篇里所展示的，恰恰是对这个论断的一种实践性的反驳。**

---

> **原句 6:** It is a testament to my parents that each of the six of us feels individually, intimately, known and loved. And so we mourn differently.

**中文理解**：**值得敬重的是我父母：我们六个人，每人都感到自己被个别地、亲密地了解和爱着。而因此我们哀的方式各不相同。**

**句子结构**：`It is a testament to my parents that each of the six of us feels individually, intimately, known and loved` 是一个**形式主语句**（真正主语是 that 从句，testament to = 见证）。破折号（此处为 `,`）后 `And so we mourn differently` 是一个**结果句**（so + 主语 + 动词）。

**关键词**：a testament to my parents / each of the six of us / individually, intimately, known and loved / we mourn differently

**表达方式**：**以"It is a testament to"（这是……的见证/证明）开篇**，**承认父母的伟大**（是父母让每个孩子都感到被个别地爱着），**然后立刻接一句"而因此我们哀的方式各不相同"**——**这个"因此"（so）构成了一个令人意外的推论**。

**为什么这样写**：`a testament to my parents`（我父母的见证/证明）——**这七个字是对父母一生的最高评价**。而 `each of the six of us feels individually, intimately, known and loved`（我们六个人每人individual、intimate地感到被了解和被爱）——**这句话的精妙在于 `individually`（个别地）与 `intimately`（亲密地）这两个副词**——**它们表明：这个家的爱不是"一视同仁"的大锅饭，而是"每个人都被单独地、深入地爱着"**。**而正是这种"个别被爱"（而不是"被集体地爱"）**——**导致了下一句"我们因此哀的方式各不相同"**——**这是一个精妙的因果**：**正因为每个人都被单独地爱过，所以每个人都以自己独特的方式哀悼**。**而这句话也回望了 ch17（父亲读她写的一切、单独地给每个孩子建文件夹 ch18）——**"个别被爱"正是父亲一生的方式**（他给每个孩子一个文件夹、单独地追踪她的行程、单独地读她的每一篇作品）——**而这个"个别"最终变成了"哀的方式各不相同"**。

> **原句 7:** Yet 'people mourn differently' is easy for the intellect to absorb, but for the heart it is much harder.

**中文理解**：**而"人们哀的方式不同"这句话，是 intellect（智识）容易吸收的，但对心来说却难得多。**

**句子结构**：`Yet 'people mourn differently' is easy for the intellect to absorb` 是一个**转折 + 主系表**（Yet 引出，表语 easy to absorb）。`but for the heart it is much harder` 是一个**并列分句**（for the heart 状语 + 主系表 it is much harder）。

**关键词**：people mourn differently / easy for the intellect to absorb / but for the heart / much harder

**表达方式**：**以一个"转折"（Yet）引出一句"intellect（智识）与 heart（心）的对立"**。而 `absorb`（吸收）这个词选得极准——**它是一个智识性的动词**（吸收知识、吸收信息），**而它被用来说"接受一个观点"**——**暗示"人们哀的方式不同"这句话对智识来说是"可以被吸收的"，但对"心"来说不是**。

**为什么这样写**：`for the intellect`（对智识而言）与 `for the heart`（对心而言）——**这组对照是全书最精准的一次「智识 vs 心」的划分**。**"人们哀的方式不同"是一个道理（a truism），而道理是被"吸收"的，不是被"感受"的**。**而 heart（心）——**这个词呼应了 ch10（`He is resting` 带来"一路拖向疼痛"，心脏是痛苦之源）**与 ch03（`my heart... is running away from me`）——**心在本書里始终是身体的、有痛感的**。**而 `much harder`（难得多）**——**这个比较级暗示：心与智识之间的差距，不是一点，是"难得多"**。**也就是说：他们完全理解"每个人哀的方式不同"，但这并不能让他们原谅彼此的不同（或原谅自己的不同）**。**而"心难以吸收道理"这一点，也预示了后文：母亲与子女之间关于"要不要剃光头"的分歧，恰恰是一个"道理"（男女平等）与"心"（为了他，我什么都做）的分歧。**

> **原句 8:** I come to dread the Zoom calls, shrouded in shadow. The family shape is changed forever, and nothing makes it more poignant than to slide on my phone screen and no longer see the square with the word 'Dad'.

**中文理解**：**我开始害怕那些 Zoom 通话，被阴影笼罩。家庭的形态永远地改变了，而没有什么比这更令人心碎：在我的手机屏幕上滑动，再也看不到那个写着"Dad（爸爸）"的方块了。**

**句子结构**：`I come to dread the Zoom calls, shrouded in shadow` 是一个**主谓 + 过去分词短语**（come to + 动词原形；shrouded in shadow 作伴随状语）。第二句 `The family shape is changed forever` 是一个**主系表**（The family shape 主语，is changed 被动）。破折号（此处为 `,`）后 `nothing makes it more poignant than to slide on my phone screen and no longer see the square with the word 'Dad'` 是一个**比较结构**（nothing...more + 比较级 + than + 不定式）。

**关键词**：come to dread the Zoom calls / shrouded in shadow / The family shape is changed forever / more poignant than / slide on my phone screen / the square with the word 'Dad'

**表达方式**：**以一个"我开始害怕"的转折开篇**（come to dread = 开始害怕），**紧接着用"被阴影笼罩"这个状态短语**（shrouded in shadow）。而 `The family shape is changed forever`（家庭的形态永远地改变了）——**一个极其正式的、几乎是社会学语汇的表达**（family shape = 家庭结构/形态）。而最后那个长句——**以"没有什么比这更令人心碎"引出，用一个极其日常的、极其具体的画面作结——手机上那个写着"Dad"的方块**。

**为什么这样写**：`come to dread`（开始害怕）——**这是一个渐进的过程**（come to = 逐渐变得），**暗示作者一开始并不害怕 Zoom（ch01 那是他们最宝贵的联结），而现在它变成了一个"让人恐惧"的东西**。而 `shrouded in shadow`（被阴影笼罩）——**这个词组给 Zoom 通话蒙上了一层死亡的气息**。**而 `The family shape is changed forever`（家庭的形态永远地改变了）**——**这个表达极其冷静、极其学术**——**它是"family structure"（家庭结构）这个社会学概念的文学化**。**而最后那个画面——"手机上那个写着 Dad 的方块消失了"**——**这是全书最"数字化"的丧失**。**父亲作为"联系人"被注销了**。**而这个丧失的独特之处在于：它是"可见的"但"不可逆的"**——**不像遗物（ch12）那样可以触摸、可以分放两家；不像照片（ch13）那样可以凝视；这里的丧失是——你的手指滑过屏幕，而那个位置是空的**。**"没有那个方块了"——**这句话是本篇最精微的一处，而它之所以如此精微，是因为它**把"父亲的存在"还原成了"屏幕上一个有名字的图标"**——**而在父亲死前，他也是一个图标**（ch01：Zoom 通话上只有他的额头）。

> **原句 9:** I say that nobody ever shaves men bald when their wives die; nobody ever makes men eat plain food for days; nobody expects the bodies of men to wear the imprint of their loss.

**中文理解**：**我说：从来没有人因为妻子去世而剃男人的光头；从来没有人让男人连吃几天清淡的食物；从来没有人指望男人的身体带上他们丧失的印记。**

**句子结构**：`I say that...` 是一个**转述结构**（say + 宾语从句）。从句由**三个平行的否定句**构成（nobody ever shaves...; nobody ever makes...; nobody expects...），**每一句都以 "nobody ever" 开头**（never + ever 的加强），三个分句用分号连接。

**关键词**：nobody ever shaves men bald / nobody ever makes men eat plain food / nobody expects the bodies of men / to wear the imprint of their loss

**表达方式**：**以三个"从来没有人"（nobody ever）的重复**，**构成一次系统的反驳**。而 `shaves men bald`（把男人剃成光头）、`makes men eat plain food`（让男人吃清淡的食物）、`expects the bodies of men to wear the imprint`（指望男人的身体带上印记）——**三个例子都是关于"身体的"**。

**为什么这样写**：`nobody ever`（从来没有人）这个重复**极其有力**——**它把那个"习俗"（女性被要求自我惩罚）**还原成了一种"从未存在过"的东西**——**而这个"从未存在过"，实际上是在暗示：这种习俗是"只对女性存在"的**。**而三个例子的共同点是"身体"**——**剃光头（改变外貌）、吃清淡的食物（改变内在）、身体带上印记（改变身体本身）**——**作者用"身体"这个维度，勾画出了一整套"女性在丧偶后被要求承受的身体性惩罚"**。而最后那句 `to wear the imprint of their loss`（带上他们丧失的印记）——**这是本篇最深刻的一处**：**"印记"（imprint）这个词暗示：女性的丧失，以一种"可见的、留在身体上的"方式被记住了**——**而男性的丧失则是"无痕的"**。**而这句话也呼应了 ch03（身体是哀的所在：舌苦、胸沉、心跳失序）**——**而作者在此质疑的是：为什么只有女性的身体要被"标记"？**

> **原句 10:** But my mother says she wants to do it all: 'I'll do everything that is done. I'll do it for Daddy.'

**中文理解**：**而母亲说她要把这一切都做：「我什么都做。我为了爸爸，什么都做。」**

**句子结构**：`But my mother says she wants to do it all` 是一个**转折 + 转述结构**（says + 省略 that 的宾语从句）。冒号后 `'I'll do everything that is done. I'll do it for Daddy.'` 是**直接引语**（内含两个独立的将来时句子）。

**关键词**：she wants to do it all / I'll do everything that is done / I'll do it for Daddy

**表达方式**：**以一个极其平静的"她想要做这一切"开篇**。而 `'I'll do everything that is done'`（我什么都做，那些被做的）——**这句话用了一个"被动语气的定语从句"**（everything that is done = 一切被做的事）——**母亲把自己定义为"执行者"**（做一切"被规定要做的事"）。而 `'I'll do it for Daddy'`（我为了爸爸做）——**一个极为简洁的、几乎是宣言式的短句**。

**为什么这样写**：`I'll do everything that is done`（我什么都做，那些被做的）——**这句话的被动语态（that is done）极其关键**——**母亲说的不是"我要做我想做的"，而是"我要做一切（该做的）"**——**她把自己放进了那套"习俗"的框架里**。而**这句话与前面弟弟们的"这很荒谬，不会发生"、作者的"从来没人让男人受这种苦"形成了极其尖锐的对照**。**母亲没有为习俗辩护（她说"这很荒谬"的是弟弟们），她只是平静地说"我要做"**。**而 `I'll do it for Daddy`（我为了爸爸做）——这句话是全书最重的一句之一**——**因为它揭示了母亲做这一切的唯一理由：为了父亲**——**而为了一个已经不在的人的"意愿"，她愿意把自己置于那套要求女性自我惩罚的规矩之下**。**而作者在记录这句话时，没有给出任何评论**——**文本让母亲的这句话作为本篇的最后一词而悬置**。**这是一个精微但重要的选择**——**因为如果作者在这里说"这不对"，她就站到了母亲的对立面；但如果作者什么都不说，她就默许了母亲的牺牲**。**而文本选择了让读者自己去面对这其中的张力。**

## 一句话总结

这一篇写**一个从未破过的家庭，在破掉之后的失序**：他们在 Zoom 上「在实务与情感上都在扑腾」，因为**他们此前太幸福、太完整，被一个安全的家庭单元包裹着，以至于不知道拿这道裂口怎么办**——而「直到现在，哀都属于别人」；**幸福变成了一种脆弱**（它让你在哀面前毫无防御），于是他们从强颜欢笑摇摆到被动攻击、再摇摆到争餐桌；而「我们六个人每人都被个别地、亲密地爱着」也意味着**我们哀得各不相同**——**道理（智识）能吸收，心却难**。而最深的一击是：母亲讲起寡妇要剃光头的规矩，弟弟们说荒谬，作者说**从来没人这样对男人**——**而母亲说：「我什么都做。我为了爸爸，什么都做。」** 于是这件事再无下文，全书在「手机上那个写着 Dad 的方块消失了」的空白里，继续。

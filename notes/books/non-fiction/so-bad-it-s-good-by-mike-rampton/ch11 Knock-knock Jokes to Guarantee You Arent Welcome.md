# 11. Knock-knock Jokes to Guarantee You Aren’t Welcome

## 概览

- **出处**：*So Bad It's Good: The Art of the Terrible Joke*，Mike Rampton 著，Pavilion（HarperCollins 旗下）2026 年出版
- **作者**：Mike Rampton
- **章节定位**：正文第 10 篇，纯笑话目录；紧接 ch10 对敲门格式的解释，可视为那节的实例附录
- **字符数**：约 2,113（提取件 `text/ch11_knock_knock_jokes_to_guarantee_you_arent_welcome.txt`）
- **一句话主旨**：二十条敲门笑话证明这个格式的全部弹性都在"名字"这一格：名字可以是一个完成时句子、一个长到荒谬的人名、一个被听错的音节，甚至一次"打断"，格式越被填满就越不像笑话。
- **结构**：20 条，全部以 "Knock, knock. Who's there?" 起头，无一字解说

## 论证结构

- **核心论点**：敲门笑话的槽位只有两个（名字／谐音解释），所以它的"创作"实际上是**往名字里塞什么**。作者选的这二十条按填充物分三类：塞句子（I've eaten up）、塞近音词（Anita／Cowsgo／Cash）、塞破坏规则的东西（Control freak 抢话、Spell 要求拼写、Persephone… 长名失效）。第三类是本章真正的论点：格式的边界由它容许的破坏方式划定。

- **证据链**：

  | 证据 | 类型 | 支撑什么 |
  |---|---|---|
  | I've eaten up → "You've eaten a WHAT?" | 句子作名字 | 名字必须被当成名词，一旦是完成时就滑向食人 |
  | Anita → "I need to use your toilet" | 连读 | 整个格式依赖连读把两个词粘成一个名字 |
  | Cowsgo → "cows go moo" | 误听 | 答案要同时纠正语法与动物叫声 |
  | Control freak → 抢话，规定对方台词 | 元笑话 | 角色性格侵入格式本身 |
  | Little old lady → yodel | 语音 | "who" 被拖长成约德尔调 |
  | Spell → "W-h-o" | 字面化 | 把"怎么拼"当作问题本身 |
  | Kanga → "Actually, it's kangaroo" | 截断 | 名字只给前半截，答者纠正成完整词 |
  | Banana ×7 → Orange | 耐心消耗 | 格式可以被无限拖延，笑点是"终于换了" |
  | Cash → "nut allergy" | 谐音 | cashew 被当成坚果，答非所问 |
  | Persephone Twinkletoes McGinty | 过载 | 名字长到无法接话，提问者反被问住 |

- **论证脉络**：顺序大致按"破坏程度"排列：先是正常的谐音，再是抢话、拼写这类破坏格式本身，最后两条（香蕉、超长名）已经不是笑话，而是对"讲笑话的人"的耐心测试。作者没有加任何评论，让排列自己说话。

- **可质疑处**：
  1. 二十条里有近半需要特定口音才成立（Anita／Cowsgo／Cash／Kanga），写成文字后读者往往要念出声才能还原，本章因此更像"发音练习"而非阅读材料。
  2. 作者选的几乎全是"反例"——最好笑的几条都是破坏格式的，这与 ch10 的判断一致，但也意味着这个格式在书里没有被正面展示过一条真正好笑的。
  3. "Guarantee You Aren't Welcome" 这个标题暗示这些笑话会冒犯听者，但实际内容大多只是无聊，冒犯性被标题夸大了。

## 选择性精读

> **原句 1:** "Knock, knock. Who’s there? I’ve eaten up. I’ve eaten up who? You’ve eaten a WHAT?"

**中文理解**：敲门。谁呀？"我吃完了。" "我吃完了"谁？你吃了个什么？！

**句子结构**：四问四答压缩成一行；最后一句用大写 WHAT 与感叹号把格式的语调整个掀翻。

**关键词**：eaten up / WHAT

**表达方式**："I've eaten up" 是一个没有宾语的完成时，被硬当作人名；一旦追问，听者才意识到"吃完了"意味着吃了东西——而那个东西可能就是提问者。

**为什么这样写**：放在第一条，因为它把敲门笑话的恐怖潜力一次用尽：格式要求你把任何话当名字，于是最普通的一句家常话变成了食人 confession。

> **原句 2:** "Knock, knock. Who’s there? Anita. Anita who? Anita use your toilet."

**中文理解**：敲门。谁呀？安妮塔。安妮塔什么？"我需要用你的厕所。"

**句子结构**：三行标准格式，第四行把整个名字读成一个句子。

**关键词**：Anita / toilet

**表达方式**：Anita 连读为 "I need to"，所以 "Anita who?" 的答案其实是 "I need to use your toilet"——一个名字的语音里藏着一句请求。

**为什么这样写**：这是本章最"标准"的一条：没有破坏格式，纯粹靠连读。作者把它放在第二条，让读者先掌握规则，再看不守规则的。

> **原句 3:** "Knock, knock. Who’s there? Cowsgo. Cowsgo who? No they don’t, cows go moo!"

**中文理解**：敲门。谁呀？"牛去。" "牛去"什么？不对，牛只会哞哞叫！

**句子结构**：四行，最后一行用 No they don't 否定一个从未被说出的命题。

**关键词**：Cowsgo / moo

**表达方式**：Cowsgo 是 "cows go" 的连写，答者把它听成"牛会去（某处）"，于是用"牛只会哞"来纠正——纠正的对象其实不存在。

**为什么这样写**：这一条暴露了格式的语法漏洞：名字可以是任何音节组合，而答者必须为这个组合编出一句"纠正"。

> **原句 4:** "Knock, knock. Who’s there? Control freak. Con–– Okay, now you say, ‘Control freak who?’"

**中文理解**：敲门。谁呀？控制狂。"控制——"好了，现在你该说"控制狂什么？"

**句子结构**：三行，第四行被破折号截断，随后角色自己接管了对话。

**关键词**：Control freak / Okay

**表达方式**：控制狂不肯等对方问完，自己规定对方下一句该说什么；格式的"提问权"被角色抢走。

**为什么这样写**：本章第一个元笑话：它不再用格式讲笑话，而是讲格式本身。作者把它放在中段，标志着目录从"填充名字"转向"破坏规则"。

> **原句 5:** "Knock, knock. Who’s there? Little old lady. Little old lady who? I didn’t know you could yodel!"

**中文理解**：敲门。谁呀？小老太太。小老太太什么？我不知道你还会唱约德尔调！

**句子结构**：四行标准格式；最后一行用感叹句把语音误认成才艺。

**关键词**：yodel / lady

**表达方式**："little old lady who" 连续的高低声调听起来像约德尔唱法，答者不解释双关，直接夸对方会唱。

**为什么这样写**：这是本章少数完全靠"念出来"才成立的一条；它说明敲门笑话在书面形态下几乎是残疾的，必须靠声音补全。

> **原句 6:** "Knock, knock. Who’s there? Spell. Spell who? W-h-o."

**中文理解**：敲门。谁呀？拼。拼什么？W-h-o。

**句子结构**：四行；最后一行不是句子，是三个字母。

**关键词**：Spell / W-h-o

**表达方式**：把 "Spell who?" 的 who 按字面拼出来，答案既回答了问题又取消了问题——因为拼出来的正是问题本身。

**为什么这样写**：全章最省力也最无解的一条：它连谐音都不需要，只需要读者承认"who"这个词可以被当作待拼写的对象。

> **原句 7:** "Knock, knock. Who’s there? Kanga. Kanga who? Actually, it’s kangaroo!"

**中文理解**：敲门。谁呀？袋。袋什么？其实，是袋鼠！

**句子结构**：四行；最后一行用 Actually 开头，是一次礼貌的纠正。

**关键词**：Kanga / kangaroo

**表达方式**：Kanga 是 kangaroo 的前半截，答者以为对方在说一个不完整的单词，于是替它补全——格式要求"名字"必须完整，而这里故意不完整。

**为什么这样写**：这一条把"名字"这个槽位暴露成语法单位：只要它像词头，听者就会自动补全，笑话就建立在这个补全冲动上。

> **原句 8:** "Knock, knock. Who’s there? Banana. Banana who? Knock, knock. Who’s there? Banana. Banana who? Knock, knock. Who’s there? Banana. Banana who? Knock, knock. Who’s there? Banana. Banana who? Knock, knock. Who’s there? Banana. Banana who? Knock, knock. Who’s there? Banana. Banana who? Knock, knock. Who’s there? Orange. Orange who? Orange you glad I didn’t say banana?"

**中文理解**：敲门。谁呀？香蕉。香蕉什么？敲门。谁呀？香蕉。香蕉什么？（重复七轮）敲门。谁呀？橘子。橘子什么？你不高兴我没说"香蕉"吗？

**句子结构**：七轮完全相同的问答，第八轮换词；最后一句用 Orange 谐音 "Aren't you" 收束。

**关键词**：Banana / Orange

**表达方式**：重复本身就是铺垫：听众的耐心被消耗到临界点，换词的一刻才产生解脱感；笑点不在双关，而在"终于结束了"。

**为什么这样写**：本章最长的一条，也是唯一一条把"时长"当材料的：它证明敲门笑话可以靠纯粹的重复变成耐力测试。作者把它放在后段，正好承接 ch10 关于长毛狗故事的讨论。

> **原句 9:** "Knock, knock. Who’s there? Cash. Cash who? No thanks, I have a nut allergy."

**中文理解**：敲门。谁呀？现金。现金什么？不了谢谢，我对坚果过敏。

**句子结构**：四行；最后一行用一个完全无关的礼貌拒绝作答。

**关键词**：Cash / allergy

**表达方式**：Cash 谐音 cashew（腰果），答者把它当成端来坚果的主人的名字，于是拒绝——双关在语音上成立，在对话逻辑上却是答非所问。

**为什么这样写**：这一条示范了本章最经济的手法：不需要解释，只需要让答案看起来像在回应一个完全不同的问题。

> **原句 10:** "Knock, knock. Who’s there? Persephone Twinkletoes McGinty. Persephone Twinkletoes McGinty who? You … you know multiple people named Persephone Twinkletoes McGinty?"

**中文理解**：敲门。谁呀？珀耳塞福涅·闪脚趾·麦金蒂。珀耳塞福涅·闪脚趾·麦金蒂什么？你……你认识好几个叫珀耳塞福涅·闪脚趾·麦金蒂的人？

**句子结构**：四行；最后一行用两个省略号断开，把回答变成反问。

**关键词**：multiple / Twinkletoes

**表达方式**：名字长到荒谬，以至于 "who?" 这个追问在逻辑上失效——如果名字已经独一无二，"who" 就问不出任何东西。答者的反问指出了这一点。

**为什么这样写**：全章最后一条，也是格式的终点：当名字无法再被误听、被截断或被连读时，笑话就只剩一个尴尬的停顿。作者用它收尾，等于承认这个格式已经用尽。

## 一句话总结

二十条敲门笑话把同一个槽位填到极限：句子、连读、单词前半截、甚至"打断"本身——格式的规则只有一条（名字必须被听成别的东西），而这条规则一旦被违反（控制狂抢话、拼写、超长人名），笑话就变成了关于笑话的元笑话。

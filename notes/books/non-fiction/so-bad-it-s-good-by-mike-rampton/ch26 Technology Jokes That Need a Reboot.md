# 26. Technology Jokes That Need a Reboot

## 概览

- **出处**：*So Bad It's Good: The Art of the Terrible Joke*，Mike Rampton 著，Pavilion（HarperCollins 旗下）2026 年出版
- **作者**：Mike Rampton
- **章节定位**：正文第 25 篇，类型笑话章；主题是电脑、网络、家电与工程，是全书技术词密度最高的一章
- **字符数**：约 3,700（提取件 `text/ch26_technology_jokes_that_need_a_reboot.txt`，正文 644 词，32 条 + 一段七条清单）
- **一句话主旨**：技术笑话的通用公式是"把技术词的字面义当成物理事实"：caps lock 锁住帽子，contacts 是隐形眼镜，gather dirt 是收集灰尘，bug 是虫子——术语越抽象，被物化时越好笑。
- **结构**：32 条笑话；中段插入一段八行的清单（引子 "Of all the inventions ever created …" + 七条），每条以"最 X 的发明"收尾；其余为一问一答或两句对话，无小节标题。

## 论证结构

- **核心论点**：技术词汇大多由隐喻构成（cache、bug、dirt、traffic、lock、connection），使用者早已忘记它们的字面来源；笑话只要把隐喻重新物化，就能让"电脑"与"日常物件"在同一个句子里同时成立。

- **证据链**：

  | 证据 | 类型 | 支撑什么 |
  |---|---|---|
  | remorse code | 谐音 | Morse code 被换成悔恨 |
  | rota／rotor system | 谐音 | 轮值表与直升机旋翼，同一句里两个语境 |
  | human computer／十分钟睡着 | 字面化 | 电脑待机＝人的午睡 |
  | to be sure, to be sure | 双重含义 | 双重认证的字面执行 |
  | PayPal decree／papal decree | 谐音 | 支付方式与教皇诏令 |
  | stroganoff／strong enough | 谐音 | 密码强度被读成一道菜 |
  | caps lock／帽子 | 字面化 | caps 既是"大写"也是"帽子" |
  | lost its contacts | 字面化 | 联系人／隐形眼镜 |
  | site for sour ryes | 谐音 | site for sore eyes，酸面包提供字面 |
  | gathering dirt | 字面化 | 收集灰尘／收集黑料 |
  | 列表七行 | 排比 | "最具 X 性的发明"把评价词逐个读回字面 |

- **论证脉络**：条目大致按"硬件→软件→网络→日常设备"排列：先是摩斯码、直升机、电脑、主板，再是密码、缓存、路由器、联系人，最后是手机、游戏机、吸尘器、键盘。中间的列表是唯一的结构性停顿，把前面零散的双关收成一组排比。

- **可质疑处**：
  1. 约十条依赖英国本地知识（GCHQ 式的 "to be sure" 爱尔兰口音、Stroganoff、Worthing／Brighton、hoover 作动词），书中没有注释。
  2. 列表七行里有几条只有形容词的字面义而缺少技术语境（"Corduroy pillows generate the most headlines"），与其他条目的构造方式并不一致。
  3. 与 ch16（数学与科学）一样，技术在这里只提供词汇，不提供经验：没有一条涉及使用电脑的真实挫败感，除了最后那条密码要求。

## 选择性精读

> **原句 1:** "What do you call an apology written in dots and dashes? Remorse code."

**中文理解**：用点和划写成的道歉叫什么？悔恨码。

**句子结构**：一问一答；答案是一个被替换了首词的复合名词。

**关键词**：Remorse code

**表达方式**：Morse code（摩斯电码）由点和划组成；remorse（悔恨）与 Morse 同音，而"道歉"正是悔恨的表达。

**为什么这样写**：开篇第一条就给出本章最干净的结构：一个技术名词 ＋ 一个与它同音的情绪词。

> **原句 2:** "All of us at Try To Invent A Helicopter Club have been attempting to figure out how best to make sure everyone does their fair share of cleaning. I said, ‘Perhaps we should have a rota system,’ and they all said, ‘YES WE KNOW.’"

**中文理解**：我们"尝试发明直升机俱乐部"的全体成员一直在琢磨，怎样才能确保每个人公平分担打扫工作。我说："也许我们该搞个轮值表。"他们齐声说："我们当然知道！"

**句子结构**：两句：一段冗长的背景叙述 ＋ 一句对话式的反击。

**关键词**：rota system

**表达方式**：rota（轮值表）与 rotor（旋翼）同音；俱乐部成员研究的就是直升机，所以"旋翼系统"是他们的常识，不需要外人提醒。

**为什么这样写**：这一条把双关藏进一个荒唐的俱乐部名字里：读者要读完两行铺垫，才会发现"轮值"其实是"旋翼"。

> **原句 3:** "My nickname is ‘the human computer’. Not because I’m smart, but because I go to sleep if left alone for ten minutes."

**中文理解**：我的外号是"人形电脑"。不是因为我聪明，而是因为只要十分钟没人理我，我就会睡着。

**句子结构**：两句：称号 ＋ 否定—肯定式的解释。

**关键词**：human computer

**表达方式**：电脑闲置十分钟会进入休眠；人的"待机"是打瞌睡。称号的褒义（聪明）被替换成技术特性（自动休眠）。

**为什么这样写**：这一条的笑点来自"期望落空"：human computer 通常指天才，这里指节能模式。

> **原句 4:** "Why does Irish technology involve two-factor authorization? To be sure, to be sure."

**中文理解**：为什么爱尔兰的技术要用双重认证？为了确认，再确认。

**句子结构**：一问一答；答案是一句重复的爱尔兰英语口头禅。

**关键词**：To be sure

**表达方式**：to be sure, to be sure 是爱尔兰英语里表示强调的重复说法；双重认证要求"两次确认"，于是这句口头禅成了字面的安全流程。

**为什么这样写**：这一条的笑点依赖口音刻板印象：技术流程被翻译成一句地方性口头禅。

> **原句 5:** "The best way to pay for things in Vatican City is by PayPal decree."

**中文理解**：在梵蒂冈城最好的付款方式是"PayPal 诏令"。

**句子结构**：一句陈述句，没有问答。

**关键词**：PayPal decree

**表达方式**：papal decree（教皇诏令）与 PayPal decree 同音；梵蒂冈是教皇国，所以"诏令"是当地的通用货币。

**为什么这样写**：这一条把地名、宗教制度与现代支付工具压进四个词，是本章最依赖"同音替换"的一条。

> **原句 6:** "Why shouldn’t you use ‘beef stew’ as a computer password? It isn’t stroganoff."

**中文理解**：为什么不该用"炖牛肉"当电脑密码？因为它不够"奶油蘑菇牛肉"。

**句子结构**：一问一答；答案是一个否定句加一个菜名。

**关键词**：stroganoff

**表达方式**：Stroganoff 与 strong enough（足够强）谐音；密码强度被说成一道菜的火候，而 beef stew 正是同类菜。

**为什么这样写**：这一条需要读者同时知道"密码要够强"和"Stroganoff 是一道牛肉菜"，两个知识在最后三个音节上重合。

> **原句 7:** "Why couldn’t the beginner typists remove their hats? They had caps lock on."

**中文理解**：初学打字的人为什么摘不下帽子？因为他们开着大写锁定。

**句子结构**：一问一答；答案把键盘键名当身体状态。

**关键词**：caps lock

**表达方式**：caps 在键盘上是 capital letters，在衣着上是帽子；lock 既是"锁定"也是"锁住"，所以帽子被"锁"在头上。

**为什么这样写**：这一条是全章最典型的"术语物化"：一个键名同时描述了打字状态与衣着状态。

> **原句 8:** "Why was the mobile phone wearing glasses? Because it lost its contacts."

**中文理解**：手机为什么戴眼镜？因为它丢了联系人。

**句子结构**：一问一答；答案是一个双义名词。

**关键词**：contacts

**表达方式**：contacts 既是手机里的"联系人"，也是"隐形眼镜"；丢了隐形眼镜就要戴框架眼镜。

**为什么这样写**：这一条只用一个名词的两个义项，就完成了因果链：丢联系人→戴眼镜。

> **原句 9:** "I bought some dark, vinegary bread online. Boy, was that a site for sour ryes."

**中文理解**：我在网上买了一些深色、带酸味的面包。天哪，那真是"酸黑麦的网站"。

**句子结构**：两句：购物描述 ＋ 一句感叹式双关。

**关键词**：site for sour ryes

**表达方式**：a sight for sore eyes（让人看了舒服的东西）被换成 a site for sour ryes（酸黑麦的网站）；"网上买"提供了 site 的字面义，"深色带酸味"提供了 sour rye 的字面义。

**为什么这样写**：铺垫里每个形容词都在为最后的谐音服务：dark、vinegary、bread、online，一个都不能少。

> **原句 10:** "Sure, your phone and computer spy on you all the time, but they’re not the worst. Your hoover has been gathering dirt on you for years."

**中文理解**：当然，你的手机和电脑一直在监视你，但它们还不是最糟的。你的吸尘器已经收集了好几年的"你的脏东西"。

**句子结构**：两句：让步 ＋ 转折，最后一句是一个双关。

**关键词**：gathering dirt

**表达方式**：gather dirt 意为"收集灰尘"，gather dirt on someone 意为"收集某人的黑料"；吸尘器的功能让字面义成立，监视的语境让比喻义成立。

**为什么这样写**：结尾把技术恐惧收在一个家用电器上：最古老的设备，反而是收集黑料最久的那一个。

## 一句话总结

技术笑话把术语的字面义重新装上：caps 是帽子，contacts 是镜片，dirt 是黑料，bug 是虫——电脑越抽象，被当成日常物件时越可笑。

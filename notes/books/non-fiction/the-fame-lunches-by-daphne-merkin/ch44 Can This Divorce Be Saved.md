# 44. Can This Divorce Be Saved?（精读分析）

## 概览

- **出处**：*The Fame Lunches* by Daphne Merkin, "Can This Divorce Be Saved?"
- **作者**：Daphne Merkin
- **章节定位**：Part VI "The Mating Game" 第八篇，书评/个人随笔，写于 2002 年
- **字符数**：约 24,033 字符（16 段）
- **一句话主旨**：Merkin 通过评论 E. Mavis Hetherington 的《For Better or for Worse》和自己的离婚经历，探讨"离婚"作为"文化指标"——离婚是"死亡的替代品"；Hetherington 的研究是"乐观的"但"方法论上有缺陷"；离婚是"一种生活方式"而非"一种结局"。

## 论证结构

- **核心论点**：离婚是"死亡的替代品"（a functional substitute for death）；Hetherington 的研究是"乐观的"但"方法论上有缺陷"；离婚是"一种生活方式"而非"一种结局"；Merkin 的"离婚后适应风格"是"有缺陷的"。
- **论证脉络**：

  以"深夜读 Hetherington"破题 → Hetherington 的"研究" → Merkin 的"离婚后适应风格" → 离婚的"历史" → 离婚的"文化" → 结尾："离婚是一种生活方式"

- **可质疑处**：
  1. Merkin 对 Hetherington "方法论缺陷"的批评是否足够——她是否也"有缺陷"？
  2. 她将离婚比作"死亡"是否过于悲观——这是否只是"个人偏见"？
  3. 结尾"离婚是一种生活方式"是否过于乐观——这是否回避了更深的痛苦？

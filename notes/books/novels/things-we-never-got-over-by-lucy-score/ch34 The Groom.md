# 34. The Groom

## 本章导航

- **一句话概括**：Naomi 和 Waylay 准备睡觉，Warner 突然出现在酒吧，Knox 为保护 Naomi 与 Warner 打架。
- **情感弧线位置**：冲突 — 从温馨到威胁
- **Tropes 兑现/反转**：日常温馨 → 旧情人纠缠 → 英雄救美
- **人物弧线**：Naomi 从放松到恐惧，Knox 从冷静到暴力
- **叙事手法**：Naomi 视角 — 从准备到冲突

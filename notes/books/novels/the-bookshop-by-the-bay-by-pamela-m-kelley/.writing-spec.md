**做法**：一次 `sed -n '9,400p' text/chNN_chapter_N.txt` 读全章 + `tail -3` 确认结尾。

### ② 引语只能手打「前缀」，正文由脚本注入
**不要手打引语正文**。在 md 里写占位符，然后：
```bash
python3 scripts/inject_by_para.py "<书目录>/chNN chapter <english>.md" "<书目录>/text/chNN_chapter_N.txt" \
  'Q1=@短前缀' 'Q2=@短前缀+N' 'Q3=@短前缀*'
```
- `@短前缀`：取**以该前缀开头的那一句**
- `@短前缀+N`：从那一句起，**再连取 N 句**（同一自然段内）
- `@短前缀*`：取**含该前缀的那一整段**
- 前缀必须**在句首**且**全文唯一**，否则退出码 2 且**不写文件**（这是好事，不要绕过）
- **句首切分规则**（决定你的 N 取多少）：`[.?!] + 空白` 才切句；但 `.` 紧跟 `”` 时**不切**。
  所以 `“Good. I know you wanted…` 的第一个切分单元是 `“Good.`，前缀要写 `I know you wanted`。
  **不确定就先跑**：`python3 /tmp/units.py <txt> "<锚点片段>"`（会打印该段每句的切分结果）
  —— 若该文件不存在，用下面这段一次性打印：
  ```bash
  python3 - <txt> "锚点片段" <<'PY'
  import re,sys
  ABBR=(r"Mr|Mrs|Ms|Dr|Prof|St|Mt|Rev|Hon|Sen|Rep|Gov|Gen|Col|Capt|Lt|Sgt|Mme|Mlle|Sr|Jr|Fr|vs|etc|Nos|Fig|Vol|Op|pp|ca|cf|ed|al")
  def sents(par):
      text=par.strip(); out=[]; start=0
      for m in re.finditer(r"[.?!]\s+", text):
          if re.search(rf"(?:^|\W)(?:{ABBR})\.$", text[:m.start()+1], re.I): continue
          if re.search(r"(?:^|\W)[A-Za-z](?:\.[A-Za-z])?\.$", text[:m.start()+1]): continue
          b=text[max(0,m.start()-4):m.start()+1]; a=text[m.start():m.end()+3]
          if re.search(r"\.(\s*\.){2,}$", b) or re.match(r"^(\.\s*){2,}", a): continue
          p=text[start:m.start()+1].strip()
          if p: out.append(p)
          start=m.end()
      tail=text[start:].strip()
      if tail: out.append(tail)
      return out
  t=open(sys.argv[1]).read()
  for p in [x for x in t.split("\n\n") if x.strip()]:
      if sys.argv[2] in p:
          for i,s in enumerate(sents(p)): print(f"  [{i}] {s[:95]}")
  PY
  ```

### ③ 一条引语只能取自**一个自然段**（红线）
- 跨段、跨说话轮次 ⇒ **拆成两块**，或把分析收窄到单段 + 块外内容用中文转述
- 跨省略号拼接（`…`）是最高频引语缺陷，**不要用**
- 分析（中文理解/关键词/为什么这样写/读者视角提示）**只能覆盖本条引语里的内容**

## 5. 禁止事项

1. **禁止写任何一次性批量改写脚本**。2026-09-29 曾因 `zip(列表A, 列表B)` 长度不等而静默截断，
   损坏全书 15 章，且 `audit_structure` 对该损坏报 0、`verify_quotes` 全绿。
   要改内容就用 `edit` 逐处改。
2. **禁止 `git add -A` / `git add .`**，只加明确路径（本机多实例并行）。
3. **禁止写不可核的计数断言**（「三个词」「五个字」「唯一的」），`audit_numbers` 只能报一部分。
4. **禁止在中文里夹生英文**（如「一阵隐隐作痛的stress headache」）。
5. **禁止写「（未出现在原文）」「未见于原文」类标注**。
6. **禁止引用他章而不 grep 回源**（8.1 第 7b 条）；导航里的 `chNN` 引用必须当场验。
7. 提交信息用 `git commit -F - -- <明确路径>`，heredoc 内**不放 pathspec**、正文**不含反引号**。

# 61. Interstitial: Hasty Madder

## 本章导航
- **一句话概括**：一份植物档案（快速茜草）——俗名、学名、适应谱系；她的育种记录。
- **情节位置**：小卫星线间插文本，紧跟 ch060；植物档案，记录她的育种工作。
- **人物弧线**：无（档案格式，没有叙事弧线）。
- **叙事手法**：百科式条目；科学命名；把适应谱系写成血统。

## 精读

> **原句 1:** "Common name: Hasty Madder"

**中文理解**：这株植物的俗名——快速茜草。

**关键词**：common name / Hasty Madder

**为什么这样写**：用百科条目的格式写出植物档案——冷静、精确；“快速”二字暗示这株植物长得快，或就是为速度而培育的。

**读者视角提示**：Signy 的工作——她记录自己的创造。

> **原句 2:** "Species name: Rubia alexandrae"

**中文理解**：学名的后半段表明，它是以某个人的名字来命名的。

**关键词**：species name / Rubia alexandrae

**为什么这样写**：用拉丁双名法写出科学的正式感；那个后缀是一个纪念名，指向某个名叫 Alexandra 的人；也暗示她与这个名字的来源有私人关联。

**读者视角提示**：命名作为纪念——植物以 Signy 认识的人命名。

> **原句 3:** "Adaptation path: Rubia tinctorum -> Rubia astralis -> Rubia cypsela -> Rubia alexandrae"

**中文理解**：适应谱系——从地球的原种，到适应环系的两个阶段，最后到这一株。

**关键词**：adaptation path / Rubia tinctorum / Rubia astralis / Rubia cypsela

**为什么这样写**：用一串箭头写出演化与育种的谱系——从地球的祖先到适应环系的后代；每一个阶段都出自她的手；也暗示这是历经数代的培育。

**读者视角提示**：Signy 的遗产——她的植物是她毕生的工作。

## 精读

> **原句 1:** "Common name: Better Guar"

**中文理解**：这株植物的俗名——改良瓜尔豆。

**关键词**：common name / Better Guar

**为什么这样写**：用百科条目的格式写出植物档案——冷静、精确；“改良”二字表明它是原种的改进版；她的命名讲究实用。

**读者视角提示**：Signy 的工作——她为实用改良而育种。

> **原句 2:** "Species name: Cyamopsis cypsela"

**中文理解**：学名——后半段的后缀是适应环系的标记。

**关键词**：species name / Cyamopsis cypsela

**为什么这样写**：用拉丁双名法写出科学的正式感；那个后缀是关键标记——所有适应环系的植物都带它；也暗示她一贯的命名惯例。

**读者视角提示**：Signy 的系统——她按适应阶段为植物命名。

> **原句 3:** "Adaptation path: Cyamopsis tetragonoloba -> Cyamopsis astralis -> Cyamopsis cypsela"

**中文理解**：适应谱系——从地球的原种，到适应环系的两个阶段。

**关键词**：adaptation path / Cyamopsis tetragonoloba / Cyamopsis astralis

**为什么这样写**：用一串箭头写出演化与育种的谱系——从地球的祖先到适应环系的后代；每个阶段都出自她的手；地球时代的旧名与环系时代的新名并置，暗示她为这里重新命了名。

**读者视角提示**：她留下的东西——为环系创造了新的物种。

# 概述

## 全书梗概

《Pretty Bossy》讲述了 Zarna Rai 和 Mayan Samar 从"假婚约"到"真感情"的故事。Zarna 是一名有创业梦想的 junior 员工，Mayan 是一名被指控打假拳的 MMA 明星。两人因为一场意外（音乐太大 → 闯入房间 → 剪坏头发）相遇，又因为一次"被迫陪游"（暴风雨困于野外小屋）达成了"假婚约"交易：她扮演他的未婚妻以向 FFY 证明他是"family man"，他出资帮她启动 Gin 品牌。

全书以 Zarna 的第一人称视角展开，通过她的内心独白和黑色幽默，展现了一个"被困在无聊工作中的创意灵魂"的挣扎。她从"假装 bland"到"找回自我"的成长弧线，是全书的核心主题。

## 主题

1. **假婚约 → 真感情**：全书的核心套路是"fake relationship"，但作者通过"完全诚实"的对话（ch16 浴室坦白）和"热气球惊喜"（ch21）让"假"与"真"的界限模糊。
2. **创伤治愈**：Zarna 被前任 Kage 操控、被同事 Sandheer 陷害、被父母误解；Mayan 被 Noa 勒索、被舆论压迫、被过去困扰。两人的相互治愈是全书的情感核心。
3. **自我认同**：Zarna 从"假装 bland"到"找回自我"的成长，通过"创作绘画"（ch21）和"品牌发布"（ch22）完成。

## 人物弧光

- **Zarna Rai**：从"meek Victorian princess"（ch03）到"vibrant, bold, assertive"（ch21）。她的成长不是"变成别人"，而是"不再假装"。
- **Mayan Samar**：从"冷静精英"到"愿意为爱改变的保护者"。他的成长不是"变得软弱"，而是"学会被需要"。

## 叙事结构

- **第一幕**（ch01-06）：相遇 → 假婚约 → 同居
- **第二幕**（ch07-15）：嫉妒 → 家庭危机 → 第一次接吻 → 提取计划曝光 → 分离
- **第三幕**（ch16-22）：反思 → 擂台对决 → 热气球表白 → 品牌发布

## 定稿格式强制项（九项）
frontmatter、概览、逐句精读（`> **原句 M:**` + 五子项）、段末 `**段落逻辑：**`、全文段落逻辑箭头链、词汇分级三档表、长难句专项、精读结束总结、可迁移表达。

## Obsidian 渲染 4 大坑（2026-08-20）
1. **表格行首 1 空格** → 被解析为代码块，整张表不渲染。
2. **`- **段落脉络**：` 紧跟表格无空行** → 表格被吞进 `<li>`。
3. **表头/分隔/内容列数不一致** → 以内容列数为准改表头分隔（不要重写内容）。
4. **年份被空格拆列** → 如 `2002 | 年夏末`，应合并为 `2002 年夏末`。

## 子代理可靠性教训
- status=completed 报告不能信，fan-out 后必须 `ls -la` + `wc -c` + `grep` 实地核验，未变重派。
- 写文件每块 < 8KB，避免 90s 超时。

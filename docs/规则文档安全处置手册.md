# 规则文档安全处置手册

> **用途**：改规则文档时"怎么动手才不慌"的操作规程。
> **定位**：这是**操作规程**，不是规范源——规则正文仍在 `AGENTS.md`；本手册只规定"改它的动作顺序与回滚方式"。
> **配套**：方案与逐块数据见 `docs/规则文档结构调整方案.md`；本文是该方案的执行前置与回滚依据。
> **生成日期**：2026-09-27 ｜ **回退锚点**：`rules-before-refactor-20260927`

---

## 0. 一句话

**规则多 ≠ 不能动。** 只要满足三个条件，任何一步都能整体回退：

1. 改前有**锚点 tag**（已就位）；
2. 每步**只动一个文件、一块内容**；
3. 每步有**能跑的验收命令**，且结果与基线数字对比。

**违反任一条就别动。**

## 4. 标准动作（每块 5 步，任何一步异常就停）

```bash
# ① 记基线
wc -c AGENTS.md

# ② 落盘（只增，不动源文件）
#    把要迁的内容写进 docs/实测档案/…，然后核对字节
wc -c "docs/实测档案/xxx.md"

# ③ 核对：迁出内容在档案里逐字可查（抽样 3 句）
grep -F "<原句片段>" "docs/实测档案/xxx.md"

# ④ 删源块 + 加指针（一个 commit 只做一块）
git add -- AGENTS.md "docs/实测档案/xxx.md"
git diff --cached --name-only     # 确认只有预期文件，无他人暂存
git commit -m "..." -- AGENTS.md "docs/实测档案/xxx.md"

# ⑤ 复验
wc -c AGENTS.md && git status --short
```

**复验三项（一次性跑完）**

```bash
cd ~/Documents/Works/EnglishRead

# 体积
wc -c AGENTS.md README.md .memory/AGENTS.md "docs/新书启动模板.md"

# 引用计数（基线 114）
grep -rhoE '第 ?[0-9]+ ?条' AGENTS.md README.md COLLABORATION.md \
  "docs/新书启动模板.md" "docs/新书归档指令.md" \
  docs/COLLABORATION_ARCHIVE_README.md .memory/AGENTS.md | wc -l

# 指针完整性（基线 14 个唯一值 / 死链 0）
for f in $(grep -rhoE 'docs/实测档案/[^ )`|、，。]+\.md' AGENTS.md README.md \
  COLLABORATION.md "docs/新书启动模板.md" "docs/新书归档指令.md" \
  docs/COLLABORATION_ARCHIVE_README.md .memory/AGENTS.md | sort -u); do
  [ -f "$f" ] || echo "❌ 死链 $f"
done
echo "（无输出 = 零死链）"
```

> **口径提示**：`grep` 交替请用 `-E`（macOS BSD grep 的 `\|` 不生效，会**返回空而非报错**，容易把"有"看成"没有"）。

## 5. 一键回滚（三种粒度，从轻到重）

```bash
git revert --no-edit <commit>                    # 撤销某一步，保留历史（推荐）
git checkout <commit> -- AGENTS.md               # 只恢复单个文件
git reset --hard rules-before-refactor-20260927  # 全部回到锚点（⚠️ 丢弃未提交改动）
```

**回滚后不需要额外动作**——本次改动不涉及脚本与精读内容，回滚即完全复原。

## 6. 明确不做

- ❌ 不 push（等你指令）
- ❌ 不动 `notes/`、`scripts/`、`site/` 与任何精读文件
- ❌ 不用 `git add -A` / `git add .`；不删 `index.lock`；不 `--amend` 他实例的 commit
- ❌ 不建"平行清单"：同一事实只允许一处正文，其余为指针
- ❌ 不在同一次 commit 里混做"落盘"与"删除"

## 7. 每步之后记一行

往本工作区日志（`.workbuddy/memory/YYYY-MM-DD.md`）或 `.memory/daily/` 记：

```
日期 ｜ 文件 ｜ 字节变化（前→后）｜ 验收命令与结果 ｜ commit hash
```

**记这一行的意义**：下次再动时，你有"上一步是什么、验到什么程度"的凭据，不必靠回忆判断——这是"敢处置"的真正来源。

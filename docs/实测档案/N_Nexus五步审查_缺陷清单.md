## 二、⭐ 本轮最有价值的发现

### 发现 1：分析层**语法级改字**是六道门禁的共同盲区

**现象**：`that was the engine`（原文 `that **were**`）、`a extremely powerful weapon`（原文 `an`）、`a objective reality`（原文 `an`）。

**投毒测试**（遵守「修完先提交再投毒」，否则 `git checkout` 会还原修复）：

| 尺子 | 注入 `were→was` 后 |
|---|---|
| `sweep_analysis_inline` | 「零命中 **0**」——漏过 |
| `verify_quotes` | 117/117 ——漏过 |
| `check_vocab` | FAIL 0 ——漏过 |
| **`check_analysis_indep`** | ✅ 逐条列出 → 人判抓到 |

**根因**：三把主力尺子只比对**完整引语块**，不比对分析层散落的英文片段。**补救**：`check_analysis_indep` 应进常规门禁清单（当前仅 d 步跑）。

### 发现 2：**子代理的"阻断型"定性与行号都需复核**（子代理 23 条 → 复核后实缺陷 20 条）

- 2 条假红（`ch05:96` 章号口径、冠词扫描）
- 1 条幻觉（行号错位 + 取证路径错误）
- 2 条被我**升级**（`ch06:151`、`ch09:167` 从提示型升为阻断型）
- 1 条**部分**成立（`ch06:111` 前半无据、后半有据——子代理说后半也错，实际原文有 `old men on the podium in Red Square`）

**这印证了 AGENTS 第 3 条**：不分类就照单全改，会把正当内容改坏。

### 发现 3：最高频语义缺陷类（引语截短）在本轮**为零**

Such a Fun Age 批次曾有 18 处「先写中文理解后挑引语」导致引语截短。本轮对**全 78 块**做机械检测（中文理解里的英文词是否全在引语内 + 理解/引语字数比）：**截短 0 处**；全部 13 章引语均**长于**中文理解（比值 0.26–0.34）。根因是写作期词表/引语均由脚本产出、只做减法。

## 六、2026-10-23 口径更正（同日晚，含两处工具 bug 修复）

**① 「阻断」≠「英文字段」。** 本文前面的数字（2,839 处 / 212 本）是 `check_chinese_layer` 的阻断量，
它把「缺字段」也算进阻断。拆开看：
- `wolf-hour`：726 阻断 = 723 缺中文理解 + 2 解析问题 + 1 密度，**英文字段 0**；

**② 修 `> ` 引用符盲区（`1aa12d7ef`）。** `sections()` 不剥 markdown 引用符，`> **中文理解**：`
写法整段解析成 `'> > > >'` ⇒ 判「英文」。修后 `such-a-fun-age` 170→0、`the-harpy-knight` 71→2，
全库重扫 2,839 → **2,398**。

**③ 修标签变体与全角冒号块头（同日）。** `为什么这一句这样写` 这类变体归一到标准名；

**教训（比数字重要）**：**量具不认识某种写法时，会静默地什么都不查，而报告看起来像「没问题」。**
本轮三处（`> ` 引用符 / 全角冒号块头 / 标签变体）都是这一类，累计影响 9 本书。
⇒ 见到「无法判定」或「密度突然很低」，先怀疑解析器，再怀疑内容。

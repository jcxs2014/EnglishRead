## 判例一 · 引语粒度的作废线：同一套门禁全绿，仍然是一本要作废的稿子

### 事实

| 口径 | 旧稿（作废） | 新稿（本次） |
|---|---|---|
| 引语块数 | 111 | 128 |
| **每块词数中位** | **152 词**（此前口头记法 168 词，计数口径不同，结论一致） | **41 词** |
| 最长一块 | **1126 词** | 69 词 |
| >100 词的块 | **74 / 111** | **0 / 128** |
| 每章块数 | 5–8（中位 6） | 5–8（中位 8） |
| 硬线要求 | 1–3 句 / 30–70 词 / ≤4 行 | 同左 |

**旧稿与新稿的块数完全同档**——被作废的原因不在块数，在**引语粒度**。

### 门禁确实全绿（现场复现）

把旧稿 `ch00–ch02` 连同本书 `text/` 复制到临时目录后直接跑现有工具：

```bash
$ python3 scripts/bookform.py /tmp/dlha-oldform --all ; echo "EXIT=$?"
  ⚠️ 引语偏长（提示型，不判红）：2 章有块 >100 词 —— ch02 4 块、ch00 1 块
  汇总：空引号 0 章 ｜ 形态偏离 0 章 ｜ 无法判定 0 章
EXIT=0

$ bash scripts/chapter.sh "/tmp/dlha-oldform/ch01 chapter 1.md" ; echo "EXIT=$?"
  空引语 0｜子项缺 0｜关键词不成立 0｜中文过薄 0
  ✅ 引语长度：全部 ≤100 词
  结论：✅ 机器层无阻断
EXIT=0
```

### 结论

- `bookform` 的**引语长度检查是提示型（⚠️），不判红**；`>100 词` 只在整书体检里打一行提示，单章体检甚至显示「✅」。
- **创建卡 §3 的「1–3 句 / 30–70 词 / ≤4 行」没有任何 lane 强制**，整书 20 条 lane 里没有一条查它。
- ⇒ **同一批块数、同一套门禁全绿，可以是一本从头到尾作废的稿子。** 判「合不合规」时，粒度要靠人（或专门的脚本）看，不能拿门禁当证据。
- 复核方（2026-10-21 异实例）实测新稿：引语中位 32–54 词、**全书最长 69 词、>100 词的块 0 个**——与上表一致。

## 判例二 · 「真空绿」长什么样：形态量具解析到 0 个子项时，它报 0 而不是报错

### 复现

把本书三章的子项标签冒号从粗体**外**改成粗体**内**（`**中文理解**：` → `**中文理解：**`），其余一字不动：

```bash
$ python3 scripts/bookform.py /tmp/dlha-vacgreen --all ; echo "EXIT=$?"
  汇总：空引号 0 章 ｜ 形态偏离 0 章 ｜ 无法判定 0 章
EXIT=0

$ bash scripts/chapter.sh "/tmp/dlha-vacgreen/ch01 chapter 1.md" ; echo "EXIT=$?"
  空引语 0｜子项缺 0｜关键词不成立 0｜中文过薄 0
  ✅ 引语长度：全部 ≤100 词
  ⚠️ 体裁 profile 的子项是 中文理解/关键词/为什么这样写/读者视角提示/句子结构，
     本书是 ———**不算错**
  结论：✅ 机器层无阻断
EXIT=0
```

**32 行子项，一个都没被解析；「子项缺 / 中文过薄 / 关键词不成立」三条全部在空集上判 0；形态行直接把子项集显示成 `———` 并且只记一句「不算错」。**

### 两支，取决于书内还有没有别的章能被解析

| 情形 | 表现 | 性质 |
|---|---|---|
| **全书同形态**（所有章都解析到 0） | 众数子项集 = ∅ ⇒「子项缺 0」；`bookform --all` 退出码 0；整书 20 lane `gate.sh` 退出码 **0**、合格分析密度 **100%**、阻断 **0** | **真空绿**（量具没量，却报了绿） |
| **部分章同形态**（本书众数仍解析得到 4 项） | 那几章被报「子项缺 4/8」⇒ ❌ 阻断 | **假红**（2026-10-21 本机 ch00 实战：32 行子项写 `**中文理解：**` ⇒ 报「子项缺 8」） |

### 边界：真空绿只发生在形态量具上

把同一份「真空绿」文件里某个 `中文理解` 正文改成纯英文，**⑲ 中文层照样抓**：

```
=== 汇总：37 个引语块 | 合格分析密度 97% | 整层夹杂率 0% | 阻断型 1 | 提示型 0 ===
══ 退出码层：1 个 lane 报阻断 → ⑲中文层 ══
```

⇒ `check_chinese_layer` 自己认得粗体内冒号形态，**只有 `bookform` 的 `SUB_RE` 不认**（它要冒号在粗体外：`**中文理解**：` 或列表项 `- 中文理解：`）。

### 夹具与盲区

- `scripts/tests/bookform_bullet/` 是**列表型**子项的阴性对照（`README.md` 记：2026-10-20 在 `fabulous-bodies` 上实测「子项集 0 项」而每块实际有 4 个子项；判据＝输出里必须出现「❌ 子项缺：原句2 → ['为什么这样写','读者视角提示']」，否则说明列表型子项又没被解析）。
- **盲区**：**粗体内冒号（`**中文理解：**`）这一形态没有夹具**，本文件即其现场记录。
- 读法：**形态行出现「本书是 ———」＝ 该书的形态量具处于空载状态**；此时门禁的「子项缺 0 / 中文过薄 0」是空集上的 0，不是「量过了没问题」。

## 判例三 · 「词不存在」与「词拼错了」在 `check_vocab` 输出里长得一样

### 事实

`ch13 chapter 13.md` 高级档词头写成 `convolutions`（原文是 `convulsions`），整书门禁 lane ② 报：

```
--- FAIL (1) ---
  ch13 chapter 13.md [高级] 词条(A类虚构，epub 全书查无)
      「convolutions」
```

把词头改回 `convulsions`（例句 `Her convulsions made too much noise.` 一字不动）⇒ FAIL 0。

### 为什么难认

| 输出 | 含义 | 处置不同 |
|---|---|---|
| 「词条(A类虚构，epub 全书查无)」 | 词真的不存在（自造词） | 按 A 类处理：要么删词，要么改成原文有的词 |
| 同一条输出，实为**拼写错** | 词存在，只是打错 | 改词头即可，**例句和全文都不用动** |

### 现场分辨法（本次唯一用上的线索）

同一份输出里还有一条 WARN：

```
--- WARN (7) ---
  ch13 chapter 13.md [高级] 例句不含词头「convolutions」
```

**例句是从原文逐字粘的**（`docs/rules/创建卡.md` §5 禁手写例句），所以「例句不含词头」＋「例句本身逐字命中原文」＝**词头多半是拼错，不是虚构**。
判 A 类之前先在原文里找**词根与形近词**（`convulsions`/`convolution`/`convolutionary`），找不到形近词才谈 A 类。

### 一个附带事实

没有 epub 时，同一条错判会变成「无法判定是否虚构」而不是 FAIL（`check_vocab` 退出码 0）——**同一本错稿，口径不同，红不红也不同**；判读时先确认 epub 在位。

## 一、类一：章内引语块顺序倒置（本书 11 章 / 12 处 → 0）

### 判据（`scripts/check_quote_order.py`，与门禁共用 `chapter_contiguity.flat` 归一口径）

1. 每条引语在本章 `text/` 展平后**唯一命中**（0 处或多处 ⇒ 该章「不可判定」，不判红）；
2. 命中位置**严格递增**；
3. `> **原句 N:**` 的 N 必须是 1..N 连续。

## 二、类二：重排工具自己制造缺陷（尾空行归属）

首版 `.memory/tools/reorder_quote_blocks.py` 在本书实跑时**自己造出 2 章缺陷**：

- **根因**：解析时把「末块之后、标题之前的空行」单独算作 `tail_blank`，而**每个块的尾空行归属**却是「谁在原位上谁带着」；
  ⇒ 原末块搬到中间时**少一个**空行、原中间块搬到末位时**多一个**。
- **症状**：ch17 / ch42 各出现「**块间无空行**」1 处 + 「**标题前双空行**」1 处。
- **修法**：装配改成**核心块 + 统一分隔空行**（分隔数不统一就整章跳过、不猜）；
  并加**落盘前自检**（块数 / 去编号后块内容多重集合 / 编号连续 / 无连续空行）。

**阴性对照（本次改动的验收）**：

1. 把本书复制到 `/tmp`，在 ch05 上**把原句 3 与原句 5 两块对调**；
2. `check_quote_order` ⇒ **报 1 章缺陷**（工具确实看得见这个形态）；
3. 跑修复工具 ⇒ 修复后 **0 章缺陷**，且**产物与规范文件逐字节一致**（`cmp -s`）；
4. **幂等**：对已修好的书再跑 ⇒ **0 改动**。

> **教训**：**「改写工具自己造成的损坏」比原缺陷更难发现**——因为复验命令往往只查目标缺陷、不查结构副作用。
> ⇒ 复验必须用**不同的那把尺子**（本例：查块序的工具查不出空行归属问题 ⇒ 必须另查连续空行）。

## 三、类三：写作期自述泄漏（lane ⑰ 的 E 判据盲区）

本书 ch13 第 100 行（**已在 HEAD 里**）：

```

```

它**不属于任何字段**，是模型写作时留下的自述。**19 lane 全绿**——
因为 lane ⑰ 的 E 判据是**固定中文串白名单**：`写作期自查记录` / `不作为独立引语块计` / `自查记录` / `写作期备注`。
**英文形态的第一人称草稿话一条都认不出。**

⇒ 2026-10-20 给 `scripts/check_quote_blocks.py` 补 **F 判据**：**结构位置 + 元写作短语**双条件。

| 条件 | 细则 |
|---|---|
| ① 结构位置 | 该行必须是**独立段落行**——不是引语行（`>`）、不是 `**字段：**` 行、不是标题（`#`）、不是表格行（`|`）、不是列表项（`-`/`*`/`1.`） |
| ② 元写作短语 | `Let me fix` / `typo in the` / `anchor =` / `with X flag` / `TODO` / `FIXME` / `PLACEHOLDER` / `as an AI` / `note to self` / `Now the vocab` / `inject quotes` / `待补充` / `占位符` / `回头改` / `自检记录` / `写作侧记录` |
| ③ 匹配前 | **必须先剥离引文跨度**（直引号 / 弯引号 / 单引号 / 反引号） |

## 五、顺带修的工具缺陷：`name[:30]` 截断

`scripts/check_quote_blocks.py` 的报告行写 `name[:30]` ⇒ **文件名被截到 30 字符**，
复核者按报告里的名字**根本找不到那一行**（实测多本书文件名 >30 字符）⇒ 已改为完整文件名。

> 通用形态：**报告里的定位信息被截断，等于没有定位信息**——
> 而「报不出位置」会让人误以为该条不可复核，从而放过。

## 六、处置：`check_quote_order.py` 进终验清单，**不进正门**

| 方案 | 后果 | 结论 |
|---|---|---|
| 进正门作**新 lane** | lane 数 19→20 ⇒ 须同步**五处**文档（AGENTS.md / 新书模板 / 期刊模板 / 终验清单 / `.memory/AGENTS.md`），而 **AGENTS.md 已超注入预算（54,468 B vs 32,768 B）⇒ 不得再往里加字** | ❌ 不做 |
| 并进 lane ⑰ 作**阻断型** | **354 本存量书一次性变红**，而按「新规则的适用范围」存量书不自动回溯 ⇒ 门禁变成无法行动的红海 | ❌ 不做 |
| **进终验快速检查清单 + E 组工具表**（本轮采用） | lane 数不变 ⇒ 无须五处同步；新书必须手跑并把结果写进报告；存量书不自动回溯 | ✅ 采用 |

> **这是「加新检查」与「加新 lane」的第三种解法**：**检查清单是五处同步点之一**，而 lane 数的同步只针对 lane 的增删。
> ⇒ **能不动 lane 数就不动**——否则每次加检查都要付「五处文档同步」的税。

1. **「19 lane 全绿」不等于「结构对」**——**没有一道 lane 验的东西，就是隐形**。

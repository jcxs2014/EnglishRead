## 四、扫描配方（本轮实际用的四把尺子，可直接复用）

1. **计数型量词**（`N 秒 / N 个词 / N 次 / N 倍`）——把散文里所有数字断言拎出来逐条数：
   ```bash
   python3 - <<'PY'
   import glob,re,os
   BOOK="notes/books/novels/the-dues-don-ts-of-magic-by-delemhach"
   for f in sorted(glob.glob(f"{BOOK}/ch*.md"))+sorted(glob.glob(f"{BOOK}/00_*.md")):
       for i,l in enumerate(open(f,encoding="utf-8").read().split("\n"),1):
           if l.startswith("> ") or "关键术语" in l: continue
           for m in re.finditer(r"[一二三四五六七八九十两半\d]+\s*(?:秒钟|秒|个词|倍|次(?:开口|说话|叫|喊))",l):
               print(f"{os.path.basename(f)} L{i}: …{l[max(0,m.start()-60):m.end()+50]}…")
   PY
   ```
   ⇒ 抓出 50 处候选，人工只核可疑的那些（本轮 7 处真缺陷）。
2. **绝对化断言**（`唯一 / 全书第一 / 再没有 / 从未 / 再也`）——逐条问「**这句能被计数否证吗**」；能计数的（如「ch13 之后 Hound 出现 14 章」）就改成可证表述，否证不了就降级措辞。
3. **说话人归属**——凡「X 一句『…』」必须回原文看**该句是否在引号内**（`“…”` 是台词，无引号是叙述句）。本轮 7 处误植全部出在「叙述句被当成台词」。
4. **章号指认**——凡跨章引用（`chNN`）都要在 `text/chNN_*.txt` 里命中一次；注意**章号扫描要数「该场景」而不是「该词」**（`blanket` 在 ch09 是 0、在 ch18 是 3；而 `rain` 在 ch09 也有 1 次，单看词会被骗）。

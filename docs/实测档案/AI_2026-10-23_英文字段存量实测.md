# 英文字段存量实测（全库 551 本）

> 统计时点：2026-10-23 11:30 前后。全库有多个实例并行写作，本章节数字是**快照**；
> 复跑同一段代码，前后两次可能相差十几处——差异来自别人正在改书，不是测量不稳。
> 判据只有一个：字段正文**一个汉字都没有**（`[\u4e00-\u9fff]` 命中数为 0）。
> 「中英夹杂」「中文句子 + 英文引文」一律不计入——那类在 ⑲ 里是**提示型**，不是阻断型。

## 一、数的是什么

统计对象是「中文理解 / 为什么这样写 / 读者视角提示」三个字段（`知识库` 体裁的必备子项；
「关键词」天然是英文词表，不查；「句子结构」「表达方式」单列，见第四节）。

逐文件解析 `ch*.md`：以 `> **原句 N` 切块 → 块内按标签取字段正文 → 判定有无汉字。

与 `scripts/check_chinese_layer.py`（下称 ⑲）的三点差别，读表前必须先知道：

1. **块头写法**：⑲ 的 `BLOCK = ^> \*\*原句 \d+:\*\*` 只认**半角冒号 + 闭合 `**`**；
   写成 `> **原句 1：**`（全角冒号）的书，⑲ 解析出 **0 个块**，直接报「无法判定」，
   全书的英文段落**一处都看不见**。本文的块头只要求 `> **原句 N`，不要求冒号形式。
   （实测 `notes1/books/novels/love-on-the-brain-by-ali-hazelwood` 18 处整段英文，
   ⑲ 对该书输出「未解析出任何引语块」。）
2. **同名标签出现多次**：⑲ 首组入库、其余进 `dups` 另查；本文按**出现次数**各算一个字段。
3. **裸段落**：块内第一个标签之前的裸段落，⑲ 当作没写标签的「中文理解」（第六修），
   本文照做，并且**标签到来时合并**而不是各算一条——否则会把「英文引文行」误记成英文理解
   （首轮 41 本里的假阳性多来自这里，见第五节）。

## 二、全库结果

- 按字段分：`为什么这样写` 143 条、`中文理解` 85 条、`读者视角提示` 85 条。
- **没有一本**书的英文字段超过该书字段总数的一半（详见第三节）。

## 五、关键区分：**「阻断 726」≠「726 处英文」**

以 `notes1/books/mystery-thriller/wolf-hour-by-jo-nesbo` 为例（本次实测的起点）：

| ⑲ 的阻断项 | 处数 | 实际是什么 |
|---|---|---|
| 缺中文理解 | 723 | **字段没写**（只有 ch01–ch09 共 48 块写了，ch10 起全无） |
| 重复子项字段 | 2 | 引语头写坏（`> **原句 16:"…` 缺收尾 `**`），块被合并 ⇒ 一块里两组子项；ch38 4 处、ch56 7 处 |
| 密度不足 | 1 | 合格分析密度 6%（48/771） |
| **整段英文（英文理解/为什么/读者提示）** | **0** | 三个字段只要写了就是中文；无中文的 1,203 条字段行里汉字 0 缺失 |

即：阻断数统计的是「中文层不合格的块」，一个块可以同时缺字段、缺密度；**它不数英文**。
把阻断数当英文存量，会把「写作欠账」误判成「翻译任务」——这正是本书最初被误判的原因。

## 六、对本目录首轮数字（41 本）的更正

首轮行级扫描报 **41 本**，本次修正后是 **28 本 / 313 处**。差异两处，方向相反：

1. **少 13 本：全是解析假阳性。** 字段写成 `**中文理解：**`（冒号在粗体内部、正文另起一行）时，
   首轮正则把收尾的 `**` 当成正文 ⇒ 正文＝`**` ⇒ 无汉字 ⇒ 记一次英文。
   受灾最重的是 `styx-the-river-by-nikita-gill`（1474/1474）与 `the-man-by-laura-sims`（290/1061），
   两本实测分别是 1474 条、1061 条字段，**汉字缺失 0 条**，全中文。
   其余 11 本（in-a-rush、reliquary、unloved、what-we-give-away、wolftamer、you-were-never-not-mine、
   blue-arrow-island、guilty-until-innocent、home-sick、the-spanish-love-deception、up-in-molten-lights）
   同因，实测均为 0。
2. **多 1 本：⑲ 看不见的那一类。** `love-on-the-brain-by-ali-hazelwood` 用全角冒号块头
   `> **原句 1：**`，⑲ 判「无法判定」，实际有 18 处整段英文（ch15–ch17 的「中文理解」写成了英文剧情摘要）。
   这一类只有本文的口径能捞到。

## 七、复跑

```python
import glob, os, re
HAN = re.compile(r"[\u4e00-\u9fff]")
BLOCK = re.compile(r"(?=^>\s*\*\*原句\s*\d+)", re.M)          # 不限冒号形式，保留块头
LAB = re.compile(r"^(中文理解|理解|句子结构|关键词|为什么这样写|表达方式|读者视角提示)"
                 r"\s*(?:[（(][^）)]*[）)])?\s*[：:]\s*(.*)$")  # 标签行先剥 ** 再匹配
TARGET = {"中文理解", "理解", "为什么这样写", "读者视角提示"}

def fields(text):
    out = []
    for seg in re.split(BLOCK, text)[1:]:
        cur = synth = None
        for raw in seg.split("\n"):
            s0 = raw.strip()
            if not s0 or s0 == "---": continue
            s = re.sub(r"^(?:>\s*)+", "", s0)
            s = re.sub(r"^[-*]\s+", "", s).replace("**", "").strip()
            m = LAB.match(s)
            if m:
                lab = "中文理解" if m.group(1) == "理解" else m.group(1)
                body = m.group(2).strip()
                if lab == "中文理解" and synth is not None:      # 裸段落＋正式标签合并
                    out[synth][1] = (out[synth][1] + " " + body).strip(); cur = synth; synth = None
                    continue
                out.append([lab, body]); cur = len(out) - 1
                continue
            if s0.startswith(">") or s.startswith((">", "#", "|", "```")): continue
            if cur is not None: out[cur][1] = (out[cur][1] + " " + s).strip()
            elif synth is None: out.append(["中文理解", s]); synth = len(out) - 1; cur = synth
    return [(l, b) for l, b in out if l in TARGET]
```

对每本书统计 `sum(1 for l,b in fields(t) if b and not HAN.search(b))` 与该书 `len(fields)`，
按前者降序即得第三节表。

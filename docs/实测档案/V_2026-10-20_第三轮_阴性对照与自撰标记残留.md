## 二、方法：阴性对照（negative control）是「跳过型」的唯一可证伪判据

AGENTS 第 3 条的「跳过型」判据写的是「**核对工具实际读了什么，再看它报的数字**」——
但「读源码」只能证明「它会怎么判」，不能证明「它这次判到了东西」。**阴性对照**补上后半步：

1. 把书目录**复制**到 `/tmp`（**绝不改真书**）；
2. 往里注入一条**必然**违规的内容；
3. 跑同一个工具，看它**报不报**；
4. 不报 ⇒ 该工具在本书上**是死的**（扫描集为空或口径不匹配）。

本轮实测三例：

| 工具 | 注入内容 | 结果 | 判读 |
|---|---|---|---|
| lane ⑯ `check_xref_chapter` | ch01 导航层加 ``ch05 `Zxqvblorp qqqzzz` `` | **报 0 条** | **死代码**：不是本书格式问题，是工具恒跳过 |
| lane ⑨ `check_nav_layer` | ch01 导航层加 `“Zxqvblorp … waldo”`（弯引号） | **报 0 条** | 工具 `_PAIRS` 只认 `「」『』`＋ASCII `"`＋`'`＋反引号，**不认 `“”`** |
| lane ⑨ `check_nav_layer` | 同上但用 **ASCII `"`** | **报 ❌ 1 条** | **活的**——扫描集正常 |

⚠️ 阴性对照的**前提是注入内容必须真的命中该工具的判据**。
第一次注入用弯引号时报 0，差点误判成「工具坏了」；换 ASCII 引号才响 ⇒
**「没响」有两种原因：工具死、或我的注入没命中口径。**判读前必须先读判据。

## 三、lane ⑯ 是死代码（跨书影响，已修）

```python
# scripts/check_xref_chapter.py
by_chap = dict((num, f) for num, f, _t in ref)   # num 是零填充字符串 '01'…'43'
...
tgt = int(nm.group(1) or nm.group(2))          # tgt 是整数 5
if tgt == own or tgt not in by_chap:            # '05' vs 5 ⇒ 恒为 True ⇒ continue
```

`sai.load_ref()` 返回的 `num` 是**零填充字符串**（`'01'`，插叙件还可能带字母后缀 `'01b'`），
而判定用的是**整数** ⇒ `tgt not in by_chap` **恒真** ⇒ **本项对所有书 100% 跳过，永远只报 `0/0/0`。**

**修法**（按 int 建索引，一个章号对应多个提取件，兼容 `ch01` / `ch01b` 插叙）：

```python
by_int = {}
for num, f, _t in ref:
    m0 = re.match(r'(\d+)', str(num))
    if m0:
        by_int.setdefault(int(m0.group(1)), []).append((num, f))
```

**修后必须补阴性对照**：注入 `ch05 \`Zxqvblorp qqqzzz\`` ⇒ 由「0 条」变为「❌ 伪造 1 条」⇒ 工具活了。

> **教训**：这不是「本书的洞」，是**全库的洞**。
> 板与日志写「gate.sh 19 lane EXIT=0」时，**lane ⑯ 的 0 是恒真的 0**——
> 与 AGENTS 第 3 条「跳过型必须写『未进扫描集，❓ 无法判定』」同族，
> 但更隐蔽：它不是**本书**的格式问题，而是**工具**根本不判。

## 五、新缺陷类：导航层「关键术语」行的自撰标记残留 + 词形不对齐 + 虚构词

### 5.1 形态

书里 4 章的 `## 本章导航` → `**关键术语**` 行里留着**写作时的自问自答**：

```
ch15  … · blister（水泡）· foraging（采集）· low-level fairy（低阶妖精）· lineage（门第）· sachets? → sachet（药包、布袋）。
ch16  … · marigold（万寿菊）· incantation? → satchel? no · larynx（喉头）· groin（裆部）。
ch17  … · Wolf（渡鸦）· scrying? no · recipe（方子）· tincture? no · blister（水泡）· trolling? no.
ch18  … · Obbie（妖精主事）· blob of gold? → 那一袋金子 · witch（女巫）· broker（魔力掮客）。
```

### 5.2 为什么 19 lane 全绿

| 门禁 | 为什么看不见 |
|---|---|
| ⑫ `check_anchor` | 只管**引语块的「关键词」字段**，不看导航层「关键术语」 |
| ⑨ `check_nav_layer` | 只扫**带引号**的成对片段；`关键术语` 行是 `term（中文）` 形态，**无引号** |
| ⑩ `sweep_analysis_inline` | 只管**行内英文片段**是否逐字；`foraging` 不是引语，它只是「一个英文词」 |
| ⑲ `check_chinese_layer` | 只查**是不是中文**——`foraging` 后面跟着中文释义，中文密度满分 |
| ⑦/⑤ `check_chapter_quotes`/`sweep_full` | 只管**引语行** |

⇒ **术语行既不是引语、也不是「分析字段」**，它在所有 lane 的口径之外。

### 5.4 扫描配方（可复用）

`关键术语` 行按 `·` 切段 → 每段取 `英文（中文）` 的英文部分 → 必须**逐字出现在该章 `text/`**；
同时正则扫 `词? →` / `词? no` / `词? yes` 三种标记形态（自建 `.memory/tools/nav_terms_check.py`）。

⚠️ **分档**：「术语在本章查无」59 条判为**提示型（口径不匹配）**——

## 八、四条可复用判据

1. **「门禁报 0」要先问扫描集在不在**——用**阴性对照**判，比读源码可靠；读源码只能判「它会怎么判」。
2. **「没响」有两种原因**：工具死，或**注入没命中口径**；判读前先读判据（本次弯引号 vs ASCII 引号）。
3. **工具的 0 可能是恒真的 0**——`by_chap` 键类型不一致 ⇒ `tgt not in by_chap` 恒真 ⇒ 跳过 100%；
   **凡是「条件不成立就 continue」的分支，都要单独验证那条条件真的成立过**。
4. **导航层不是「分析层」也不是「引语层」**——它是**第三种口径**，19 lane 全部不管；
   `term（中文）` 行里的英文词，既不是引语（不必逐字连续），也常不是原文词形（`foraging` vs `foraged`），
   **必须单独扫**。

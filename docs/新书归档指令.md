> 对标 `docs/新书启动模板.md`（精读开工用）——本文件是**归档任务**的启动指令。
> 归档流程细则已固化在根 `AGENTS.md`「新 epub 归档流程」节（2026-09-22），本指令不重复规则，只负责触发。

## 一句话启动指令（复制即用）

```
books 根目录有新增书籍文件。执行归档：
1. 先读 AGENTS.md「新 epub 归档流程」节。
2. 归档根目录全部新增 epub（核对已归档——命中按 AGENTS 处置表：重复副本删根目录 / library 为空且精读已完成也删根目录 / library 为空且精读未完成移入回拷 → 未归档的抽检开篇定体裁，边界本先问我拍板 → 建 <cat>/<slug>/library/ 手工 mv → index.md 字母位插入 + kebab 对账零缺零幽灵 → daily log + COLLABORATION 各记一条 → pathspec commit，不 push）。
3. 完成后输出新书相对路径清单（删除/回拷归位的分别标注）。
```

## 常用追问（归档完成后）

```
检查这几本书的精读是否已完成
```
（口径：ch*.md 覆盖 text/ 正文 + 总览三篇齐备；短篇合集豁免总览；偏移映射书以 frontmatter source_text 为准，不按文件号直比）

## 已归档书籍（含精读已完成）的处置

根目录 epub 与既有目录命中时，**不新建目录、不重复插 index 行**，按 AGENTS 处置表分支：

| 命中情形 | 动作 |
|---------|------|
| library/ 已有同名字节数一致的 epub | 重复投喂 → 删除根目录副本（字节数不一致停下问用户） |
| library/ 为空 + **精读已完成** | **删除根目录副本**——完成的书不留存 epub，核验需 epub 时按届时指令另拷（完成口径见 AGENTS 第 1 步） |
| library/ 为空 + 精读未完成/进行中 | 回拷 → 移入既有 library/（供 extract 提取） |
| 同名不同书 / 版本存疑 | `grep -rl` 全库排除跨书同名，拿不准问用户 |

## 门禁要点（验收时对照，细则见 AGENTS 归档流程节）

| 步骤 | 必须 | 禁止 |
|------|------|------|
| 体裁判定 | 抽检开篇 + 出版方/叙事人称/LoC 三方互证 | 凭书名、作者印象、Praise 修辞（"thriller"）直判 |
| 边界本 | AskUserQuestion 用户拍板 | 实例自行归类 |
| 目录移动 | 手工 mkdir + mv（library/ 未被 git 跟踪） | `git mv`（报 bad source） |
| 收尾对账 | 目录 kebab vs index 链接 slug 零缺零幽灵 | 只插行不对账 |
| 提交 | pathspec 只加 md 文件 + 明确路径 | `git add -A` / 自行 push |

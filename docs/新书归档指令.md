## 门禁要点（验收时对照，细则见 AGENTS 归档流程节）

| 步骤 | 必须 | 禁止 |
|------|------|------|
| 体裁判定 | 抽检开篇 + 出版方/叙事人称/LoC 三方互证 | 凭书名、作者印象、Praise 修辞（"thriller"）直判 |
| 边界本 | AskUserQuestion 用户拍板 | 实例自行归类 |
| 目录移动 | 手工 mkdir + mv（library/ 未被 git 跟踪） | `git mv`（报 bad source） |
| 收尾对账 | 目录 kebab vs index 链接 slug 零缺零幽灵 | 只插行不对账 |
| 提交 | pathspec 只加 md 文件 + 明确路径 | `git add -A` / 自行 push |

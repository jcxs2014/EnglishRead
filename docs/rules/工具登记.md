## 按书归置的工具包（不进顶层）

> 单本书专用的生成/校验工具放 `scripts/<书简称>/`，子目录里带 `README.md` 说明用法。
> **不进顶层 `scripts/` 平铺**——顶层只放跨书复用的工具。

| 包 | 脚本 | 一句话职责 |
|---|---|---|
| `scripts/astarion/` | `astarion_build.py` | 按 JSON 规格生成一章精读 md，引语从 text/ 逐字抽取 |
| `scripts/astarion/` | `astarion_assemble.py` | 把 spec + tiers 两份 JSON 装订成一章 md |
| `scripts/astarion/` | `astarion_fix_nav.py` | 把每章 spec 的「书内章号」改成实测切点来源 |
| `scripts/astarion/` | `extract_chapterless.py` | 无章节标记 epub 的分段提取（PRH house style） |
| `scripts/astarion/` | `check_sliced_corpus.py` | 自造切点的对账（无章节标记 epub 专用） |
| `scripts/bird/` | `gen_bird_overview.py` | Bird of a Thousand Stories 总览三篇的引语池 |
| `scripts/bird/` | `precheck_bird.py` | Bird of a Thousand Stories 单章写作期预检 |

## 旧脚本名 → 新命令（2026-10-20 合并）

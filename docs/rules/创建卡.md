# 创建卡 · 写一章精读

> 每写一章前读一次，全文约 2 KB。**这是创建期的全部规则**——判例、历史、为什么，都不在这里。
> 目的只有一条：**忠实于原文**。它拆成四问：逐字？对应？可回溯？不漏？
>
> 细则另在：语料提取 / 词汇 A/B 裁决 / 批次节奏 → `docs/rules/30-writing.md`；门禁判读 → `docs/rules/20-gate.md`；改引语 → `docs/rules/11-fix-sync.md`。
>
> **形态与阈值只从一个地方取**：`python3 scripts/bookform.py "<书目录>" --contract`
> ——一条命令打齐「会判红的 5 项 / 不判红但会毁掉这本书的 / 一章的骨架（含本书体裁的导航项名）」。
> **不要读 `scripts/` 源码反推判据**：契约就是上面那些，源码只是它的实现；反推一次要几十次调用，且会把注意力从原文挪到代码上。

## 0. 三句话

1. **引语先定，分析后写**——顺序反了，必然出现"引语截短、分析讲更长的原文"。
2. **分析里出现的每个人名/动作/关系，都必须在这段引语里**；不在，就是引语选短了。
3. **拿不准的事实，grep 一次原文**，不要写"大概"。

## 0.5 一章的骨架（脚本按这个形状判，别自创）

```
---
状态: 未读
modified: "YYYY-MM-DD"
---

# NN. Chapter N            ← H1 跟本书既有形态（新书用这个，库内占 85%）

## 本章导航                 ← 项数与项名按体裁 profile（novels/mystery 是 5 项）

## 精读
> **原句 1:** "…"          ← 每块：引语行 + 子项
**中文理解** / **关键词** / **为什么这样写** / **读者视角提示**
                          ← ★ 上面这个形状是 novels/mystery 的 4 子项（可加「句子结构」，profile 里已列为 optional）
                          ← 短篇合集与非虚构是 5 项（多「句子结构 / 表达方式」）

## 本章词汇                 ← 三档表（⭐⭐⭐ / ⭐⭐ / ⭐），例句逐字取自本章 text/
                          ← 位置固定：`## 精读` 之后、`## 一句话总结` 之前；漏了它 `check_vocab` 只报「词条 0」，不判红

## 一句话总结               ← 必须有正文（只写标题不写内容，lane ⑬ 判红）
```

- **形状以 `python3 scripts/bookform.py "<书目录>"` 第一行打印的 profile 为准**——
  唯一定义在 `docs/rules/genre-profiles.json`，不在本卡也不在脚本里。
- 新书前 3 章按 profile 判；满 3 章后**由本书前 3 章自校准**，profile 降为参照。
- 短篇合集**没有总览三篇**；其余体裁完工时三篇必做。
- 形态偏离不算错，但在 `4-verdict.md` 写一行理由。

### 另外两种体裁的章内骨架（与上图只有这些差异）

**短篇合集**：一篇一文件；块 = 引语行 + **5 子项**（中文理解 / 关键词 / 为什么这样写 / **句子结构** / **表达方式**）；导航项名按集子性质自定（异象集用「异象类型 / 事件年代」，年度选集用「出处 / 篇幅」），**项数 3–6**；**不写总览三篇**。

**非虚构**：顺序是**先看骨架再看语言**，论证结构在精读之前。

```
## 概览        出处 / 作者 / 章节定位（属哪个 Part）/ 字符数 / 一句话主旨
## 论证结构    核心论点 · 证据链表（| 证据 | 类型（案例/研究/数据/类比）| 支撑什么 |，3–6 行）
              · 论证脉络（引入 → 反直觉 → 证据 → 推论 → 落点）· 可质疑处（1–3 条，无则写「无明显漏洞」）
## 选择性精读  处数据 profile 与本书中位，每处 5 子项（中文理解 / 句子结构 / 关键词 / 表达方式 / 为什么这样写）
## 词汇分级    三档表
## 一句话总结
```

**可质疑处不得省略**——那是非虚构精读的价值所在。

## 1. 开工命令

```bash
python3 scripts/bookform.py "<书目录>"            # 本书形态：H1 / 导航项 / 子项集 / 块数中位
ls "<书目录>/text" | grep -i "ch0*NN"             # 本章语料在不在；不在先提取，别动笔
bash scripts/chapter.sh "<书目录>/chNN 标题.md"    # 写完立刻跑
```

- 新书第一次：先跑 `verify_corpus.py`（件数 + 人物锚点）。**语料错了，下面所有绿都是假的。**
- 形态**偏离本书众数不算错**，但要在审查表里写一行理由。

## 2. 生产顺序（不可调换）

| 步 | 动作 | 判据 |
|---|---|---|
| ⓪ | **先写素读清单**：读 `text/chNN.txt`，列 5–8 条「谁做了什么」，每条挂一段原文逐字锚点，用 `suread.py` 校验 | 锚点在原文 100% 命中（查无 = 这条事实是凭印象写的） |
| ① | 只读 `text/chNN.txt`，按本书块数中位选段 | 每段先 `grep -F` 确认逐字命中 |
| ② | 先落引语全文，再写各子项 | 子项里的人名/动词能在该段引语中找到 |
| ③ | 词表从 `vocab_candidates` 输出里挑，只做减法 | 例句必须是原文句；分档不注水 |
| ④ | 导航 + 一句话总结 | 与本书既有章同形（项数、分隔符、H1 形态） |
| ⑤ | 补 frontmatter（`状态: 未读` / `modified: "YYYY-MM-DD"`）| 与本书既有章逐字同形 |
| ⑥ | 跑 `chapter.sh` | 按 §4 处置 |
| ⑦ | **立刻提交本章**（pathspec），再开下一章 | 相邻两章提交间隔 < 2 分钟或 > 6 小时无提交，都会被 `check_rhythm.py` 标出 |

### ⓪ 为什么先写素读清单

「我读过原文」这句话无法核对，「这 6 条事实都能在原文里指到字符」可以。
`python3 scripts/suread.py "<书目录>" chNN "<facts.txt>"` 会逐条校验锚点，
产出 `.memory/raw-gates/<slug>/production/chNN-suread.json`。
审查方第一眼就能看见**你读的是哪几段**——只写了开头的章，清单会立刻露馅。
（这条原本只属于审查方 R1；2026-10-21 前移到生产期，理由见 `docs/实测档案/` 的会话审计。）

## 3. 七条硬线（无例外）

- **块数有上下限，不能随意定**：每章 **2–15 块**，超 15 判**阻断**（`chapter.sh` / `gate.sh` 都查）。
  - 按篇幅取：**800 词 2 块就够**；1,000–1,600 词 3–4 块；1,600–2,400 词 4–6 块；2,400–4,500 词 6–12 块；4,500 词以上最多 15 块。
  - `chapter.sh` 会打「本章 N 词，建议 a–b 块」；落在建议区间外只是 `⚠️`（提示型），**越出 2–15 才是阻断**。
  - 来历（2026-10-21 用户拍板）：「引语块的数目应该有下限和上限，不能随意决定，比如这个 800 词，搞两个引语就够了，最多不能超过十块，不然读起来也费劲」；同日上限由 10 改为 **15**。
  - 实证：`ebenezer-scrooge` ch03（1,731 词）写到 11 块；全库仍有 **49 本书 / 577 章** >15 块（`bruja-s-nest` ch22 达 211 块），按「新规则只对新增书籍生效」只记账不回溯。
- **引语是句级，不是段落级**：每块 **1–3 句、30–70 词、不超过 4 行**；超了就按原文句界**拆成两块**（拆不等于删，句界之间一个字不动）。
  - `chapter.sh` 对 **>100 词**的块打 `⚠️ 引语偏长` 并列出块名与词数——**提示型、不判红**（退出码仍 0）；看到它就拆，别等审查。
  ⚠️ 这条 `chapter.sh` 与 `gate.sh` **都不查**——没有 lane 管引语长度，机器全绿也可能整本不合格。
  实证：`don-t-leave-her-alone` 72% 的块超过 100 词（中位 168、最长 1,126），读者要读完一整页英文才见到分析，整本返工。
- **引语逐字**：省略号两侧必须是原词；两段隔着叙述的，**宁可拆成两条块**，不要用 `…` 缝合。
- **不凭记忆引原文**：任何英文句子，先 grep 再落笔。
- **断言先取证**：「谁做的 / 什么关系 / 死因 / 数字」四类，写之前 grep，写时顺手记下章号。
- **不许写模板句**：`本句描写了场景与人物的反应…`、`把 X 重新定义 as Y, not Z`、`此句通过修辞与节奏把人物的内心状态外化…`、`为后续情节的转折埋下伏笔` —— 这些是**没写**的伪装。
  - `chapter.sh` 判**阻断**（含「同一句在同一字段重复 ≥3 次」），`关键词` 整句照抄也报 ⚠️。
  - 判据来历：2026-10-21 `ebenezer-scrooge` 免费模型 33 分钟写 40 章，子项齐全、中文够长、旧门禁全绿，只有模板特征能识别——分析层是英文抄写＋句式循环。
- **句子要读得通（补字 ≠ 补内容）**：`的` 后直接跟动词（`把 X 的 写成…`、`"祖母"的 词与并列`、`让 X 成为 Y 的`）就是**缺词残句**，`chapter.sh` 判**阻断**。
  - 判据：每一句都要能出声读出来，并答得出「把**谁**的**什么**写成了**什么**」。
  - 起因：2026-10-21 `finding-darla` 的修复方把 314 处空引号填了字，句子仍不成立，而 `check_chinese_layer` 只数汉字 ⇒ 五条验收全绿。全库 551 本实测该模式只命中这一本 119 处 / 21 章。

## 4. 门禁红了怎么处置

| 输出 | 处置 |
|---|---|
| ❌ 且能指到原文的冲突/缺失 | **阻断，必须改** |
| ⚠️ 措辞、启发式判的 | 记一行，不改 |
| ❓ 无法判定（缺 epub / 缺语料） | **报告里写「未核」，不许当干净** |
| 正当写法被报错 | **先修工具，不动 md** |

## 5. 三条禁令（都来自实证事故）

- 不手写词条例句（手挑+手写 = 9/16 章伪造；脚本粘贴 = 0 缺陷）。
- 不整文件 `write` 覆盖（三篇总览尤其），用行级 `edit`。
- 批量修复不用 `re.S` 跨块替换（曾一次损毁 116 处结构）。

## 6. 收工

- 只 add 本章路径；`git commit -m "..." -- <路径>`；不 push（等指令）。
- **最后一章**写完后再做三篇总览（`00_概述.md` / `00_金句精选.md` / `00_情感节点.md`），引语必须逐条 grep 原文，格式见 `30-writing.md`。
- `run review` 的产物落 `.memory/raw-gates/<slug>/review/chNN/`，写作时不用管。
- 判例与事故档案在 `docs/实测档案/`，**按需查，不要顺序读**。

# 生产步骤 ↔ 审查探针对照

> 用途：审查不是「再读一遍」，而是**按生产流程逐站打靶**——每一站只查它在生产中真正会失手的地方。
> 生产五步见 `docs/rules/创建卡.md` §2；审查五步 R1–R5 见 `docs/rules/审查表.md`。
> **本文件只写「哪一步容易错成什么样 + 用什么探」**；判据与档位仍以 `20-gate.md` 四档为准。

## ⑥ 施事 / 归属反转（S3 的第 6 类，两本书实测 6 例）

这类错误的特征是**句子通顺、引语逐字、中文是中文**——四道机器探针全绿，错的只是「谁对谁做了什么」。

| 实例 | 书 | 错法 |
|---|---|---|
| 「**人们**被鼓励去舔病人的肉伤」 | capture ch31 | 原文是**狗**被牵去舔伤口（`text/ch31:37` dogs…encouraged to lick） |
| 「问的人其实是**马瑟**」 | capture ch12 | 提问的是**露西**，马瑟是答话的人 |
| 后酬方向写反 | the-dues | 商人付法师 → 写成法师付商人 |
| 初吻归到「她」名下 | the-dues | 原文归马库斯 |
| Ben 母亲的经历安到 Jane 头上 | the-dues | 两人经历互换 |
| 「那酒是谁提的」写反 | the-dues | 主动方与被动方对调 |

**为什么会发生**：写分析时脑子里装的是「这段的情节」，中文句子的主语由**印象**而不是由**原文句子结构**决定。
英语的被动、分词状语、「the other one」这类指代，最容易在转述时被顺手安到显眼的人物身上。

**先分清叙述人称**：第一人称小说里的 `Am I…?` / `Do I…?` 是**叙述者的自问**，不可能是别人的内心话——
2026-10-21 审查方就把它判成「露西问的」，误报了一条阻断（capture ch12），执行方照改反而把正确的 `:28` 改坏。
**改之前先看这句是谁的视角**，再看是谁的动作。

**怎么查（R4 固定三问）**：这块的中文里，① **每个动词的主语**是谁、② **宾语/受事**是谁、
③ 涉及「谁的 / 谁欠谁 / 谁问的」时，**回原文那一句核对代词与介词**（`by` / `to` / `from` / `of` 决定方向）。

**不可机械化**：语义角色没有稳定的字面锚点，`check_speaker_consistency.py` 实测只到抽查级（1 条真缺陷 / 约 1/3 假阳）⇒ **不要为这一类加 lane**。

## 三条使用纪律

1. **先跑机器探针，再动眼睛**：机器能判的（S4 全量、S3 的密度/夹杂、S5 的引语）先用脚本扫，人只处理机器结构上查不了的**五类**：**漏 / 对应 / 说话人 / 施事归属 / 事实断言**。
2. **每个探针必须能被"阴性对照"证伪**：工具报绿不等于查过（`check_entities` 对 108 本抽 0 段仍 exit 0）。新加探针时配一个故意坏的夹具（`scripts/tests/`）。
3. **报警先读行再定性**：成片同类报警先假定工具口径错了（Such a Fun Age 19 条标注全对）；判对了才改 md。

## 按章节类型加权（不是每章都同样重）

| 章型 | 加重的站点 | 理由 |
|---|---|---|
| 首章 / 新书第 1–2 章 | S1、形态 | 没有本书众数可依，基线来自 profile；读者第一印象 |
| 有前情提示的章（retelling / 回忆 / 双时间线） | S1、S5 | 同一件事有两种版本，最容易把「她的版本」写成事实 |
| 对话密集章 | S2（跨话轮）、S3（说话人） | 拼接与错配都发生在话轮边界 |
| 章末有 cliffhanger | S2（归属） | 对话实际发生在下一章，引语容易提前 |
| 最后一章 / 后记 | S5 | 总览与「结局」断言全押在这里 |

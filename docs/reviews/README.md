# docs/reviews/ — 独立审查任务书与报告存档

- **谁写**：执行方完成一本书（含自审）后，按 `docs/独立审查任务书模板.md` 生成 `<slug>.md`
- **谁审**：独立审查方（另一实例 / 同机另一独立会话 / 用户指派的新会话）——同会话内自审与子代理不计入
- **报告去向**：审查方在 `<slug>.md` 追加"审查方报告"节，并在 COLLABORATION.md 回帖结论（通过 / 整改后通过 / 不通过）
- **依据**：AGENTS.md 第 10 条「强制条款（2026-09-18）：两道审查」
- **状态口径**：`完工待审` →（独立审查）→ `审查通过` = 完工释放

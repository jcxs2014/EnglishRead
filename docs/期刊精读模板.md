# 期刊文章精读模板

> **何时必读**：精读 `notes/` 下七个期刊来源（`notes/parisreview/` `notes/atlantic/` `notes/newyorker/`
> `notes/economist/` `notes/brainpickings/` `notes/lithub/` `notes/granta/`）的任何一篇**之前**。
> **书籍精读不走本文档**——那是 `docs/新书启动模板.md` 的事（两者体裁、格式、门禁都不同）。

> **规则仍在 `AGENTS.md`**（它是注入区，每会话都在）：禁令 1/1a/2/3、引语逐字、总览三篇豁免、
> 批次节奏、多实例并行保护。**本文档只放期刊侧的格式与编排**，不重复存规则。

---

## 期刊文章逐句精读格式（Economist / Atlantic / New Yorker / Brain Pickings / Literary Hub / Granta）
文件层级固定为：
0. `frontmatter`：`---` / `状态: 未读` / `---`（Obsidian 属性栏，点击切换阅读状态）
1. `# 标题（精读分析）`
2. `## 概览`：来源/栏目/副题 → 主题一段话 → 结构列表 → 段落脉络表格 → 核心金句
3. `## 逐句精读`：每个原文段落一个 `### 第 N 段：主题概括`；段内每个原句一个 `> **原句 M:**` 分析块，固定含**中文理解 / 句子结构 / 关键词 / 表达方式 / 为什么这样写**五子项；每段末尾 `**段落逻辑：**` 用 → 箭头串起该段逻辑链；原句编号 M 全文连续不重置
4. `## 段落逻辑`（可选，全文级逻辑梳理）
5. `## 词汇分级`（独立章节，含三档子标题）
- `### ⭐⭐⭐ 高级`（词/短语 | 释义 | 例句 表格）
- `### ⭐⭐ 进阶`
- `### ⭐ 基础`
6. `## 长难句专项`（2-5 个长难句逐句解剖）
7. `## 精读结束总结`（含子标题：1. 本文核心表达 / 2. 重要语法 / 3. 写作技巧等）
8. `## 可迁移表达`（独立章节）

**顺序核心规范**：5 → 6 → 7 → 8，四章顺序不得打乱。**核心规范**：每个原句一个分析块，禁止多句合并；结尾无 ■ 标记。
**引用块规则**：`>` 块**只含原句英文**；五个子项及一切解读内容都在块外，块与下方解读之间留空行。**五子项之间也需空行分隔。**

## 与书籍侧的分工（别串）

| | 期刊文章（本档） | 整本书（另一档） |
|---|---|---|
| 入口 | **本文档** | `docs/新书启动模板.md` |
| 单位 | 一篇 | 一章 + 总览三篇 |
| 格式骨架 | `## 概览`→`## 逐句精读`→`## 词汇分级`→`## 长难句专项`→`## 精读结束总结`→`## 可迁移表达` | 按体裁四档表（见新书模板） |
| 总览三篇 | **不要求**（文章无须总览） | 除短篇合集外**强制** |
| 原文核验 | 无成书可比，**不适用**第 3 条门禁 | 第 3 条全量 |

⚠️ **本库期刊精读的实际产出**：384 个 md（`economist` 199 / `brainpickings` 40 / `newyorker` 38 /
`atlantic` 33 / `parisreview` 32 / `lithub` 24 / `granta` 24），全部在 `notes/<来源>/<日期>/` 下。
**每篇开头的 frontmatter 用 `状态: 未读`**——`未读` 表示还没做精读。

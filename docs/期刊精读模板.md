## ⛔ 三件事，缺一件就别动笔

### 一、原文必须先落地成 `.src.md`（唯一真值）

**期刊侧的「原文先行」= 同名 `.src.md` 就位。** 没有它，下面所有门禁都是「无法判定」而不是「通过」。

| 来源类型 | 原文从哪来 | 落地形态 |
|---|---|---|
| **RSS 全文源**（parisreview / brainpickings / lithub / granta） | 跑 `python3 scripts/fetch_<源>.py`（四个脚本，产出 `NN <slug>.md` + `index.json`） | **把该期每一篇重命名/复制为 `<文章标题>.src.md`**，与精读 md 同名同目录 |
| **付费墙源**（atlantic / newyorker / economist） | 思源笔记对应文档导出 | 导出正文存为 `<文章标题>.src.md`，**只存正文**，frontmatter 与「Source in SiYuan」指针可留可删 |

- 命名：`<文章标题>.src.md`（与精读 md **同名**，仅后缀不同）。已入库的 42 个双后缀
  `*.src.src.md` 是 fetch 脚本与人工改名相撞的产物，视为同一形态。
- `.src.md` 已被 `.gitignore` 忽略 ⇒ **不跨机可用**。换机器做核验前需重新导出。
- **只存原文，不要在 `.src.md` 里做精读。** 精读 md 是另一份文件。

### 三、门禁：期刊侧是**降级 lane**，不是「无门禁」

```bash
python3 scripts/sweep_journal.py                        # 全库
python3 scripts/sweep_journal.py "notes/economist"      # 单来源
python3 scripts/sweep_journal.py "notes/economist/260822"  # 单期
```

口径复用 `verify_quotes.extract_quotes` + `flat_alpha`（与 `check_short_quotes.py` 同一做法），
**不另立尺子**。三档 lane 与 `AGENTS.md` 第 3 条同一套判据：

| lane | 判据 | 含义 |
|---|---|---|
| **完整** | 有同名 `.src.md` 且正文 flat ≥ 400 字符 | 逐条比对，报 ✅ 逐字 / ✅ 省略号合法截断 / ❌ 疑似改写 |
| **无语料** | 无 `.src.md` | 退出码 2 + 「❓ 无法判定」，**不产出计数** |
| **语料残缺** | `.src.md` 只有思源指针，或明写被截断 | 报「⚠️ 无语料可比」，**不判红** |

**「无语料」不是「检查通过」，是「检查没做」**——报告里必须写清 lane，不得与完整 lane 的数字混用。

#### 报警按三档定性处置（`AGENTS.md` 第 3 条）

| 档 | 处置 | 判据 |
|---|---|---|
| **阻断型** | **必须改** | `❌ 疑似改写`——整串 flat 查无且按 `…` 切分后仍有片段查无 |
| **提示型** | 只记不改 | `⚠️ 无语料可比` |
| **假红型** | **先修工具** | 见下方「A/B 裁决」第 2 条 |

#### A/B 裁决：**判 A 前必须先判 src 可不可信**（期刊侧专属，书籍侧第 5 条未覆盖）

期刊的 `.src.md` 来自思源导出，**实测会系统性损坏**。2026-09-29 抽样实测：

| 现象 | 样例 | 归属 |
|---|---|---|
| **丢撇号** | 原文 `life's opposite` → src `life opposite`；`Gilligan's portrait` → `Gilligan portrait`；`Leah's three young children` → `Leah three young children` | **B 类（src 脏，md 是对的）** |
| **单词截断** | 原文 `Savoiardi biscuits` → src `Sawia biscuits` | **B 类** |
| **md 擅自改写** | `chose`→`choose`（改正语法）· `He's a conflicted force…`→`Jordan is a conflicted force…`（主语替换）· `administration's`→`administration`（删 `'s`）· `*H. sapiens*`→`*Homo sapiens*`（展开缩写）· `Democratic National Committee (DNC)`→`the DNC`（删全称） | **A 类（md 缺陷）** |
| **跨标签拼接** | 抹掉中间的 `, Michael wrote` / `she writes` / `("Battyman" is an offensive word…)` 后用句号接上 | **A 类（禁令 5）** |
| **伪加引号** | 原文间接引语 `phrases like absolutely bananas and too bizarre` → md 写成 `"absolutely bananas" and "too bizarre"` | **A 类** |
| **假红** | 整类都归 B 类（某次思源导出丢了全篇撇号）⇒ **先修/重导 src，再判 md** | **假红型** |

⚠️ **「大面积同类报警」先读行复核，再批量改**（`AGENTS.md` 第 3 条同款）：
某篇成片报「疑似改写」时，**先 `grep` 抽 2–3 个词回 `.src.md` 看原文长什么样**——
若原文明显缺撇号，**那是 src 脏，不是 md 错**。

#### 已知盲区（不要把 0 当成「全对」）

1. **分析层行内英文不在口径内**——「句子结构 / 为什么这样写」里的英文短语属禁令 3，
   期刊侧与书籍侧都**没有**低成本机检。
2. **词汇例句、概览层、段落逻辑层**的英文不在口径内。
3. **只抽 `>` 块**。若把非引语写进 `>` 块（如交叉引用笔记），本脚本会当引语判 ❌——
   那是 md 的格式缺陷（`>` 只有引语能用），**不是脚本假红**。

## 期刊文章逐句精读格式

文件层级固定为：
0. `frontmatter`：`---` / `状态: 未读` / `---`
1. `# 标题（精读分析）`
2. `## 概览`：来源/栏目/副题 → 主题一段话 → 结构列表 → 段落脉络表格 → 核心金句
3. `## 逐句精读`：每个原文段落一个 `### 第 N 段：主题概括`；段内每个原句一个 `> **原句 M:**` 分析块，固定含**中文理解 / 句子结构 / 关键词 / 表达方式 / 为什么这样写**五子项；每段末尾 `**段落逻辑：**` 用 → 箭头串起该段逻辑链；原句编号 M 全文连续不重置
4. `## 段落逻辑`（可选，全文级逻辑梳理）
5. `## 词汇分级`（独立章节，三档子标题）
   - `### ⭐⭐⭐ 高级`（词/短语 | 释义 | 例句 表格）
   - `### ⭐⭐ 进阶`
   - `### ⭐ 基础`
6. `## 长难句专项`（2-5 个长难句逐句解剖）
7. `## 精读结束总结`（含子标题：1. 本文核心表达 / 2. 重要语法 / 3. 写作技巧等）
8. `## 可迁移表达`（独立章节）

**顺序核心规范**：5 → 6 → 7 → 8，四章顺序不得打乱。**核心规范**：每个原句一个分析块，禁止多句合并。

**引用块规则**：`>` 块**只含原句英文**；五个子项及一切解读内容都在块外，块与下方解读之间留空行。**五子项之间也需空行分隔。**
⚠️ **汇总性说明、交叉引用笔记、词表释义都不要写成 `> 引用块`**——`sweep_journal` 会当引语去 `.src.md` 里找，找不到就报 ❌。

**两条易错点**：

- **「状态: 未读」是 Obsidian 的「我还没读」标记，不是「还没做精读」。**
  已完成的精读文件**保持 `未读`**，直到你自己读过才改。这样 `status` 才能当筛选器用。
  （2026-09-29 实测：318 篇里 188 篇标着 `未读` 且确有完整精读内容——那是正常状态，不是漏标。）
- **`■` 是 Economist / Atlantic 原文自带的文章结束符，会随 `.src.md` 一起进引语。**
  模板不禁止它出现在**引语内部**；但**不要在精读文件结尾自己加一个 `■`**。

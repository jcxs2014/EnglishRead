**三条硬性纪律**（本项目反复吃亏的地方）：

1. **改引语必须同步改分析**——中文理解 / 句子结构 / 关键词 / 为什么这样写四处都要跟着重写（AGENTS 第 9 条）。只改引语留旧分析是已知缺陷类。

3. **提交前 `git pull` + `git status`**——多实例并行，`git add` 只加本任务明确路径，**禁 `git add -A` / `git add .`**（AGENTS 第 4 条）。

# EnglishRead 书籍分站（notes1）

主站（englishread.jcxs2014.workers.dev）的**整书精读分站**。主站保留期刊类（The Economist / The Paris Review / Brain Pickings / Granta / Literary Hub）与剩余书籍；本站收录第一次滚动切割迁出的 **302 本**整书精读。

## 分类导航

- [推理 / 悬疑](books/mystery-thriller/)（37 本）
- [非虚构](books/non-fiction/)（43 本）
- [长篇小说](books/novels/)（201 本）
- [短篇合集](books/short-story-anthologies/)（21 本）

完整书单见 [书单](books/index)。

## 说明

- 精读内容以 `ch*.md` 逐章呈现，每本书目录下含 `00_概述` 等概述类文件
- 本站与主站同源仓库、同构 Quartz 构建，由 Cloudflare Workers 独立部署（englishread1）
- 主站与分站的搜索索引、书单各自独立维护

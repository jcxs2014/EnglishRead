# Venus Fly Trap — 全书概述（Plot Overview）

> 作者：Emma Medrano ｜ 类型：心理惊悚 /  lesbian thriller ｜ 叙事者：Louise（第一人称）
> 全书 31 章精读见同目录 ch01–ch31。本篇为宏观脉络梳理。

## 一句话总括

一个孤独、有精神病史的女孩 Louise，痴迷于光芒四射的室友 Cat，一步步活成 Cat 的影子；Cat 利用这份痴迷，把"杀夫"的刀递到 Louise 手里，自己全身而退——这是一场捕食者与被捕食者互换身份的悲剧。

## 三幕结构

**第一幕 · 执念成形（Introduction + Ch1–Ch9）**
- Louise 在公寓发现 Cat 死于刀伤（Introduction 倒叙钩子）。
- 回溯：Louise 与 Cat 相识（Ch2），被 Cat 主动选中为"最好的朋友"（Ch3）。
- Louise 的空洞背景：死去的姐姐 Maisie（服药自杀）、间断的精神病院经历、与 Alistair 的 sugar daddy 关系（Ch4）、与 Chloe 的敷衍恋爱（Ch5、Ch20）。
- Cat 提议三人行（Ch5 表象），实为喂养 Louise 对她的执念（Ch28 Henry 揭穿）。

**第二幕 · 共谋与畸变（Ch10–Ch27）**
- Louise 撞见 Henry 打 Cat（Ch15），从此"救 Cat"成为执念。
- 她纹 Cat 的玫瑰刺青（Ch19）、偷 Cat 内裤（Ch22）、穿 Cat 衣妆（Ch26）——逐渐"成为 Cat"。
- 与 Henry 的对峙中 Cat 说"我希望他死"（Ch21），两人规划谋杀：Cat 造不在场证明、Louise 动手（Ch26–Ch27）。
- Oliver 淋雨闯入，第一次 external 点破："你看起来像她"（Ch28）。

**第三幕 · 收网（Ch28–Ch31）**
- 前夜化妆、Cat 用卷发棒自烫脖颈造伤（Ch29）。
- Louise 赴 Henry 公寓，对话中 Henry 说"三人行是 Cat 的主意""Cat eats people"（Ch29）。
- 取刀、被扼颈、反杀指喉却松手未杀（Ch31）——Louise 不是凶手。
- 案发后 Cat 杀 Louise 的宠物鼠、回避、不接牢房电话（Ch30）。
- 证据链全部指向 Louise（指纹/DNA/偷手机/精神病史/枕下 Cat 内裤），Cat 探监翻脸指认她（Ch31）。
- 终局：Louise 面对 sketchbook 上十个 Cat 的笑脸，懂了——Catherine Parr，都铎六妻中唯一善终者。

## 核心主题

1. **心理利己主义（psychological egoism）**：Cat 不信利他，认为一切行为皆为自身利益；Louise 的"替她顶罪"是全书的反例，也是唯一真正的无私。
2. **模仿与吞噬**：Louise 模仿 Cat 到失去自我；"Cat eats people"既是 Henry 的警告，也是字面结局。
3. **创伤的代际传递**：Maisie 之死让 Louise 把"拯救 Cat"当作自我救赎；她没能救 Maisie，于是要救 Cat——却救进了一个陷阱。
4. **叙事不可靠**：第一人称 Louise 的视角被 her 自身妄想与 Cat 的表演双重遮蔽，读者直到 Ch31 才与她同时醒悟。

## 人物弧光速览

| 人物 | 起点 | 终点 |
|------|------|------|
| Louise | 空洞、寄生于他人身份 | 被吞噬、顶罪、仍画着 Cat 的笑脸 |
| Cat | "伤者"/光芒 | 捕食者、全身而退的 Catherine Parr |
| Henry | 脸谱化反派 | 被低估的、会怕会装的普通人 |
| Oliver | 被轻视的友人 | 唯一在法庭前仍来探监的人 |
| Maisie | 已死的姐姐 | Louise 终生未能释怀的幽灵 |
